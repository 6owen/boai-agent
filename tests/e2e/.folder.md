# e2e

通过真实 Electron 应用验证桌面、环境、扩展能力、历史记录和数据升级。

一旦我所属的文件夹有所变化，请更新我。

| 成员 | 地位 | 功能 |
| --- | --- | --- |
| `desktop.spec.ts` | 文件 | 桌面导航、离线 Carbon 图标、任务空态入口、草稿保留、未保存对话框和员工操作验证 |
| `environment.spec.ts` | 文件 | 员工环境、技能读取与产物发布的桌面验证 |
| `extensions.spec.ts` | 文件 | 主题、背景高级选项、外部 Agent 与自动化的桌面验证 |
| `history.spec.ts` | 文件 | 历史群聊和活动轮次的端到端验证 |
| `upgrade.spec.ts` | 文件 | 旧数据升级和恢复的端到端验证 |
| `appearance.spec.ts` | 文件 | 真实窗口尺寸/75–150% 原生缩放时页面铺满、字体/颜色立即生效、菜单同步、重启与重置验证 |
| `ui.spec.ts` | 文件 | 全部 UI 模块编译、真实弹层/菜单/选择/主题/图标与无 ring/outline 键盘焦点的集成验收 |
| `contacts.spec.ts` | 文件 | 通讯录浏览不建会话、真实配置保存与未保存保护、复用会话/草稿、搜索折叠和固定列表宽度 |
| `avatars.spec.ts` | 文件 | 紧凑弹窗、一致行尺寸/悬停、12 个 SVG、本地上传/失败保持和焦点恢复、跨页面与重启头像保留 |
| `detail-panel.spec.ts` | 文件 | 内容宽度标签与上下分割线精确对齐、分栏拖拽与原生缩放、标题截断/固定、关闭保存和嵌套返回焦点 |
| `creation.spec.ts` | 文件 | 三字段员工与群选人创建、Prompt 保存、右侧群编辑、纯手动侧栏与图标状态 |
| `composer.spec.ts` | 文件 | 权限/模型真实保存、草稿保留、群聊员工隔离、执行锁定与原生窄窗口菜单 |
| `pages.spec.ts` | 文件 | 创建弹窗必填校验、保存并退出、右侧复选框状态、Enter 提交、菜单焦点与任务筛选 |
