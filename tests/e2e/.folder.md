# e2e

通过真实 Electron 应用验证桌面、环境、扩展能力、历史记录和数据升级。

一旦我所属的文件夹有所变化，请更新我。

| 成员 | 地位 | 功能 |
| --- | --- | --- |
| `desktop.spec.ts` | 文件 | 桌面导航、任务空态入口、草稿保留、未保存对话框和员工操作验证 |
| `environment.spec.ts` | 文件 | 员工环境、技能读取与产物发布的桌面验证 |
| `extensions.spec.ts` | 文件 | 主题、背景高级选项、外部 Agent 与自动化的桌面验证 |
| `history.spec.ts` | 文件 | 历史群聊和活动轮次的端到端验证 |
| `upgrade.spec.ts` | 文件 | 旧数据升级和恢复的端到端验证 |
| `appearance.spec.ts` | 文件 | 字体/颜色/原生缩放立即生效、菜单同步、重启与重置验证 |
| `ui.spec.ts` | 文件 | 全部 UI 模块编译、真实弹层/菜单/选择/主题/图标与 Soft 键盘焦点的集成验收 |
| `pages.spec.ts` | 文件 | 必填校验、保存并继续、复选框状态、Enter 提交、菜单焦点与任务筛选 |
