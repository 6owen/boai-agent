场景描述、业务步骤与桌面支撑分层。

一旦我所属的文件夹有所变化，请更新我。

| 成员 | 地位 | 功能 |
| --- | --- | --- |
| `desktop.ts` | 共享支撑 | 独立目录、延迟启动、可选场景引导入口、同数据重启、trace/截图与资源清理 |
| `test.ts` | 共享支撑 | playwright-bdd fixture 根及场景生命周期 |
| `skill-marketplace.ts` | 网络支撑 | 离线商店服务/生产适配器、Vite fixture、同商店/跨商店延迟和错误控制 |
| `skill-updates.ts` | 更新支撑 | 真实 AppService/SQLite、可控下载源与测试 HTTP 桥接，不替代原生 IPC 验收 |
| `native-skills.ts` | 原生技能支撑 | 生产 main/worker 引导、隔离用户目录及替换网络的同名异源商店/ZIP fixture、脚本与图片副作用探针、取消/部分响应体断流与重启；不进入产品构建 |
| `automation-history.ts` | 历史数据 | 指定时刻的历史遮挡数据；到期等待 fixture 与真实累计账本；仅向场景独立数据库写入已结束的记录，验证完整分页/按计划筛选且不调用模型 |

| `automation-notifications.ts` | 通知支撑 | 仅替换系统 show 提交端，驱动实际主进程监听的点击/失败事件；不弹真实 OS 提醒 |
| `automation-monitor.ts` | 监控数据 | 隔离已发布 JSON 文件和检查点只读查询；不替换监控执行链 |
| `automation-recovery.ts` | 中断支撑 | 真实写文件后挂起的本地模型端点与本场景 utility process 故障注入 |
| `local-skills.ts` | 成员 | 隔离 worker 用户目录与本机/插件 fixture；导出空白用户目录引导、复用图标浮层选择导航 |
| `group-chat.ts` | 群聊支撑 | 场景独立 SQLite 已交付消息/工作/真实文件与本地协议模型，生产 main/IPC/renderer 原样运行 |
