# RPC 传输

- index.ts：默认仅类型出口。
- client.ts、server.ts：明确Node连接入口。
- channels.ts：通过CliServicePort装配业务方法。
- discovery.ts：同机连接发现。
- events.ts、history.ts：订阅与游标协议。

- `channels.ts`：owner task list/result沿原服务读取，不授予运行凭据跨任务读取权。
