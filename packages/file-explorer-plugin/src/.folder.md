文件系统宿主与无平台UI分离；正文只在当前活动预览内持有。
一旦我所属的文件夹有所变化，请更新我。

- `host.ts`：目录分页、范围复核和只读预览；路径校验与启用状态由宿主注入。
- `tree.ts`：迁用DSH展开/缓存投影与文件后缀拆分。
- `explorer.tsx`：左侧预览插槽、右侧虚拟树及键盘/刷新/隐藏文件操作。
- `explorer.css`：共享主题变量，宽窄面板均左侧主预览、右侧窄文件树。
