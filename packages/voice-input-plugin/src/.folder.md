# src

一旦我所属的文件夹有所变化，请更新我。

2026-10-27本轮成员同步：

- `capture-worklet.js`：单声道PCM16k重采样与明确尾段flush；不设录音总时长额度。
- `capture.ts`：AudioWorklet采集、真实设备关闭、尾段确认和有界回压。
- `controller.ts`：临时预览、一次草稿插入、改稿失效与迟到整理保护。
- `host.ts`：语音单租约、启动/关闭协调、真实helper退出与临时音频清理。
- `local-helper.cjs`：独立utility process中的公共Silero VAD、PCM读取、识别结果回执与真实退出。
- `local-recognizers.cjs`：SenseVoice/Whisper引擎适配器，封装模型加载与语言参数；Whisper规格复用同一适配器。
- `local-audio.cjs`：按适配器声明读取PCM段首上下文，使用显式文件位置并限制文件起点，保持VAD扫描位置。
- `model-manifest.ts`：SenseVoiceSmall、Whisper Tiny/Base及Silero/完整许可的固定来源、字节和SHA256，关联引擎适配器。
- `models.ts`：按modelId下载/取消/移除、独立进度、完整SHA校验和原子安装，保留旧SenseVoice路径。
- `protocol.ts`：转出shared唯一语音合同，不维护第二份schema。
- `qwen.ts`：Qwen实际实时协议、确认片段排序/去重及未知用量，不重传。
- `settings.ts`：v3模型选择、v1/v2无写入迁移、串行CAS、坏文件只读保护与识别地址绑定密钥。

2026-10-27语音设置增量：

- `settings.ts`：v1无写入迁移到v2，显式保存与后端语言校验。
- `capture.ts`：精确设备采集、缺失不回退、迟到授权和取消立即关流；`controller.ts`传递同版设备选择。
- `host.ts`：识别与短期设备授权互斥，语言/规则按配置revision下发。
- `qwen.ts`：在线语言参数；`local-helper.cjs`：校验本地语言并传给SenseVoice。
