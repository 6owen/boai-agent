# appearance

跨进程外观合同、内置主题和语义 token 真源；兼容旧偏好与主题 ID，增补字体、缩放及分模式颜色。

一旦我所属的文件夹有所变化，请更新我。

| 成员 | 地位 | 功能 |
| --- | --- | --- |
| `BASE46-LICENSE.txt` | 许可 | 随色板分发的 Base46 MIT 许可 |
| `base46.json` | JSON 例外文件 | 输入：Base46 色板；输出：内置配色数据；地位：静态主题资源 |
| `imported-palettes.json` | JSON例外文件 | bobo项目21套CSS色值、名称/模式、来源hash与终端色彩角色 |

| `index.ts` | 共享实现 | 图片不改变模式解析；玻璃/遮罩/模糊独立，默认null/40%/8px及32px上限；外观DTO、局部更新合并、字体/缩放/主题和语义token；四状态12%混色背景及Soft操作前景对比度 |
| `terminal.ts` | 终端配色 | 按实际应用主题ID映射官方Base46或VS Code Plus ANSI，BoAI及未知主题沿原明暗保底色板 |
