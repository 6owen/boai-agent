资源模块管理本地技能安装、兼容受管副本、导入计划、用户收藏和知识查询；员工授权归员工服务。

一旦我所属的文件夹有所变化，请更新我。

| 成员 | 地位 | 功能 |
| --- | --- | --- |
| `management-skills.ts` | 显式文档装配 | 按当前消息的内置管理标签加载固定SKILL.md，原权限及已有绑定副本保持 |
| `local-resources.ts` | 文件边界 | 完整 YAML、受限资源树/hash、受管导入与排除宿主归属标记的产物列表/启动历史发现；本机显示兼容名称、受管导入严格校验 |
| `resource-cleanups.ts` | 清理恢复 | D4 删除事务保存真实 UUID 所有权/hash 并清除私有回执，外改保留；旧资源路径规则不变；失败记录/手动重试/重启恢复，不跟随外部链接 |
| `skill-updates.ts` | 更新用例 | D4 新副本在明确更新最终事务同步新 hash/files、保留 UUID/所有权，失败保留旧证据；本机与受管单项/批量只读检查、未知安装基线确认、本地同盘交换/恢复与缓存失效；差异/绑定预览、本地修改显式确认、资源独占及实际旧内容回滚/启动恢复 |
| `skill-collections.ts` | 持久集合 | 事务版本检查、分组前后/技能顺序与跨组原子保存、收藏分组/旧库幂等合并及资源删除时来源/检查结果清理；local 本机身份与受管技能共用版本化收藏，授权独立 |
| `skill-management.ts` | 管理用例 | D4 复用扫描计划/操作账本准备与原子员工绑定、已知远程来源/本机身份、未知只读回执和安全恢复；多来源/旧库预览与幂等安装；local 目标写 ~/.agents/skills 并失效目录缓存、仅保存来源/收藏/操作，不创建 Resource；保留旧受管管道、取消与中断恢复 |
| `skill-binding-files.ts` | D4 文件边界 | 冻结 hash 文件清单、独占 UUID/所有权标记和有界普通文件复制；仅 hash 匹配清理，外改/链接保留且显性失败，不运行程序 |
| `skill-binding-records.ts` | D4 清理合同 | 原 skillOperations 回执清除私有员工/资源快照后保留 requestId/fingerprint tombstone，副本清单转移至既有清理日志 |
| `skill-library-export.ts` | 便携导出 | 本机/受管技能的原版 BoAI 仓库 ZIP、从冻结文件生成相对目录/类型/大小的实际清单、同名冲突/敏感配置排除、可取消 ZIP、原子无覆盖保存及持久结果 |
| `knowledge-search.ts` | 查询 | 获准本地知识的检索 |
| `marketplace-providers.ts` | 来源适配 | 从旧项目迁移三家列表/搜索/详情映射，保留所有者和原生分页 |
| `marketplace-http.ts` | 网络边界 | 固定 HTTPS 商店、响应体超时/体积限制和 schema 校验 |
| `skill-marketplace.ts` | 商店用例 | 输入能力校验、有界缓存/去重、过期失败回退和取消 |
| `local-skill-catalog.ts` | 成员 | 本机只读目录缓存/并发去重、显式刷新、详情始终复核；共享/Agent/启用插件，链接去重、与安装共用的稳定身份、坏文档诊断、详情与 ID 预览边界 |
| `local-skill-install.ts` | 本地安装边界 | 固定 ~/.agents/skills、同名内容冲突/复用、同盘暂存与发布；不覆盖已有技能，仅清理本次暂存 |

| `local-skill-updates.ts` | 本机更新边界 | 只读取 CLI 全局来源记录并规范 GitHub 来源；校验 local 身份、固定 ~/.agents/skills 与同盘恢复路径，拒绝符号链接和插件写入 |

| `catalog-commands.ts` | 全局管理薄桥 | 普通bobo技能/数据源schema、有限服务映射和稳定请求身份 |

| `local-skill-editing.ts` | 文件边界 | 共享技能创建/核源编辑/同盘移出；插件和其他Agent目录只读 |

| `knowledge-management.ts` | 知识资料管理 | 原资源/员工绑定、准备和完成回执、独立保存与重启清理 |
| `knowledge-files.ts` | 知识副本 | 固定内容/hash/归属的不可变副本和保守清理 |

| `knowledge-tools.ts` | 共用知识工具 | 资料目录/固定版本检索与分页读取；调用前后核验当前授权，不创建Work |

| `prompt-templates.ts` | 提示词目录 | 全局列表/事务版本保存/删除、同请求核对与重启持久化，不执行模型 |

| `bound-skill-tools.ts` | 绑定技能按需读取 | 普通聊天与本机共用 list_skills/read_skill，前后授权及固定字节核验，不启动 Work |

| `bundled-skills.ts` | 默认装配 | 新Bobo单次种子与原绑定回执核对；内置源稳定身份、独立副本及不重放删除 |

bundled-skills.ts清单导入声明JSON类型，保证Node ESM/BDD加载与打包行为一致。

| `prompt-collections.ts` | 集合事务 | 提示词分组/顺序/归属与旧数据投影，CAS及损坏记录拒绝 |
