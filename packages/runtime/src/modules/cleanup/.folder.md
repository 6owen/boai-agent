# 清理与恢复

宿主确认对象和空闲状态后调用相应协调器。每个协调器保留自己的事务、重放身份和失败处理。工作区清理从已核实的业务身份派生路径。

| 文件 | 职责 | 行为 |
| --- | --- | --- |
| `conversation-history.ts` | 清理用例 | D6 最终清理事务删除私人阅读/完成事实并提升最小 clock epoch；成果失效/hash 清理及修订/采用回执、外改冲突阻止递归删除；普通消息清理去重回执与材料 hash 清理冲突恢复门禁；核心首发保留去正文的最小 cleared 回执，阻止清理后的首发重放；清空/解散共用重启日志并先传播记忆来源失效，防跨会话摘要和原文回退；解散删除会话配置/通讯录顺序且不重建目录；清理关联模型调用/技能激活/执行区间、Trace、监控检查点、自动化私有意图/跨工作证据/预算回执/待回答引用，终结失去上下文的等待，保留个人资料/共享资源/触发身份；通知待提交抑制/提交中未知；聊天清理同事务移除codexSessions/claudeSessions映射，不复用旧外部历史。；来源聊天清理同事务清除应用回执正文，保留防重放身份。 |
| `contact-deletion.ts` | 删除用例 | D4 副本 hash/所有权转移到资源清理日志、私有回执转最小 tombstone，外改保留；选中整批/标签完整成员按所见偏好版本校验，员工及全部记忆、专属资源/绑定/多标签关系和剩余群成员同事务删除，保留群历史；固定目录无符号链接校验、持久清理日志和重启续清，失败不复活已删除员工；员工删除同事务清除关联应用回执正文，已删除员工不因旧请求复活。 |
| `path.ts` | 路径前检 | 核实根目录范围与现存路径分段，保留两种用例各自的错误文案。 |

conversation-history.ts 在最终清理事务移除浏览器来源/作用域，动作仅保留 ID/hash/cleared 去重；浏览器实际存储清理未完成时恢复保持门禁。

conversation-history.ts 在最终事务以其它会话真实 Work 引用核对共享协作预算，原讨论清理不清零累计额度，旧调用只保留哈希身份且不能再次执行。
