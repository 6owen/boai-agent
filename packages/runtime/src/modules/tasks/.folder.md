# 任务读取

`read-model.ts` 拥有任务页与活动查询的输入、员工可见范围、持久游标和执行投影。看板和活动只读人工委派；通用任务分页可返回员工内部进度。对外操作的描述、结果类型和登记在 ../application/task-operations.ts；任务创建、修改和调度沿原入口执行。
