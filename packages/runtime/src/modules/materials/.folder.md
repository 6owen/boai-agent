聊天材料由 SQLite 管理身份与授权，原件仅在宿主私有 materials/ 下；不会进入群共享工作区。
新附件使用 deliveryScope=conversation，当前成员自动可见，新加入/退出按真实会话判定；持久 authorizedAgentIds 只是当时成员快照，不控制此模式。缺省 scope 的旧记录保留明确名单，不自动扩大授权；新附件不接受人为选员工或单独授权修改，离线成员不阻塞准备与发送。
TXT/Markdown 维持 128KiB/16000 字符及 text-v1；图片/任意文件使用 20MiB/binary-v1，不解码为正文。仅实际 PNG/JPEG/GIF/WebP/BMP/AVIF 字节可生成非持久 data 图片预览，HTML/SVG 和未知文件保持不执行的原件。
文件准备与事务提交分离，取消先挡提交再等待实际退出；重启先撤销未发送草稿再按 hash 清理，保留外部修改/原请求回执，不重新读取外部源或调用模型。
