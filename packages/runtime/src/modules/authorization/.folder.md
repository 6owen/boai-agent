# 宿主执行授权

- execution.ts 核对执行模式与当前操作，持有本次工具调用的异步授权范围。宿主、API 与本机适配器直接使用同一实现。
- command-grants.ts 管理旧配置允许记住的员工命令授权。员工配置变化或删除时按原集合与事务撤销。工作区目录、业务来源和插件授权仍由各自负责人核实。
