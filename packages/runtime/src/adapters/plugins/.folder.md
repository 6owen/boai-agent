# Runtime plugin host

- host.ts：插件租约、核源、公共事件投影与原生员工业务引擎。
- runner.ts：独立模块进程、请求/事件关联与退出。
- validation.ts：宿主与插件双向私有 DTO、事件与动作校验。
- 提供方实现和Node辅助已归 `@boai/runtime-plugins`，公共接口归 `@boai/runtime-plugin-sdk`。
