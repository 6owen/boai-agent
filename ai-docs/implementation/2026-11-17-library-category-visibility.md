# 资源库分类显隐（2026-11-17）

先创建[feature issue #154](https://github.com/6owen/boai-agent/issues/154)，再从origin/main独立worktree实施。

- “资源库”标题右侧增加显示分类按钮，使用共享DropdownMenuCheckboxItem控制技能、数据源、提示词、应用、助手；菜单内支持连续勾选，分类名称单行显示，至少保留一类。
- 默认全部显示，隐藏项保存到本机localStorage的`boai.library.hiddenCategories`。无效或全部隐藏的旧值恢复默认导航，不写任何资源、员工绑定或权限接口。
- 显隐同步作用于上方分类、下方已安装分组与该区域搜索；仅剩应用/助手时不显示无关的资源搜索/分组。恢复分类立即显示已有资源。
- 隐藏当前分类沿原GuardContext处理未保存草稿，再切换到第一个仍可见分类。来自其他页面的显式技能详情定位仍可打开，不修改保存的隐藏偏好；原数据源详情路径保持。

实际检查：7项组件回归覆盖默认、仅技能/数据源、重挂恢复、恢复提示词、草稿守卫、至少一类、无效偏好和隐藏技能外部定位；typecheck、UI lint/字体规则与完整build通过。

后台Chromium用真实资源库及应用完整样式、隔离只读目录验证：标题按钮在右侧，五类菜单正常，隐藏当前分类后回退，刷新页面保留仅技能/数据源，隐藏项不参与侧栏搜索，恢复后原提示词可找到，窄窗口正常。技能、数据源、提示词各1项夹具保持不变，所有API请求均为目录读取，无创建/修改/删除调用，页面错误0；截图已查看。首轮夹具重挂/菜单退出时机的失败日志与修正后结果一并保留。

未启动个人Electron或全量E2E，没有操作个人配置/资源、运行模型或重启安装版。新PR关联关闭Issue #154，并沿boai-dev-workflow检查通过后自动合并；云端检查与实际生效单独核对。
