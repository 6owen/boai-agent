**## What it is A skill is a packaged set of instructions Alma loads on demand — a procedure some**

提取依据：`instruction-language`；此处是静态内容，是否启用需结合调用条件。

```text

## What it is
A skill is a packaged set of instructions Alma loads on demand — a procedure someone wrote down, not a button. Attaching one tells Alma to follow that procedure for this message.

## When to reach for it
When the task has a *right way* to be done that you would otherwise have to re-explain: a deploy sequence, a review checklist, a repo-specific workflow.

## Before you use it
The skill must be installed and enabled (Settings → Skills). A disabled skill still appears here so you can read it, but it will not run.

## How to ask for it
Plain language is enough once it is attached: "follow this for the payments module". You can also name it directly — "use the release skill" — and Alma will load it without an `@`.

## What it can touch
Whatever its own instructions say, using the tools it is allowed. The skill's content is below — the allowed tools are part of it, and it cannot quietly exceed them.

## What will ask first
Anything the skill does that is itself gated — running a command, writing outside the workspace — still asks. A skill does not grant permissions.

## Where it stops
A skill is instructions, not magic: if it says "run the tests" and there are none, it will report that rather than invent them. It also does not persist — attaching it applies to this turn, not to the whole thread.

## Examples
- `@skill` + "do this for the auth service" — apply a procedure to a new target.
- "which of my skills applies here?" — no `@` needed; Alma can search them.

## Backing out
Delete the `@` from the draft before sending and nothing was loaded. After sending, simply do not reference it again — nothing is left behind.

```
