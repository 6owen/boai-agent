## 脱敏方式

- 配置键匹配凭据、身份字段；环境变量和请求头保留键名、替换值。
- 文本检查 token/私钥、认证 URL、邮箱/电话、主目录；USER.md 的名字与平台身份字段替换。
- SQLite 仅查询配置表；没有导出原始数据库或聊天表。专业 Agent prompt 从脱敏设置再单独汇总。
- 所有替换用 `[REDACTED:类型]` 标记；空值、数值开关、模型参数尽量保留。
- 保留导出范围和字段位置，检查已收集的敏感原值不再出现在输出中。规则脱敏不是对任意自然语言个人信息的形式化保证。

## 配置与默认值不要混用

缺失的本机文件不补写为默认文件。默认情绪、疲劳、旅行的规则和常量已在主分析与原代码中说明。特别是默认 emotion CLI 与对话计算不完全一致，旅行“七天”也主要是行为约定；请结合调用路径阅读。
