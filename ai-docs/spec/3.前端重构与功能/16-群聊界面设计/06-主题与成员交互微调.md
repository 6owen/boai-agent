# 主题与成员交互微调

- 消息头移除员工名称旁的职责描述，只保留姓名和时间。
- 正文由固定 15px 改为全局 `1rem`，当前为 13px；消息标题缩小到约 14px。字体、颜色继续跟随全局主题。
- 消息卡片直接复用 `soft-card` 的主题背景、边缘、高光、阴影与圆角，移除选中态灰底和独立 12px 圆角。
- 工具条复用与消息相同的 `soft-card`，内部使用原版 ghost 按钮；移除圆角清零、独立分割边框和 hover 颜色覆盖。外层按统一圆角裁切，避免悬停背景越界。短消息旁置、长消息角落与自己消息镜像规则保留。
- 姓名悬停或键盘聚焦变为主题主色并显示 @；点击绑定真实成员 ID、去重并聚焦 composer。已停用或已不在群中的员工不提供提及操作。
- 点击消息头像打开共享 Popover，展示姓名、职责、启用状态和实际绑定技能/知识；资料缺失沿用通讯录降级文案。不伪造在线状态或触发模型调用。

后续微调：

- 此前修正了已选提及按钮的 hover 颜色；按最新要求，该独立提及栏已移除，改为下述正文内标签。
- 工具条移除 @ 操作，保留表情、引用、复制和 Trace；提及通过姓名或 composer 入口完成。
- 消息头时间默认透明并保留占位，悬停消息或键盘焦点进入消息时显示，避免挤动姓名/正文。
- 表情选择和回应提交继续互斥，使用 Base UI 的 `focusableWhenDisabled` 保留焦点，局部取消 disabled 半透明效果，避免整组按钮闪淡以及焦点被转移到浮层容器。撤销回应后如焦点仍在该回应上，将焦点无滚动恢复至表情入口。仅在宿主成功回执后关闭浮层，失败仍显示错误。

最新 composer 调整：

- @ 候选确认、点击员工姓名或消息中的 @，均在输入正文当前光标处插入标签；不另设 composer 上方提及行，也没有标签删除按钮。
- 撤回此前的透明 textarea + 标签覆盖层：标签底色会挡住真实光标，视觉宽度也无法可靠支持系统按钮留白。群聊改用 Tiptap/ProseMirror 的实际行内原子节点，仅支持文字、换行和成员标签；单聊保留原生 textarea。
- 标签直接共用 `Button` 的 secondary / xs 皮肤，底色、圆角、边缘和留白均来自现有主题，不再使用自定义蓝底紧贴文字。光标与标签同层布局，可以位于标签之前或之后。
- 不再插入人为尾空格；在标签后按一次 Backspace，或在标签前按 Delete，整体移除标签与对应绑定。选中替换、剪切及撤销/重做由同一编辑模型处理；组合输入不误选或发送。
- 标签身份保存在草稿的范围元数据中，删除最后一个标签立即清除对应 mentionId；手输或粘贴字面 @ 不自动获得成员身份，同名员工按 ID 隔离。
- / 命令替换和普通编辑同步迁移标签范围；跨会话草稿继续由 Shell 保存。发送正文移除展示标签，成员 ID 继续走原 IPC，避免消息内重复 @；仅标签无正文仍沿用原来的不可发送规则。
- 单元测试直接覆盖实际编辑模型的标签前后位置、原子删除、选中替换、历史恢复与 Unicode/换行/同名身份；既有 BDD 步骤同步兼容实际行内输入及一次删除，**未执行 Electron BDD**。
