# 第二版群聊：首次实现与验收记录

本文件保留首轮结果。用户随后指出渐隐、输入框和普通问候引用问题；下文的固定标题/14px 输入框方案已撤回，最新行为和测试见 [修正记录](./04-渐隐输入与引用修正.md)。首轮视觉截图使用预置历史，遗漏了实际问候链路中的自动触发引用；下文的“视觉通过”不能作为该问题已覆盖的证据。

界面已按选定的第二版落地。**群聊视觉与专项验收通过；全量回归未通过。** 整套应用的 QA 结论为 `blocked`，不能把本次改造描述成所有测试全绿。

## 修改范围

- 群聊使用固定 64px 标题、真实成员数量与“任务与产物”直达入口。沿用原有菜单和右侧详情标签，打开详情不另建侧栏。
- 人与员工统一左对齐；正文 15px / 1.65，头像 32px。连续发言只隐藏重复头部，不合并消息或改变定位/Trace。系统消息使用中性标识。
- 引用显示真实作者和首行摘要。仅明确关联的文件内嵌到回复，歧义或旧记录仍可在会话文件列表找到。
- 审批对应实际请求、命令和工作目录；尚无公开回复的私有任务草稿，审批放在消息流末尾独立显示。允许/拒绝仍调用原有单次审批接口。
- 输入框使用 14px 圆角、细边框与小面积强调色，保留发送、停止、引用、点名和草稿。
- 任务详情按真实父子关系显示目标和负责人；依赖/接续/结果说明可展开，停止工作树仍可操作。只有状态和结果证据一致才显示“已交付”。
- 新增的 `group-chat.css` 复用全局语义 token，只作用于群聊及其任务详情。单聊保留原有右侧用户气泡、模型和权限菜单。没有修改调度、预算、权限或运行时持久化。

主要文件：`chat-view.tsx`、`conversation-header.tsx`、`composer-toolbar.tsx`、`activity-detail.tsx`；新增 `artifact-list.tsx`、`group-chat.ts` 和群聊样式。Header 与对应 `.folder.md` 已同步；没有顶级架构变动。
