# bobo会话删除状态误报

2026-10-22，状态：**修复已接线，受控竞态回归及隔离桌面删除路径通过**。用户最初要求先记录、后统一修改，随后授权开始执行五项目标；本轮已修改产品与回归测试源码，没有操作实际用户会话。

## 1. 现象与已知边界

用户删除“bobo agent”的会话时，偶发同时出现以下两条错误提示，随后会话仍成功删除：

> 组织结果暂不可核对：此会话清理尚未完成，请重试清空聊天记录

> 此会话清理尚未完成，请重试清空聊天记录

用户说明“有时候出现，有时候没有”，本次刚遇到一次。对用户而言，删除最终成功却先提示失败和重试，会造成操作是否完成的歧义；删除成功应有明确、正确的成功反馈。

证据边界：对话中的用户截图可确认两条提示同时可见；最终删除成功及偶发频率来自用户描述。截图未另行复制到仓库。本轮没有独立复现、读取用户聊天/数据库或核对当时运行进程；具体会话ID、触发时刻、单条/批量入口、删除时是否正选中该会话及请求顺序尚未确定。

这里记录的是删除会话，不是删除bobo员工。后续沿用原会话删除、清空聊天记录和员工删除的区别，不扩大数据清理范围。

## 3. 预期状态反馈

| 实际状态 | 用户应看到的结果 |
| --- | --- |
| 删除请求已受理、清理仍在进行 | 确认框保持“正在删除…”或原“正在清理…”等进行状态并锁定重复操作；属于这次正常清理的临时读取拒绝不弹失败或要求重试 |
| 原删除流程确认完成 | 从会话列表移除并按原规则离开已删除会话，统一通过Sonner提示一次“会话已删除”；不再出现该操作遗留的清理中错误 |
| 用户执行的是清空聊天记录 | 保留原会话，完成后提示一次“聊天记录已清空”，不能显示“会话已删除” |
| 真正清理失败 | 沿原恢复状态给出一次准确的失败反馈与可用重试入口，不显示成功；其他会话或独立操作的真实错误仍正常反馈 |
| 请求中断、结果尚不能确认 | 保留待核对/恢复状态，按原流程确认结果；不盲目重发删除，也不因会话暂时不可读而判定成功 |
| 删除已确认完成，但随后列表等刷新失败 | 区分已完成的删除与刷新故障，提供真实的刷新反馈；不把刷新失败解释为需要再次删除 |

一次逻辑操作只产生一次成功结果提示；请求返回与完成事件同时到达不能重复提示。批量删除只有全部目标确认完成才显示整体成功，部分完成沿原进度与重试语义，不能提前报全部成功。
