## 2. 已接入

- 设置侧栏新增“桌面活动与日报”；运行选项只保留后台运行、登录启动及 CLI。
- 活动记录器只展示记录开关，不展示记录状态文案、汇总统计、前台应用或最近采集时间；页头说明只保留“记录保存在本机”。
- 系统权限使用全局 Badge 显示状态；按实际平台与能力显示屏幕采集/键鼠权限操作，未适配的采集器显示暂不支持。页面活跃时每五秒刷新状态，离开页面停止轮询，返回应用刷新权限。
- 截图保存、全局键鼠事件监听独立开关，默认关闭。旧设置迁移保留原开关、频率、保留天数与排除列表，不自动启用新采集。
- 原生监听只保留按键/点击次数、时间、应用身份，不记录字符、键码、修饰键或坐标；同一分钟内连续的同应用计数合并保存，空闲间隔或跨分钟另起记录，避免逐秒堆积。关闭开关、运行服务退出、宿主退出或三十秒未续租停止监听。
- 配置接入采集最小间隔、心跳间隔、空闲阈值、输入停顿、画面变化轮询、JPEG 质量、本机 OCR 开关、Vision 语言及每 N 次采集识别一次。
- 安全输入、排除应用、登录窗口、可识别的隐私浏览窗口继续跳过；异步截图后重核前台应用，避免切换窗口后保存错误来源。
- JPEG 仅在开关启用时写入 `userData/v2/activity-records`，目录 0700、文件 0600；文件名由宿主生成 UUID，不接受任意模型路径。正文 OCR 跳过时不复用上一窗口文字。
- 按记录保留天数和 MB 配额删除最早的观察/输入事件，同时清理对应截图及依赖已删样本的分析、日报。清空与按日期删除沿确认入口执行。
- 最近活动从真实观察和事件计数组合，显示最近二十个片段；复用资源库技能使用的共享 ListRow，列表只显示应用和时间，点击 Dialog 查看该片段计数、分页原始观察和有效相关主题。原始记录不再在下方重复展示。
- 活动文字详情可查看已保存截图；截图读取仅对本人入口开放。设置页不提供日报分区或首发入口；既有聊天/技能的日报能力仍沿原 OCR 证据边界，不自动将截图发送给模型。
- 备份期间暂停采集并等待在途任务，复制来源仍存在的截图；备份副本的记录、截图保存和键鼠监听开关均关闭。恢复文字证据时若缺少对应图片，移除失效图片引用，不删除原文字。

## 3. 当前边界

- 当前原生采集适配器仍为 macOS 14 或更新系统；该适配器的键鼠监听需要辅助功能权限。UI 与共享能力合同不再将 OCR 等同于 macOS Vision；Windows/Linux 采集器、DS Flash 和飞桨 OCR 的实际调用尚未接入，不能将能力合同或降级显示称为这些后端已支持。
- 截图、键鼠监听和 OCR 能力分别报告。OCR 不可用或单次失败时，不复用历史文字；已有采集能力时仍保存本次真实应用/窗口以及明确启用的截图。整个平台尚无采集适配器时保留查看、查询、清理与日报入口，采集控件禁用并保留原设置。
- 截图输出目录当前是 BOAI 的受管目录，提供打开目录；没有任意目录迁移功能。
- 已接入保留天数、实际截图字节及活动数据配额清理，没有接入 Alma 的 warm/cold 分龄降画质重编码。
- 近期片段、原始观察、结构化分析与日报分别来自真实记录；开启监听本身不自动调用模型或生成分析。
- 目录状态、参数和卡片已接线，不以静态/受控检查代替真实桌面采集、真实 OCR 质量及长时间运行验收。
