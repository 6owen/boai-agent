## 2. 共享基础

| 原路径 | 唯一实现 | 应用处理 |
| --- | --- | --- |
| `src/shared/appearance/typography.ts` | `packages/tokens/src/typography.ts` | 原入口re-export，三组偏好/比例/范围保持 |
| `src/shared/appearance/index.ts`的纯配色部分 | `packages/tokens/src/theme.ts` | 主题插件、偏好、资产协议仍留宿主 |
| `src/renderer/styles/colors.css`的Soft常量 | `packages/tokens/src/surfaces.ts` | 原入口加载生成的基础CSS，保留离线字体/根排版 |
| `src/renderer/styles/tailwind.css`语义映射 | `packages/ui/src/theme.css` | 保留原Preflight，并纳入共享源码类名发现 |
| `src/renderer/components/ui/skin.css`的基础部分 | `packages/ui/src/skin.css` | 原位置导入共享皮肤，其后应用覆盖保持 |

`foundation.css`与`tokens.json`由同一TypeScript定义生成到忽略的`dist`，不手工维护；当前JSON是两种模式的CSS变量清单，不声称已经实现DTCG格式。

## 4. 当前入口

| 命令 | 用途 |
| --- | --- |
| `pnpm dev` | 原桌面开发入口，先准备共享包 |
| `pnpm dev:design` | 单独启动设计站，默认127.0.0.1:5190 |
| `pnpm build:design-packages` | 构建公共ESM、类型、基础CSS和变量JSON |
| `pnpm build:design` | 另构建静态网站与公开索引 |
| `pnpm check:design` | 实际tarball外部安装/类型/构建和CI Web浏览器检查；需要Chromium |

网站登记12页和10个组件组，示例源码直接取实际TSX文件；导航、搜索、Markdown和Agent索引沿公开catalog生成。构建的子路径都有独立HTML，不依赖伪成功的服务器兜底。全部运行结果归[03 §6](./03-实施计划与验收.md)。
