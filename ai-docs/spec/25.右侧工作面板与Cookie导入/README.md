# 右侧工作面板与 Cookie 导入

更新：2026-10-24。状态：历史研究资料，尚未实施，不列入当前架构待执行清单。

用户后续明确不需要DS Bot的产品/UI能力，本轮仅研究架构。下文保存此前截图研究和适配候选的原始背景，不作为当前实施指令；当前入口为 [架构补充调研](../../2026-10-24-DeepSeek-Bot架构补充调研.md)和 [第24组Mastra容量专题](../24.Mastra上下文容量与连续会话/README.md)。本次git cp归档这些资料，不恢复终端或引入面板/Cookie产品能力。

研究结论：值得借鉴 DSH 的面板生命周期、按需加载、终端屏幕恢复、外部应用探测，以及 DS Bot 的 Cookie 导入流程。BOAI 已有常驻详情标签、分页文件列表、独立浏览器和内部 PTY 基础，后续应在这些基础上接入。

本组遵循用户明确的方向：

- 业务、员工独立 workspace、会话、任务、文件来源与现有 BOAI 视觉样式保持。
- 右侧参考“开始 → 文件 / 终端”的组织方式，沿用 BOAI 的 Tabs、按钮、菜单、空态和布局组件。
- 文件面板借鉴路径栏、刷新和“外部打开”分体按钮；保留附件、成果、知识资料及来源定位。
- 研究重新引入可交互终端，保留网页预览和员工原有命令执行能力。
- 浏览器继续使用 BOAI 的独立窗口。只借鉴 Cookie 导入，不迁入右侧面板，不改为每员工一套登录分区。
- [第24组 Mastra上下文容量与连续会话](../24.Mastra上下文容量与连续会话/README.md)仍是独立专题，范围没有扩大到 Codex 或其他 Agent。
