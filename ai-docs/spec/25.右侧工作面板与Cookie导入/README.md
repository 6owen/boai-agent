# 右侧工作面板与 Cookie 导入

更新：2026-10-25。状态：用户已明确要求在新 worktree 实现工作区文件浏览、终端和现有独立浏览器的小型 Cookie 导入功能。实现和实际验证统一见 [02 §9](./02-BOAI适配方案与验收.md#9-唯一实际进度)。

2026-10-24 的“仅架构调研、不实施 UI”是此前阶段决定；本次明确指令启动这三项，不扩大到 DS Bot 的其他产品能力。当前 BOAI 样式、员工独立 workspace、业务与独立浏览器布局保持。

研究结论：值得借鉴 DSH 的面板生命周期、按需加载、终端屏幕恢复、外部应用探测，以及 DS Bot 的 Cookie 导入流程。BOAI 已有常驻详情标签、分页文件列表、独立浏览器和内部 PTY 基础，后续应在这些基础上接入。

本组遵循用户明确的方向：

- 业务、员工独立 workspace、会话、任务、文件来源与现有 BOAI 视觉样式保持。
- 右侧参考“开始 → 文件 / 终端”的组织方式，沿用 BOAI 的 Tabs、按钮、菜单、空态和布局组件。
- 工作区新增真实目录浏览、路径栏、刷新和外部应用菜单；原会话附件、成果、知识资料及来源定位保留。
- 重新引入用户操作的交互终端，保留网页预览和员工原有命令执行能力。
- 浏览器继续使用 BOAI 的独立窗口。保留 Netscape/JSON 文件导入，本轮追加本机浏览器profile列表和选中来源导入，不迁入右侧面板，不改为每员工一套登录分区。
- [第24组 Mastra上下文容量与连续会话](../24.Mastra上下文容量与连续会话/README.md)仍是独立专题，范围没有扩大到 Codex 或其他 Agent。
