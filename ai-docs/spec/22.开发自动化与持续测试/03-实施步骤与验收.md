# 实施步骤与验收

日期：2026-10-20。用户当前要求“先落实文档，后面统一修改”。本轮没有产品代码、测试脚本、CI配置、远程仓库或个人画图工具变更。

## 1. 依赖顺序

```mermaid
flowchart LR
  S1[参考与方案] --> S2[当前版本基线]
  S2 --> S3[自动开发到PR]
  S3 --> S4[开发画板接入]
  S4 --> S5[设计到代码协作]
  S5 --> S6[持续回归与更新检查]
```

S2开始建立持续测试基础；S4/S5在开发侧建立画板与Codex协作，再把实际BOAI功能纳入原产品回归；S6接入日常更新与发布。每个需要设计的任务按“画板设计→Codex实现→产品验证”操作，六阶段不表示设计必须晚于该任务的编码。此前S4/S5的BOAI内嵌宿主与画板任务已撤销。

个人发布与升级按[04](./04-macOS本机发布与升级方案.md)补充：S2可准备同SHA打包与产物验证，S6完成Tag/Release及本机升级闭环。没有Apple开发者证书不阻止先建立个人发布流程；标准macOS自动更新另待签名配置和实际验证。
