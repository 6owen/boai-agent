# 设置中的快捷键：设计到代码验收任务

2026-10-22当前产品增量合同见[第3组22：快捷键启停与自动保存](../3.前端重构与功能/22-快捷键启停与自动保存.md)：四项支持开关及组合键修改，点击外部自动保存，不设保存按钮；当前仅文档。第4节只读限制属于首版冻结，不再限制后续新修订；原输入、设计原件和五场验收历史不追改。接续规则见第6节。

2026-10-20历史登记：用户确认当时没有其他待开发功能，授权后续以此建立验收任务；该登记轮尚未修改快捷键或设置页面。此后只读首版已进入源码，实际历史结果继续归本组03。

## 1. 需求与边界

在BOAI设置中增加快捷键入口，覆盖Open Search、切换侧边栏、后退和前进。按macOS实际使用及现有键盘行为确定默认组合、展示和编辑方式；设计任务先核对当前实现，再给出具体可审查方案。复用原搜索、面板显隐和历史导航动作，不复制一套搜索/导航状态，不改变员工唯一主单聊。

画板位于仓库`ai-docs/design/`，由Codex与外部Excalidraw编辑，随后实现真实BOAI页面。画板不进入BOAI软件。任务由开发控制器领取、在任务专属worktree中开发，不能直接在原main目录修改。

## 2. 验收要求

| 编号 | 验收 |

| KS03 | 键盘实际触发与原按钮结果一致，保留聊天草稿、当前会话、滚动/焦点及原有快捷键边界；普通输入和组合输入不被误消费 |

该任务用于跑通本组开发/设计流程；它不使自动化控制器、CI、发布或升级等其余目标缩小为仅完成一个快捷键页面。


## 4. 源码核对后的首版冻结

本节记录当时的源码和冻结输入，不描述2026-10-22的新实施范围；只读首版已有四种实际快捷键，后续编辑合同见第6节。

当前AppShell只有Escape详情关闭处理；标题栏已有搜索Dialog、三页列表显隐和受草稿守卫的前后历史，直接复用这些动作。首版设置页只展示实际默认组合，不开放编辑，不增加保存配置/IPC：macOS `⌘ K`为Open Search / 全局搜索、`⌘ B`切换当前会话/通讯录/定时任务列表、`⌘ [`后退、`⌘ ]`前进；其他平台以Ctrl作为主修饰键。暂不实现可编辑绑定，因此KS04条件不触发。

普通输入/富文本/选择控件保留自身快捷键，应用快捷键不截获；组合输入、重复按键、已有处理、Alt/Shift附加修饰、打开的Dialog/菜单/Popover均不触发应用动作。无前后历史或当前页面不支持列表开关时不更改状态。按钮与按键共用动作、同一历史及原草稿守卫，不另建导航状态。

冻结验收源码为`tests/e2e/features/keyboard-shortcuts.feature`及对应steps：设置四组合、搜索/列表与草稿、前后历史及边界、编辑/IME/弹层四场。均使用隔离真实Electron、离线群聊历史并断言零模型请求；开发任务的允许路径不包含这两文件或已有UI基线。新页面视觉基线及受影响设置导航基线仍须实现后单独采集/审阅，不把四场行为通过代替KS05完整验收。画板原件/hash保持，实际组合由本节补充冻结；原生Codex MCP超时仍归03，不冒充该项已通过。


## 5. 关闭的自定义选择控件回归增量

v4独立审查指出普通select之外的真实Base UI Select触发器，在弹层关闭/已聚焦时也须保留自己的组合键。原四场不修改、不用旧结果冒充新覆盖，追加第五场“关闭的自定义选择框保留自己的按键”：打开实际外观页，确认真实Select触发器可见/聚焦且aria-expanded=false、无列表弹层；分别按四组合，核对没有搜索Dialog、页面/外观标题仍在原处，最终模型请求仍为0。后续需在原有缺陷候选和修正候选分别串行执行红/绿对照；此处只登记测试，尚未完成该GUI对照。

新任务修订须将这第五个完整spec名称加入report.requiredTests，禁止只按旧四场报告忽略新失败。v4的原输入/四场及模型原件保持，追加测试不追改其成绩或最终审批状态。
