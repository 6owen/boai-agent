# T3 正式狼人杀实施合同（已撤销）

**当前状态：用户要求正常对话并明确撤销这轮 T3。专用游戏面板、固定六人规则、代码主持、局内私聊接口、后台接入及新增游戏测试/评估入口已删除；T1/T2、通讯录和现有聊天数据保留。以下内容是撤销前的历史记录，不表示当前产品能力，也不得据此重新实现。**

用户已明确回复“好，开始正式实现 T3”。本合同冻结首版产品规则 `wg-v1`，替代 06 中待定人数/无女巫历史设想；不声称它是所有线下狼人杀变体的统一规则。

## 1. 六人局与代码主持

用户从当前群选择六名已启用、配置 API 模型的员工；主持人是代码驱动的产品角色，无第七次主持模型调用、不新增永久员工。其余群成员为观察者，不自动参与普通群协作。发牌采用随机 256 位种子和 SHA-256 确定性洗牌，可从局记录复算，牌组为 2 狼人、1 女巫、1 预言家、2 村民。员工 ID、工作区、配置和长期记忆不因牌面改变。

发牌后暂停，用户核对私密通知后点击继续。每夜使用夜初存活快照：两位存活狼人按座位各讨论一次，再各交一张刀票；若平票，宿主按同局种子和天数选择目标。狼人只可刀存活非狼。存活预言家查验一个存活非自己目标，只有他获得是否狼人结果。女巫各一瓶解药/毒药，每夜最多一瓶，首夜可自救，之后不可自救；有解药时才获得当夜刀口。解药只能救刀口，毒药可毒任一夜初存活玩家（包括自己）。不用药须明确 `none`。所有夜间行动结束后同时结算死亡，已中刀的能力角色仍完成当夜选择。公告只说出局者，不揭示原因/角色；无遗言。

白天存活者按座位各发言一次，再提交投票；可弃票，不可投自己。全部票收齐后公布票表。最高票平票只对候选复投一次，再平票则无人出局。狼全灭好人胜；狼数不少于好人数狼人胜。结束后公开牌面，并给本机用户查看种子、逐动作、夜间讨论和查验复盘（不发给其他局模型）。玩家可在公开发言中策略性自述身份或撒谎，代码不会因此改变真角色。

## 2. 当前局私密视角

权威 `GameSession` 保存在 SQLite，玩家模型只获得单独的 `GamePlayerView`：自己的角色、公开座位/生死、最近完整公开事件、自己局内私聊、对应角色获准信息、自己最近12次非发言选择、当前合法目标与阶段身份。不传全体角色表、随机种子、观察者 DTO、其他人的私聊、整局动作账本或配置。狼人额外得到同伴和当夜狼队讨论；预言家得到自己的累计查验；女巫得到剩余药品与获准刀口。宿主进行阶段、玩家、存活、请求、版本、药品、目标校验，模型仅提出选择。

本机用户通过独立观察 DTO 查看每位玩家的身份通知；这份本机观察数据不作为模型输入。群公共消息由宿主打 `gameSessionId` 标记，只承载公开游戏事件，普通聊天模型和统一记忆来源排除此标记消息。私密游戏数据只保存在局记录，不进入群公共消息、员工记忆文件、工具/技能、工作区、普通协作或自动化输入。

首版游戏有意不召回普通统一记忆，也不把游戏经验自动写回永久人格。现有 T2 私聊/群聊连续记忆行为保留；正式游戏中，使用面板的“本局私聊”，目标仍是同一 `agentId`。普通员工私聊不会隐式取得游戏归属。私聊是用户建议或角色陈述，不是重新发牌；“你现在是狼人”不能覆盖女巫牌面。发送会保存消息、递增视角版本并暂停；旧模型回复不能提交，实际退出后点击继续，新决策获得该玩家自己的消息。死亡玩家不接受影响当前局的私聊或行动；首版不提供采访模式。

## 3. 事务、限额与恢复

每个群只允许一个未结束局。创建/控制/私聊使用稳定 `requestId` 和语义指纹，重交不重复发牌/消息；同 ID 不同请求拒绝。动作绑定局、玩家、阶段版本、视角版本与唯一调用回执。动作、回合结算、公开消息和群预览同 SQLite 写事务发布；失联后核对原回执，不重放已接受动作。

每局最多 120 次调用、400000 已知 token、30 分钟绝对期限和八天；每调用最长 45 秒，输出最多 900 token，完整输入 JSON 最多 20000 字符，单次预留 24000 token。预留在调用前事务完成，SDK 重试关闭；模型收到的 schema 只列当前视角合法动作。一个决策最多一次有界格式修复：仅已收到的截断/结构错误且用量已知、视角未变、预算/期限允许时，另行事务预留唯一新调用并重新判断同一视角；不重放已接受动作。第二次格式失败、网络/认证/取消/未知用量立即暂停。收到真实输入/输出用量才可记为已知，取消后已有回执仍结算；未知值不作零，未知/额度/期限阻止继续，只可结束复盘。若八天仍无胜者则暂停并提示结束。共享模型连接容量仍为六，取消/暂停在执行器实际退出前不释放容量，也不开始下一调用。

用户暂停、发送私聊、配置改变、失败、超时、预算耗尽或重启均停止自动推进；不替玩家弃票、不当作正常完成。当前局成员/群设置冻结；员工/模型修改使旧决策失效，版本不再相符时需要结束重开。重启只核对已提交动作/回执，不调用模型、重发动作或自动继续。已结束局可复盘，并可明确开始新局；新局种子/私聊/角色独立。备份需游戏执行器退出，恢复备份同样暂停。清空群历史先停并等待实际退出，再同步清除局/调用/请求/公开消息，不删除员工或其工作区基础配置。
