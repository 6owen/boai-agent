用户已确认：在通讯录内置“团队创建助手”。用户描述目的，系统生成多名拥有独立身份和 workspace 的员工，可同时建群；这些员工以后既能私聊，也能在群内互动。写作是首个工作场景，狼人杀是后续角色互动场景。

本组是下一阶段开发主入口。[第 8 组](../8.Agent-IM产品完善/README.md)保留基础能力完善清单和设计参考，不要求先完成其全部 P0。团队生成、编辑和批量创建合同统一在本组维护。

## 第一版要交付什么

> 通讯录 → 一句话描述 → 内置助手生成方案 → 用户调整 → 创建员工与可选群聊 → 用户开始聊天。

- 内置助手是系统能力，不是通讯录中的普通员工；不需要用户先创建它。
- 生成真实可编辑的成员配置；创建后复用既有员工、私聊和群聊通路。
- 每名成员拥有独立 ID 和工作区；私聊与群聊引用同一名员工。
- 模型只设计方案；程序负责校验、权限、文件初始化、事务提交和结果回执。
- 创建不会自动发欢迎词、运行示例任务或开启游戏。
- 初版沿用现有“员工基础资料 + 当前会话记忆”。完整跨会话连续记忆属于 T2。

## 阶段边界

| 阶段 | 交付 | 不作为本阶段前置条件 | 状态 |
| --- | --- | --- | --- |
| T1 | 一句话创建、可编辑预览、批量员工、可选建群、幂等和故障恢复 | 新附件格式、产物验收、统一收件箱、Mastra Memory 迁移、游戏引擎 | 见 08 |
| T2 | 员工统一记忆、默认连续经历、按需召回、生命周期与管理界面 | 全员共享记忆、无视来源/范围的跨群召回、游戏规则引擎 | 实现与逐片验收见 08/第 2 组 26，范围外回归失败可见 |
| T3 | 狼人杀固定规则、玩家视角、主持与回合控制、局内私聊及复盘 | 一句话生成任意游戏规则引擎 | 专用实现已撤销，当前保留正常对话 |

“第一版完成”只表示 T1 全部验收通过。不得据此宣称连续记忆或正式狼人杀已可用。
