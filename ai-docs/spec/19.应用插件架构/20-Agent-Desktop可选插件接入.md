# Agent Desktop 可选插件接入

用户要求先通过BOAI插件系统接入agent-desktop，自己调用评价效果，满意后再考虑移除旧computer use。此轮只新增可选提供方；不迁移或删除原MCP，不修改已绑定的旧技能。

## 使用

1. 在包含此改动的BOAI中打开「设置 → 插件」，搜索「Agent Desktop」并开启，也可选择「电脑操作」分类。
2. 点击配置按钮，执行「检查连接」。这只检查程序/系统权限，不操作应用、不触发系统授权弹窗。按系统返回的缺失权限，在macOS系统设置中为实际启动BOAI的应用授权。
3. 默认保持「允许前台操作」关闭；需要真实快捷键、拖拽或双击时再开启。
4. 对员工明确说：“只使用 Agent Desktop 插件，读取 Finder 当前窗口，列出你能操作的控件，先不要点击。”然后逐步试输入、菜单、截图。模型应先发现inspect_desktop_plugin，再通过call_desktop_plugin读取上游自带desktop/platform技能，使用快照中的真实引用。

## 接线

应用清单新增默认关闭的desktop-tools贡献`boai.desktop.agent-desktop`，沿原插件启停文件与CAS配置。独立包`packages/desktop-plugin`直接固定依赖`agent-desktop@1.1.0`，不维护OS自动化实现。官方npm包内本机二进制与helper复制至版本化私有目录；首版不要求用户安装全局CLI。

API/Mastra和原生员工共用inspect_desktop_plugin/call_desktop_plugin，原生Agent循环、会话、模型和工具保持原生。员工只读权限禁止写操作，请求审批模式沿已有审批卡。未配置整体权限的旧员工写入也须明确批准。插件开关不自动修改员工权限。

桌面调用统一排队，同一员工/会话复用引用范围，其他员工和会话不会误用该范围。引用范围不代表独立桌面；多个员工仍然操作同一台电脑。配置变化/停用拒绝新调用，取消等待实际进程退出；已经发出的输入不能撤回，未知结果必须先观察，不能换旧MCP重做。截图直接转换为已有MCP图片内容通道；调用参数不写入持久Trace。

上游v1.0.2曾存在空闲常驻命令host；本轮发现已发布v1.1.0后固定使用正式新版，采用每命令独立进程，不依赖上游内部host协议。不能用旧版文档推断新版返回字段；固定发布与自带技能配套。
