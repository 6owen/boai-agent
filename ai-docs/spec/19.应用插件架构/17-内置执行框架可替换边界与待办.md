# 内置执行框架可替换边界与待办

## 1. 决策与状态

状态：**待做，未启动实施。** 2026-10-28用户明确，这项工作涉及较多配套能力，现在不用做。当前内置执行路径继续使用Mastra。

目标是未来允许BOAI内置员工的执行能力由Mastra、Pi或DeepSeek Harness等框架承载。它与[本机Agent插件](./16-本机Agent插件与数字员工产品边界.md)相互独立：后者调用已绑定的完整Agent，属于已实现产品模式；前者需要适配BOAI依赖的框架能力。

支持OpenAI风格模型API只说明模型请求有可复用的接口，不代表Memory、Workspace、会话、工具、调度或追踪可以直接互换。同一个Pi/DSH可以分别作为完整本机Agent或内置框架候选，二者不混用接入与验收结论。

核对基线：`f0ea0d87`，2026-10-28。以下是源码清单，不是新迁移结果。

| 能力 | 当前落点 | 后续需要处理的边界 |
| --- | --- | --- |
| 执行入口 | [AgentEngine / EngineContext](../../../packages/runtime/src/contracts.ts)、[MastraEngine](../../../packages/runtime/src/adapters/mastra/engine.ts) | 已有run、判断、汇报、记忆提取、行为和自动化草稿等入口；只替换run不能覆盖内置能力 |

现有Runtime API v2面向本机运行时插件，AgentEngine是内置引擎的既有入口。未来可以共用消息、工具或事件类型，但不预设必须合并成一个万能接口，也不在本轮新增网络协议。

## 3. 未来职责划分

| BOAI保有的产品语义 | 按框架适配的执行机制 |
| --- | --- |
| 数字员工、会话、消息、Work与成果身份 | 引擎对象、模型循环、内部会话和消息转换 |
| 记忆原件、来源、授权、纠正与删除 | 召回装配、上下文窗口、压缩及派生缓存 |
| 目录归属、材料与成果、访问及发布规则 | Workspace包装、工具注册、参数与结果格式 |
| 业务工具的行为、权限和持久回执 | 框架调用工具的协议、事件和等待方式 |
| 调度规则、渠道来源、预算与运行状态 | 调度库、渠道库、追踪适配器和真实用量采集 |

内部框架拥有其执行循环；BOAI提供产品服务和明确约束。沿已有边界逐项解耦，避免再造一套通用Agent内核。

## 4. 后续启动时的待办

以下仅为后续范围，不构成本轮执行任务：

1. 明确是替换内置执行循环，还是彻底移除Mastra依赖；分别列出保留组件。
2. 选择一个固定版本候选，核对实际SDK、生命周期、工具、上下文、用量及取消语义；不能只比较OpenAI兼容请求。
3. 盘点现有AgentEngine入口与产品工具，将必要业务行为同框架封装分开；优先复用原服务与回执。
4. 让第二个实现完成聊天、产品工具、等待用户、停止、续聊、文件交付的代表链路，再验证行为、记忆、群协作和自动化。
5. 分别核对质量、成本、延迟、故障恢复和兼容迁移；保留旧引擎与回退路径，不以工程测试代替真实业务验收。

切换引擎不得假定内部session可以跨框架恢复。可从仍获准的产品历史建立新会话；进行中的运行、已执行副作用与结果未知请求不得通过换引擎自动重放。
