## 1. 产品边界

| 对象 | 入口 | 职责 |
| --- | --- | --- |
| 网页检索 | 设置 → 配置 → 网页检索 | 内置浏览器、预置服务配置、凭据、测试、启停、移除及全局默认 |
| 员工网页检索能力 | 通讯录 → 对应员工 → 网页检索 | 跟随全局默认、浏览器、指定服务或关闭；独立的可用服务范围 |
| 业务数据源 | 资源库 → 数据源；员工数据源 Card | MCP、API、本地文件夹连接和原员工绑定；保留业务读取/写入 |
| 应用插件 | 设置 → 配置 → 插件 | 同一插件目录中的预览、主题、网页检索、Agent 运行时管理 |

MCP/API 是传输方式。使用 MCP 的检索服务仍属于网页检索能力，不能仅因协议相同就要求用户去数据源创建、绑定。网页检索可复用已验证的认证、连接、请求与取消实现，业务配置和员工授权分别存储。

## 2. 内置浏览器与检索插件

```text
设置 / 网页检索 → 服务配置与凭据 → 员工独立网页检索配置
                                            ↓
                               API / 本机公共检索工具桥
                                            ↓
                   BOAI 浏览器，或检索插件的 API / MCP 工具
```

BOAI 浏览器继续承担页面访问、登录状态、动态网页及交互，默认检索方式为浏览器。远程搜索/抓取不共享浏览器登录状态。员工原生 Agent 的搜索、MCP、插件及权限配置保持原生；关闭 BOAI 网页检索仅控制 BOAI 提供的检索服务，不删除原生工具或关闭其他浏览器任务能力。

当前仅 DeepSeek 沿现有 application plugin 清单增加 `web-search` 贡献，不建另一插件平台。插件启用与服务启用分别检查；停用插件阻止新请求，停用后的迟到结果不能作为成功交付。重新启用沿原服务身份、配置和凭据恢复。当前为受审内置插件，第三方任意安装/市场另期。

| 提供方 | 传输与当前实现 | 依据 |
| --- | --- | --- |
| DeepSeek | 固定 Search/Fetch HTTP POST，Bearer Key | [指南](https://api-docs.deepseek.com/zh-cn/guides/search/)、[Search](https://api-docs.deepseek.com/zh-cn/api/search/)、[Fetch](https://api-docs.deepseek.com/zh-cn/api/fetch/) |

Jina、Tavily、Exa 暂不进入设置页、员工可选服务或内置插件目录。已有适配、历史记录和已保存配置保留兼容；本次不删除用户数据或修改已有运行配置。重新开放另行确认范围。

DeepSeek 搜索与员工所用模型无关，不必选择 DeepSeek 模型。搜索密钥在检索页面独立管理，可使用用户自己的相应服务密钥。保存和读取配置不自动联网；明确测试时 DeepSeek 执行一次测试查询。测试文案区分连接、实际查询和正文，不互相冒充。

## 3. 员工选择与调用

### 3.1 独立授权

配置存于 `webSearchServices`，全局默认存于 `webSearchSettings`；员工 `webSearch` 保存首选与可选 `allowedServiceIds`。无显式范围时可使用全局启用服务，保存了范围时只使用范围内的服务；bobo 同样遵守自己的网页检索配置。该能力不读取 `sourceIds` 决定授权。

API 和本机公共产品桥都提供 `inspect_web_search` / `call_web_search`；宿主核对当前员工、执行阶段、服务身份/版本、插件状态、当前选择和取消状态。先按需读取工具 schema，再调用经过验证的只读搜索/正文操作。底层传输继续复用 SourceService，但使用独立集合与授权入口；历史 `select_web_search` 的 `mode:source/sourceId` 参数只表示检索服务身份，不能据此授予业务数据源权限。

### 3.2 选择与失效

| 配置或本轮要求 | 行为 |
| --- | --- |
| 跟随全局默认 | 使用全局已保存选择，初始为 BOAI 浏览器；全局修改对后续执行生效 |
| 指定服务 | 优先用该服务搜索或读取，页面交互继续沿浏览器 |
| BOAI 浏览器 | 使用已有浏览器路径；本轮明确选择另一获准服务可覆盖本轮 |
| 关闭网页检索 | 不向员工提供 BOAI 搜索服务工具；原生能力与其他浏览器任务能力保持 |
| 本轮明确指定服务 | 引用当前用户原文，固定服务 ID/revision；不修改员工长期配置、不扩权 |
| 首选服务停用/删除/超出可用范围 | 配置保留不可用状态；常规回退显示为浏览器并如实说明；不静默切换到另一付费服务 |
| 从员工可用范围移除其首选 | 同一员工草稿重置为跟随全局默认，保存后生效 |

同名服务以稳定 ID 区分，含糊请求先澄清。网页、历史或同事内容不能触发本轮工具选择。新增服务不夺取已保存默认。业务数据源绑定变化不重置网页检索首选。

### 3.3 普通问答与多员工

普通问答可搜索和读取网页，不因搜索制造文件 Work。私有判断、记忆维护、已结束运行和组织管理阶段不能借此外呼。群聊、渠道和自动化均按实际执行员工配置取工具，不经 bobo 代调用扩权。

## 4. 凭据、权限与生命周期

凭据由原宿主 vault 保存与注入，只通过专用桌面编辑接口回填；默认掩码，可显隐，清空即删除。模型目录、工具参数、配置摘要和日志不得含密钥。只读 POST 不是业务写入；未知工具/schema 仍拒绝进入检索能力。查询不自动附带私有聊天或知识资料。

服务编辑、停用、删除和换密钥使使用旧版本的调用失效；员工撤权、取消和退出后不发布迟到结果、不重放未知请求。插件配置损坏时仅禁用检索插件，不阻断无关聊天。全局默认变化不会取消无关进行中的任务。

产品备份包含服务配置和默认选择，但清除凭据引用、关闭服务、提升版本；恢复后需重新配置凭据。目录权限和知识资料仍由各自模块负责，本机 Agent 保留用户原生能力/权限配置。
