# 文件浏览器插件与目录入口

## 用户目标

1. 员工配置资料页的“发消息”“高级配置”旁新增“工作区”，打开统一右侧面板，浏览该员工的完整受管workspace。
2. 会话“开始”中的原工作区文件入口改为“授权目录”。无授权目录时隐藏；群聊按所选员工自己的授权展示，不能合并其他成员的权限。
3. 右侧为可展开文件树与文件预览，多授权目录可切换；复用全局右侧容器、标签及视觉主题。
4. 实现在独立官方插件包，沿现有插件设置启停；停用不改员工/会话/业务文件。默认启用以承接原目录浏览功能，可明确停用。
5. 本次不改变任务工作目录、输出路径、Mastra或本机Agent的执行位置，也不把任意目录文件登记成已发布成果。

## 目录关系与实际接线

- 员工入口：`v2/agents/<employeeId>/workspace`，包含员工系统文件、记忆与会话子目录。
- 会话入口：员工当前已保存的`directoryGrants`。只有精确命中的授权根才可打开；只读授权可以浏览和预览。授权目录不是默认执行目录。
- 普通任务仍使用原`workingDirectory`、`sessions/<conversationId>/work`或`runs/<runId>`。正式成果仍归`v2/workspaces/<conversationId>/artifacts`；原聊天“文件”列表保持附件/正式成果的业务含义。
- 用户终端保持原创建、cwd、进程与关闭合同，不因文件浏览器停用失效。

`getWorkspaceRoot`继续作为私有runtime请求：员工/会话存在、成员关系与关闭状态复核保持。可选`directory`只允许员工已保存的精确授权根；根被替换为指向其他位置的链接会拒绝。前端选择不增加授权。

`listWorkspaceFiles`、`previewWorkspaceFile`、`openWorkspacePath`由可信桌面主窗口进入插件宿主；每次验证插件启用与当前目录范围，异步读取返回前再次复核。相对路径、符号链接、普通文件类型、字节上限与分页沿宿主限制。

## 官方包与源码来源

包：`packages/file-explorer-plugin`，插件ID：`boai.file-explorer`，贡献类型：`file-explorer`。

来源：[Lanzgale/dsh-file-browser](https://github.com/Lanzgale/dsh-file-browser/tree/4c1fa36d479833e1df36f4cf2cfde98c47887858)，MIT，固定提交`4c1fa36d479833e1df36f4cf2cfde98c47887858`。迁用`lib/client.js`的展开集合/目录缓存、递归树投影与文件后缀拆分；保留原作者和修改者许可。迁入文件及改动说明见包内`source-manifest.json`。

BOAI适配：类型化IPC、目录授权、虚拟行和键盘导航、共享按钮/颜色、原文本/Markdown/Shiki/图片/PDF/Office预览。DSH的全局DOM注入、宿主读写API、编辑器和Shell打开逻辑不迁入。包内预览是只读，外部打开继续使用宿主已有应用列表。

- 树按目录懒加载，目录在前；保留展开状态、隐藏文件开关及分页。
- 点击文件在同一面板预览；HTML/SVG只显示源码，不执行。
- 隐藏标签停止读取并释放预览正文；回来后重新核对源。不同员工/授权根隔离状态。
- 停用插件卸载文件浏览视图，关闭相关标签并隐藏两类入口；终端与聊天交付文件列表保持。
- 移除授权或群成员会使对应浏览范围失效，不删除业务文件。
