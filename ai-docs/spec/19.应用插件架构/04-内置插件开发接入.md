# 内置插件开发接入

本文描述当前已实现的预览/主题插件。新增Agent运行时贡献的候选协议、独立包及开发路径另见[05](./05-Agent运行时插件协议与接入架构.md)和[06](./06-Agent运行时插件实施计划与验收.md)；当前v1清单不能直接加载该设计示例，不把React预览接口复用为Agent执行接口。

本轮插件随BOAI构建发布。新增能力改动贡献目录与对应宿主装配；员工聊天、成果页和附件页不应再增加格式判断。代码仍在应用renderer内运行，清单不是权限凭据。

## 1. 共同清单和配置

`src/shared/plugins/types.ts`定义稳定`id`、`version`、`apiVersion`、名称/说明及`preview`或`theme`贡献。`catalog.ts`校验身份唯一、贡献类型唯一、有界格式与颜色后冻结目录。`apiVersion`必须等于宿主当前版本才可启用；应用版本和插件版本分别记录，不能用名称识别插件。

`PluginSettingsStore`只接受已知插件id、布尔`enabled`、所见`expectedRevision`。宿主保存到应用数据根的`application-plugins.json`，采用串行CAS和同目录临时文件rename；只在保存后广播。renderer启动先读首帧快照、订阅事件，再回读确认。失联只读核对，不重复写入。未知禁用id保留供后续版本；损坏/未来配置原件保留、管理只读、插件停止新激活。

启停偏好是本机应用配置，不进入业务备份；备份恢复不替换此设备的插件偏好。原文件、Work、权限、来源hash和副作用回执都由核心维护。

## 2. 新增预览

1. 在共享目录加入声明，例如专门展示宿主已经识别为`text`的`.note`文件：

```ts
{
  id: 'boai.preview.note', version: '1.0.0', apiVersion: 1,
  name: 'Note 预览', description: '展示已核验的 Note 文本。',
  contributions: [{ type: 'preview', kinds: ['text'], extensions: ['note'] }],
}
```

2. 在`common/file-preview/plugins/builtins.tsx`加入受审装配：

```ts
{
  manifest: previewManifest('boai.preview.note'),
  load: () => import('./note'),
}
```

3. `note.tsx`导出默认组件，参数类型为`PreviewRendererProps`。只读`content`、`name`和可选行/Markdown视图；共享标题和文件操作由宿主放在加载/异常边界之外。扩展名只帮助从同一种**已核源内容类型**选择provider，不能把不支持/超限的文件重新解释为可读内容。

明确扩展名优先于同kind通用项，相同条件按稳定id排序。不要为了优先级改动成果/附件页。不新增动态路径、远程模块或任意文件读取。真正新增宿主无法读取的格式，需要另行设计核心有界读取协议，不能靠清单绕过。

生命周期为“可用→实际视图打开→关闭/隐藏释放”。`usePreviewRegistry`把配置和`PluginUsage`接入注册表；组件打开固定provider，运行中启停只改变下次打开的选择。正文不得保存在插件全局单例。`useEffect`清理自己的订阅、worker和对象URL；关闭后异步完成不得重新显示旧文档。模块代码可复用缓存，正文和阅读状态必须属于独立视图。

异常边界记录插件id和`viewer-failed`类别，并保留宿主文件操作与其他预览。查看器内部自行捕获的异步加载/解析失败不会到达React异常边界，必须在显示局部错误时调用可选`onPreviewError()`；PDF、Office和图片已接入。它只表达本次预览失败，不传文件内容、路径、URL或异常原文，也不表示插件代码必然有缺陷。宿主提供稳定回调，避免后台状态更新触发重新加载；查看器仍须按当前来源和取消状态丢弃迟到结果。主动取消、隐藏/卸载、文件超限和不支持格式不记故障。渲染异常/惰性加载拒绝有局部回退；未接回调的事件错误、死循环、OOM不具有跨进程隔离保证。

## 3. 新增主题

在共享清单加入`theme`贡献，或在`theme-contributions.ts`登记同一主题包中的色板；无需修改外观页面。每个色板必须包含唯一`id`、名称、`light|dark`模式，以及六位hex颜色`background/surface/foreground/muted/border/accent`。保留原包来源和许可。

不允许脚本、任意CSS、远程字体或网络地址。`availableThemes`向外观页提供当前可用配色；`resolveTheme`在插件停用时回退到宿主`boai-light/boai-dark`。主题包启停不改写保存的原主题id、自定义颜色或Scenic图片。重新启用即恢复原选择；用户主动选择其他主题则成为新的偏好。

主题使用引用由外观store取得，切换/停用释放；插件页能区分已启用待用与正在使用。宿主保底主题不作为可停用插件。

## 4. 接入检查

- 新清单不会重复id、主题id或贡献类型，不兼容项不可激活。
- 管理页自动出现新贡献；停用/重启/重新启用与真实查看器一致。
- 同名多文档互不串状态，后台更新不替换当前provider；隐藏释放引用，异步迟到不恢复旧正文。
- 插件失败不使宿主文件操作不可用，不缓存正文/路径/凭据，来源失效仍由原宿主清除正文。
- 主题停用保持原选择、自定义色、图片；配色对比度遵守原`appearance.test.ts`。
- 更新文件Header及目录地图，补合同测试和必要的中文Electron BDD。当前实际成绩唯一见03，不能只因旧查看器通过就宣称新插件已验收。
