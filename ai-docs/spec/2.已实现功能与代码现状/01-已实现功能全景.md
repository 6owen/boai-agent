# 已实现功能全景

基线：v0.2.2，核对日期 2026-09-27。本文只记录当前源码事实；规划中的功能放在第 3–5 组。

| 执行与审批 | chat/task 分开；文件工具、技能读取、文本检索、逐次命令审批、取消、流式结果 | [engine](../../../packages/runtime/src/adapters/mastra/engine.ts)、[service](../../../packages/runtime/src/service.ts) | chat 不挂工作工具；命令没有 OS 沙箱 |

| Skills / 资料库 | 导入受管副本、员工绑定；群知识取员工绑定与群共享交集 | [resources](../../../packages/runtime/src/modules/resources/local-resources.ts)、[service](../../../packages/runtime/src/service.ts) | 知识仅 Markdown/TXT 本地文本检索，无 PDF/Office 或向量 RAG |
| 持久记忆 | 员工 profile 与员工×会话记忆、来源/版本/删除、手工编辑、模型增量提取 | [memory](../../../packages/runtime/src/modules/memory/memory-repository.ts)、[engine](../../../packages/runtime/src/adapters/mastra/engine.ts) | 自建 MemoryRepository；未启用 Mastra Memory 自动历史/working memory |
| 记忆异常处理 | 格式/length 一次受预算限制的纠正；累计用量；拒绝截断来源；禁止普通任务重试记忆阶段 | [engine](../../../packages/runtime/src/adapters/mastra/engine.ts)、[service](../../../packages/runtime/src/service.ts) | 记忆失败保留诊断，不改写已成功的公开回复 |
| 持久化与恢复 | SQLite、请求去重、迁移、启动路径重定位、退出中断、备份 | [store](../../../packages/runtime/src/adapters/storage/product-store.ts)、[migration](../../../apps/electron/src/main/migration.ts) | 备份不含 API Key；不能执行中备份；恢复不自动重放命令 |
| 定时任务 | 导航、列表、详情设计入口 | [pages](../../../src/renderer/pages/) | 没有定时器执行和任务投递闭环 |

`modelCalls` 是产品对判断、公开执行、记忆及协议纠正等阶段的计数。工具任务内部还有 SDK 多步骤生成与 `maxSteps` / 用量约束，不能把该计数描述成任意场景下准确的网络请求总数。

## 已声明依赖与实际使用

以 [package.json](../../../package.json) 为准：Electron 39.2.7、React 19.3.0、Vite 8.3.1、TypeScript 7.0.2、Tailwind 4.3.3；Mastra core 1.71.0 / memory 1.32.1 / libsql 1.23.3。版本仅记录当前项目，重构不顺带升级整套依赖。

- Iconify 的 Carbon / Solar 已通过 Tailwind 编译为本地图标。
- shadcn 组件目录和 `components.json` 尚未建立；Zustand 尚未声明为依赖。
- `@mastra/memory` 和 `@mastra/libsql` 已声明，但当前产品存储实际使用 `@libsql/client`，没有实例化框架 Memory / LibSQLStore / 向量存储。
- 当前直接使用 Mastra Agent、Workspace/文件系统技能等执行能力；没有 Mastra HTTP Server，也没有 Workflow 注册与执行闭环。
- core 1.71.0 已含 LocalSandbox、A2A 与原生 schedules 等框架能力，但当前业务没有接入；命令仍使用自定义宿主 shell 执行路径。`@mastra/acp`、`@mastra/mcp`、`@mastra/client-js` 和浏览器/SDK Agent 可选适配包尚未安装，本轮未改变依赖。

## 后续必须保留的行为

1. 员工身份、会话 ID、运行 ID 和轮次 ID 分开；历史问候不算当前轮已答。
2. 单个员工可沉默，但所有有效成员有判断机会；早期合法发言不被后续慢成员阻塞。
3. 普通聊天不主动检查工作环境；工具过程与最终公开文本分开。
4. 模型、工具、记忆仅获得其作用域允许的数据；撤权和删除不能被迟到结果恢复。
5. 取消、预算耗尽、应用重启后不继续提交旧结果或自动重放有副作用的操作。
6. 本轮/历史轮展示、审批、失败恢复与记忆维护的语义不因组件或模块迁移改变。
