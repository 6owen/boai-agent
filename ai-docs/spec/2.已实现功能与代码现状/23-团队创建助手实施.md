# 团队创建助手实施

## 首版交付说明（验收通过，未发布）

从“通讯录 → 新建 → 创建团队”输入需求，选择已有模型连接并生成方案。方案可调整成员名称、头像、职责、指令、顺序、人数和群背景，支持 1–12 名成员。确认前只保存草稿；可以同时创建群聊，也可以只创建员工。

创建后，员工沿用现有个人工作区和记忆行为，私聊与群聊引用同一个员工身份。有群可直接进入群聊；只建成员可从结果中联系员工。创建动作不会发送欢迎词、发起成员模型调用或自动开始工作。

生成可停止；重新生成前若已有手工修改，会提示确认替换。连接配置变化时，需要重新核对方案。已知与未知用量分别显示，不将缺失用量当成零。模型连接错误或需求需要调整时，保留可继续编辑的内容。

应用中断后重新打开通讯录，可继续原草稿或查看该次创建的恢复入口。恢复不会自动调用模型、重复创建成员或重放工具；用户可明确“继续创建”或“放弃并清理”。文件被外部改动或清理失败时保留提示和操作记录，不能覆盖或误删其他文件。创建成功回应丢失时，重开结果仍指向原成员和群聊。

本版提供团队配置和普通群聊。狼人杀请求只生成玩家群并说明规则限制；正式发牌、私密身份、投票、胜负判定以及新增跨会话记忆能力均未交付。完整技术门禁通过，用户于 2026-09-30 明确认可当前七份真实方案，T1 最终验收已通过。未执行提交、打包或版本发布。

以下分片和检查点保留当时的实际状态与失败，最终结论见文末；唯一进度表为第 9 组 08。历史“待评审／未关闭”不代表当前仍有待办。
