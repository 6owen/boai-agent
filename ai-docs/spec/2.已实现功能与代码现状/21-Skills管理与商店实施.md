# Skills 管理与商店实施

更新：2026-09-29。**K1–K4 已实现，K-01 至 K-22 的主闭环验收已补齐。**包含本地管理、商店浏览、多来源安装/单项更新和旧库导入导出，以及商店到真实 Mastra task 读取/产物发布、完整应用备份恢复和旧资源升级。验证边界逐项列于下文；K5 使用统计和外部 Agent 全局目录管理保持可选后续。自动化扩展按第 5 组独立验收，不能用本记录证明自动化完成。

## 当前实现

- 本地管理：保留 Resource/员工 skillIds，支持目录预览、候选多选、公共/员工专属副本、逐项结果、重复请求幂等、源 hash 重验及取消。相同来源/内容/作用域复用；同名不同来源保留独立资源。
- 收藏：SQLite 事务保存收藏/分组及版本；删除组不卸载，取消收藏不撤权；移除资源在同一事务清理来源/收藏关系。
- 内容：完整 YAML 描述、兼容字段提示、安全 Markdown、受限相对文件读取；来源缺失不伪造远程版本。员工绑定仍需明确进入原有配置。
- 商店：迁入旧项目三家 provider 映射；保留原生搜索、页码/cursor 和排序能力。请求校验/响应 schema、有界响应体、15 秒超时及重定向拒绝；网络不占业务写锁。
- 缓存：列表/详情各最多 100 项，5 分钟 TTL，重复请求合并；刷新取消旧请求，旧代次不能回写缓存。过期且刷新失败显示缓存时间与错误。
- 页面：图标侧栏的技能/商城 popover 进入会话式标题/常驻搜索/可调列表宽度与完整详情；资料库原有资源标签保留兼容；分来源保存搜索条件，迟到搜索不覆盖、失败下一页可重试且条目去重；未知统计/风险保持未知。商店安装先重新读取详情，再展示实际下载包；已安装状态按 provider + 来源 ID 匹配，不按名称匹配。安装记录支持关闭窗口后继续查看和重启重开。

源码位于 `src/runtime/modules/resources/`（管理/收藏/商店用例、provider 和网络边界）、`src/shared/domain/{skills,skill-marketplace}.ts`、`src/renderer/pages/library/`；Shell 负责技能/商城图标浮层导航与现有资源详情目标。未引入旧项目的 Craft、Bun、Jotai 或全局 skills CLI。

## K3 当前实现与证据

- 来源：`src/runtime/adapters/skills/{download,archive,source}.ts` 支持原生选择的目录/ZIP、公开 HTTPS ZIP、GitHub 仓库/ref/子目录和三家商店。宿主拒绝未通过选择器授权的本地扫描；远程准备不占业务写锁。
- 下载/解包：固定经校验的公开 DNS 地址，逐跳校验重定向，100 MB 实际字节、2000 项、32 层、超时/取消及 CRC/路径/链接/冲突检查。固定 yauzl 3.4.0 / fflate 0.8.3，不执行来源文件。
- 预览/安装：可检查实际 SKILL.md、参考文件与二进制信息；使用已冻结临时内容，安装重新校验 hash。临时凭据 URL 只保存 snapshot 身份；GitHub 保存规范仓库/ref/skillPath/commit；商店保存 provider/id。安装/更新操作持久化，可从历史重新打开。
- 更新：`skill-updates.ts` 共用扫描候选，区分 current/available/unsupported/failed；name 或来源身份改变拒绝覆盖；本地修改在预览中明确显示，仅在用户确认替换已查看的内容后更新，再次变化仍拒绝覆盖。检查不改文件/集合/授权。更新保留 ID/路径/安装日期，推进来源 revision 与绑定员工配置版本，并失效来源记忆。
- 批量检查：手动“检查全部更新”只读取上游，不批量写入技能；逐项显示最新/可更新/失败/未检查，提供差异文件和受影响员工预览。停止后保留未检查项，重启将未结束批次标为中断，不自动重放网络。确认替换本地修改时，失败回滚恢复预览时的实际旧内容，而非安装基线。
- 使用边界：提交前检查活动轮次、工作 ready/running/waiting/blocked 和实际执行器存活。更新独占此资源后禁止新的绑定/读取/使用；哈希和下载在宿主临界区外进行。取消 run 后执行器未退出仍不能更新或删除技能文件。
- 一致性：持久操作记录包含受管相对路径、旧/新 hash、revision 和 prepared/files-swapped/committed/清理或修复状态。启动对照 DB 与本地文件回滚或清理，不重放网络/工具。无法判定时保留证据、阻止绑定与执行，并拒绝生成错位备份。
- `skill-sources.test.ts` 9 项来源边界测试；`skills-installation.test.ts` 28 项真实服务/SQLite 集成测试覆盖安装、身份、冻结预览、取消、持久操作、更新版本/绑定/记忆、失败回滚、7 个重启断点（含本地修改的回滚/提交）以及等待/未退出执行器阻断、删除清理失败/手动重试/重启恢复。默认离线，真实包探测另记。

删除清理由 `resource-cleanups.ts` 管理：资源/来源/集合撤销与受管相对路径记录同事务提交；失败不会恢复已撤销绑定，安装记录显示待清理并提供重试。重启仅重试本地文件清理，遇到链接指向外部时拒绝删除并保留证据。真实 Electron 场景验证了失败可见、修正目录后重试成功与外部原件保留。

- 文件与权限：保留 references/scripts/assets/许可文件；明确排除 `.env`、已知凭据和本机配置文件。不能识别任意正文秘密，分享前仍应检查文件。内容有本地修改或排除项时保留实际内容并降级为 snapshot，不冒充原始远程版本。收藏恢复可关闭；同来源/hash/作用域幂等复用，同名异源/异内容默认跳过；集合在每项安装事务内合并，保留原有归类并按包内顺序插入新组，不恢复员工绑定。

- Electron：新增“将收藏技能导出为离线库并恢复到本应用”，经过生产构建、真实管理 IPC 和原生选择器边界验证；导出/重新导入后重启，收藏分组保留而员工不自动绑定。此场景连同其余 3 个 Skills 场景通过，之后全量 32 个桌面场景也通过。系统文件选择/保存对话框由场景替代，其余流程使用真实应用。
