# 定时任务体验简化实施

实施日期：2026-09-30。对应 [第 18 项规格](../3.前端重构与功能/18-定时任务体验简化/README.md)。S1 页面与手动创建、S2 Agent 辅助、S3 本地联合验收已完成。下文区分本次专项通过结果与共享工作树的其他检查失败；没有调用付费真实模型或创建用户真实任务。

## 实际交付

- 首次进入显示任务总览，支持名称/描述搜索与全部、开启、暂停、需处理筛选。侧栏复用通讯录分组样式，展示真实即将执行计划和最近十条执行记录；完整历史另有入口。
- 阅读位置明确区分总览、任务、全部历史、单次结果。主页面切换保留搜索、筛选、折叠、列表滚动和本页详情草稿；隐藏页停止列表读取。通知按具体消息或 occurrence 定位。
- 普通创建只留标题、任务描述、运行位置、运行于、重复、时间、通知七项。执行员工或已有聊天在「运行于」选择，星期在「重复」选择，时区和五次预览在「时间」展开；未选择执行对象不能创建。
- 新建默认开启；编辑旧计划保留时区、通知、目标和暂停状态。监控走专用入口及规则编辑，继续使用确定性 JSON 比较、原子检查点和冷却，不改成模型报告。
- Agent 辅助由用户明确选择模型连接，一次无工具调用生成结构化候选。宿主校验支持的周期、获准身份及日程；对象必须是请求中明确提到、名称唯一的候选。缺少员工或时间时保持待补齐，不支持的能力明确反馈。
- 手动与 Agent 使用同一编辑器和提交入口。草稿身份/版本与请求序号共同防止迟到回填覆盖手动修改；模型失败后仍可手动填写。生成不创建计划、聊天、Work 或 occurrence。
- 新建提交绑定稳定 requestId；计划与创建回执在一个 SQLite 事务提交。重复请求返回同一计划，删除后的回执不复活计划。提交中草稿保存在本地，回执未知时冻结修改并提供核对入口；应用重启后可恢复同一提交并查询原计划。
- 完整历史按名称及全部/进行中/已完成/需处理在数据库内过滤，再按稳定游标分页。搜索中的 `%`、`_` 按字面值处理；已完成只表示运行结束，仍独立显示交付、未知和失败证据。

## 核心实现与边界

| 位置 | 本次职责 |
| --- | --- |
| `src/renderer/pages/schedules/` | 总览、七项编辑、可选草稿助手、完整历史与单次阅读 |
| `src/renderer/components/app-shell/`、`detail-panel/tabs-state.ts` | 页面阅读位置、原标签/草稿复用、通知精确导航 |
| `src/shared/domain/automations.ts`、`src/shared/ipc/` | 草稿、创建回执、恢复计划与历史过滤合同 |
| `src/runtime/modules/automations/automation-draft.ts` | 结构化候选、身份授权、支持范围和日历规则校验 |
| `automation-repository.ts`、`automation-service.ts` | 定义/创建回执原子持久化、去重、修订冲突、恢复已暂停计划 |
| `src/runtime/adapters/storage/product-store.ts` | 历史搜索/状态过滤先于分页 |
| `src/runtime/service.ts`、`adapters/mastra/engine.ts` | 显式连接、共享模型容量、超时/退出/备份管理、无工具单步生成与真实用量回执 |

草稿沿用现有 ModelUsage/UsageRecorder，按唯一请求写入 `automationDraftCalls`。缺失用量保持未知；该记录不伪装成工作运行或未来 occurrence 预算。模型失败不自动重试。计划创建回执存入 `automationCreations`；本地待核对草稿仅用于恢复请求身份，是否保存成功以宿主回执为准。

Mastra 原生 schedules 仍为唯一周期时钟。受理、预算、交付证据、通知提交、明确追加、定向停止和实际执行器退出边界保持不变；重启不自动重放模型或工具。一次性、每月、云端和由自然语言直接授权 JSON 监控仍不在本轮范围，界面不提供假选项。

## 本次验证

- `pnpm typecheck`、`pnpm lint:ui`、`pnpm build` 通过；构建仍有既有的大包体积提示。
- 7 个自动化模块测试文件共 **99 项通过**：simplification、product、repository、monitor、notifications、budget、execution。
- **14 个相关 Electron 场景通过**：新增 5 项简化流程，既有 6 项编辑/聊天/分页/通知/预算/补充流程，确定性监控、工具中断重启，以及页面表单/键盘焦点恢复。
- 额外综合「主题外部执行与自动化持久化」场景未通过：旧原生 select 操作已适配 Base UI，但随后停在外观页 760×800、200% 缩放的边界断言，未到本场景的备份恢复阶段。本轮未减少该断言或修改外观产品逻辑。自动化持久性另外由模块与专项重启场景验证。
- 全仓 Vitest 扩展检查：**574 通过、3 失败（42 个文件）**。失败在 `local-skills.test.ts` 的禁用插件来源断言，以及 `skills-installation.test.ts` 的两个批量更新断言（实际读到 164/163 个条目，而 fixture 预期 3/2 个）。这些 Skills 代码不在本次修改范围，未绕过或削弱断言。全仓结果不能表述为通过。
