# v0.2 实现记录

日期：2026-09-27。对应规格：08、09、10、11。版本：0.2.0。

后续修复与最新验证见 [13 v0.2.1 群聊修复与图标](./13-v0.2.1群聊修复与图标.md)。

本文记录 v0.2.0 初次交付；07 保留 v0.1 历史事实。定时任务仍仅提供页面设计，未实现定时执行。

## 1. 桌面界面

已将原大侧栏与模态表单替换为顶部工具栏、64px 窄导航、会话列表、聊天区、右侧非模态详情。导航包含会话、定时任务、资料库、设置及帮助。灰白背景、黑色主要操作、分栏与文本对比度对照 08 实现。

员工/群详情、模型连接、资源绑定、系统文件、记忆、任务与产物都连接实际接口。详情支持拖动、键盘调整、返回与关闭；未保存修改提供继续编辑/放弃/保存后继续，退出窗口也会检查未保存编辑。聊天草稿与表单独立，切换导航保留会话和阅读位置。

实际 Electron 操作覆盖群详情编辑守卫、系统文件保存、记忆增删、草稿保留，以及 1280/1100/900/760 像素窗口和 200% 页面缩放。窄窗口以可返回的单内容视图显示详情。所有流程仍使用本地预加载接口，没有浏览器内伪造业务数据。

## 2. 员工文件、空间与记忆

`AgentHomes` 负责明确加载 AGENTS.md / SOUL.md，结构化身份生成 IDENTITY.md。旧 instructions 原样迁入工作规则，运行只注入一次。源文件有 hash、配置版本、单文件 64 KiB 和合计 12,000 字符限制；采用原子替换与更新日志，启动恢复未完成的文件/数据库提交。

每位员工有独立 home。每个员工×会话还有自己的 sessions 工作目录；模型的 self:/ 只访问当前会话的 work/runs，shared:/ 只读取当前共享区。任务结果须经过 publish_artifact 才复制到群共享区并登记来源。普通文件工具不能改员工系统文件、读取其他员工或跨会话目录。主机命令仍逐次批准，不是操作系统沙箱。

`MemoryRepository` 使用 SQLite 保存权威记忆，区分员工基础资料与会话范围。记录包含来源、版本和失效信息；支持编辑、删除、清除与显式导入。参与员工在成功交流后由自己的模型提取有来源的候选；问候允许提取为空。删除、撤权与成员变化使旧记忆失效，版本校验拒绝迟到提取结果。

MEMORY.md / USER.md / 日期日志为生成视图，不被自动反向导入。外部修改会显示冲突；重新生成前保留副本，显式选段导入才写入目标范围。投影受大小预算限制，完整条目可在记忆界面查看。

Mastra 仍为普通 Agent 加显式 Workspace/SkillSource。未引入 OpenClaw 运行时、目录内任意 TypeScript 自动加载或 Mastra 自动历史回放。

## 3. 自然群聊与运行

`GroupScheduler` 保存轮次、公开事件、成员 delivery、参与决定、发言权与 main 工作项。用户消息和事件在一次数据库提交中保存，稳定的事件×员工标识负责去重。

每名成员使用自己的模型判断 reply/pass/wait/ask/request_handoff。模型请求没有业务工具；宿主仅校验身份、点名、依赖、顺序与预算。首个合法候选可先回复，不等待最慢成员；同群始终只有一个公开发言者。新的完整员工消息会触发后续判断，成员可以补充或保持安静。

问候和普通交流不提供文件、知识、Skills、命令工具。任务才装配获准能力；工具前言进入步骤活动，最后无工具步骤的正文进入公开回复，推理事件不进入消息或活动记录。

实际限额：首轮判断并发 3、单次判断 15 秒；每轮判断最多 `max(12, 4 × 成员数)` 次，总模型调用（含回复和记忆）最多 `max(24, 8 × 成员数)` 次，单员工最多 2 次公开贡献，最长 5 分钟，模型已报告输出上限 16,000 token。每位员工的首次贡献同属第一代，额外自动接话才扩展因果代数，最多 3 代；这不是最多 3 名员工或 3 条消息。6 人及 12 人群已验证成员独立首次回应。

用户新消息排队并在当前发言边界优先处理；停止会失效化在途决定、发言和接续，迟到结果无法复活。依赖可引用未来 main 工作项，上游完成后继续，上游失败/pass/无效依赖会触发有界重新判断或结束。未知模型消耗不假装为零，按模型已报告 usage、调用数、输出和时间限制控制。

## 4. 升级与备份

新版使用 userData/v2/，与旧版数据根分离。桌面主进程取得应用实例锁后，以 SQLite 一致快照复制旧库及受管资源到临时目录；校验完成后原子启用。复制失败保留原始数据并清理本次临时目录。凭据只在本机复制加密文件，不进入普通导出。

历史 ID、署名和部分输出保留；旧非终态运行标记中断，不重新投递历史消息或执行工具。员工目录、资源、共享文件和登记产物恢复时重定位。备份增加 agents、记忆、轮次和版本标记，具体恢复步骤随备份输出。

旧应用继续写旧根，不会改变新版副本；两边出现分叉时不自动合并。请使用新版的数据与备份入口。

## 6. 当前边界

- 定时任务只有页面入口、列表和详情设计，没有后台调度或关闭应用后执行。
- 知识仍限 Markdown/TXT 关键词检索；没有 PDF/Office 解析、向量召回、MCP 或云同步。
- 系统文件是 BoAI 的运行时约定，不承诺完整 OpenClaw 兼容；专属技能需要显式登记与绑定。
- 记忆提取受模型能力影响；来源和权限可验证，不等于对每条模型总结进行事实证明。
- 单群输出有预算，达到限额后等待用户继续。模型未报告的消耗不能精确统计费用。
- 当前交付平台为 macOS ARM64，应用未签名/公证；其他系统尚未验收。
