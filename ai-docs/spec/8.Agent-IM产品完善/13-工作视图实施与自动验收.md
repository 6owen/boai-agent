## 2. 自动准备数据，用户只审阅结果

按[02 自动化功能验收与结果审阅](../02-自动化功能验收与结果审阅.md)执行：开发代理准备隔离数据、运行真实界面、制造故障、重启、核对及重跑。用户直接看实际页面、交流和文件，不承担手动创建员工、发送测试消息、逐个点击或检查数据库。

完整矩阵要求自动准备的数据包含两名独立员工、私聊、群聊、核心会话及自动化任务聊天；真实Work覆盖ready/running/waiting/blocked/delivered/failed/cancelled/interrupted，含一个根/子工作与一个独立结果依赖。材料包含TXT/Markdown、代码、图片和不支持预览的二进制；成果包含v1/v2、本人采用v1未采用v2、同名独立文件；另准备未发送草稿、未发布文件和隐藏/删除来源作为反例。每项实际数据层和场景见下表，完整源码156/156与应用包27/27已分别登记实际结果；预置样本、离线实际执行与真实供应商证据分别标明。

用于状态/分页验证的持久样本可以通过既有fixture准备，但报告必须标“预置数据”；不能把预置的running或delivered当作真实执行证据。完整代表流程需从自动发送请求走到实际受理、执行、发布和页面导航；离线协议流程与真实模型流程分别留证，不跨运行拼成一次成功。补真实模型时复用既有MD/协作评估合同、连接与登记预算，固定输入；真实提供方受阻或未交付时如实保留失败。
