# Agent IM 产品完善

更新：2026-10-02。**状态：通用完善合同，已交付子集以第 10 组为准；IM-05 独立页面退役，当前合同为聊天内处理，入口定向验收完成，原姓名提及基线失败保留。**

当前优先开发 [第 9 组：团队创建助手](../9.团队创建助手/README.md)。本目录保留附件、产物、工具、聊天内处理、搜索与用量等完善项；下表 P0/P1 表示本组内部优先级，不要求完成全部 P0 才能开始第 9 组 T1。团队生成、方案编辑和批量创建统一由第 9 组定义；IM-07 继续负责经过验证的场景模板与首次真实交付。

本目录承接“成员都是 Agent 的 IM”产品目标。每项功能单独维护用户流程、界面行为、状态、数据边界和验收；设计图用于讨论与实施参考，不能当作实际运行截图。原单篇路线已拆入本目录。

核心交付场景：**交材料 → 员工研究/写作/核对 → 预览成果 → 指定版本修改 → 用户采用 → 后续找回。**

## 状态和维护约定

- 本目录负责基础能力完善目标；当前团队创建主线以第 9 组为准，已实现事实先看源码与[第 2 组实施记录](../2.已实现功能与代码现状/README.md)。

- 功能文档维护自己的验收清单；11 文档维护阶段状态和证据链接，避免两份清单分别标为完成。
- 每次开发按最小闭环推进；可直接指定“实施 IM-02 的首批范围”。
- 新版设计图另存版本，不覆盖历史；真实截图和运行证据在实际实施时归档，不预先填造。
