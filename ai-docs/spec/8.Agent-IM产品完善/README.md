本目录承接“成员都是 Agent 的 IM”产品目标。每项功能单独维护用户流程、界面行为、状态、数据边界和验收；设计图用于讨论与实施参考，不能当作实际运行截图。原单篇路线已拆入本目录。

核心交付场景：**交材料 → 员工研究/写作/核对 → 预览成果 → 指定版本修改 → 用户采用 → 后续找回。**
