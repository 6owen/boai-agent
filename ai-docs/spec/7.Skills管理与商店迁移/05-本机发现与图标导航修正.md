# 本机发现与图标导航修正

更新：2026-09-29。此前 K1–K4 验收覆盖了 BoAI 受管副本的安装、更新和迁移，未覆盖用户已有本机技能的发现与旧版列表交互。不能用原有测试通过推断这些体验已交付。

## 导航与交互

侧栏保持 boai-agent 的 52px 图标栏，只保留一个“技能”入口，无二级菜单或独立商城入口。点击进入统一技能页面，左栏顶部采用无整块底色、选中项浅色圆角的本地/收藏/商城 Tabs；商城内提供 skills.sh/ClawHub/SkillHub 来源切换。旧商城页面偏好归入技能页，资料库商城入口也跳转到该页的商城 Tab。

内容区参考用户提供的顶部 Tabs/搜索/列表截图：保留共享列表宽度与可拖动分栏线，Tabs 下方为胶囊搜索框和操作按钮，紧凑列表独立滚动。搜索右侧单一操作图标合并导入、重新扫描、检查更新与导出，DropdownMenu 默认向右展开；本地页菜单包含文件夹/ZIP/链接与 Git 导入，收藏页不显示导入项，分组按钮仍在搜索旁。右侧未选择时只显示居中“选择要查看的技能”，不展示详情标题或自动选中第一项；点击条目或键盘明确选择后才展示标题与正文，切换分类/商店来源时清空选择，重新进入也不恢复旧条目。保留旧 `SkillsListPanel.tsx` / `SkillInfoPage.tsx` 的刷新、添加、元数据表与 Markdown 说明交互。收藏视图的分类标题复用会话的无底色文字及悬停/聚焦箭头，扁平虚拟行由 aria-expanded 标记展开状态；分组浮层支持增改删，移除默认纵向 gap 并使用 34px 紧凑条目。分组名称原位变为输入框，新建与重命名的保存/取消都在输入框右侧，移除上下移动和行首图标；删除分组需在按钮旁浮层确认，取消不写入。收藏页标题不显示导入按钮。技能主操作菜单使用 248px 宽度、8px 外围留白和舒展条目；行菜单使用 240px 宽度，“在文件夹中显示”保持单行。来源明确显示全局、Agent、插件或 BoAI 副本。知识与按员工资源入口仍在资料库；旧技能分类转入新工作区。

商城沿用同一列表/详情分栏，提供方搜索/排序条件相互独立，搜索框下排序采用 Tabs；说明、已显示数量与刷新时间通过来源 Tabs 旁小图标的 tooltip 延迟 600ms 展示，搜索时排序保持禁用。商城“已安装”只匹配仍存在的 local 身份与精确提供商来源；查看时切回本地技能详情，避免额外挤出第三个内容栏。重启回到本机管理；不因恢复商城页面而自动联网、重新下载或重放安装。

详情的元数据、来源和正文容器使用项目共享 `Card`，元数据行使用 `soft-divide-y`，不再单独定义卡片底色、边框和阴影；技能正文和会话统一使用 `components/common/markdown.tsx`；围栏/缩进代码交给共享 `CodeBlock`，行内代码保留普通排版。Shiki 4.4.3 按[官方细粒度加载方式](https://shiki.style/guide/bundles#fine-grained-bundle)使用单例 JavaScript 引擎，本地语言/主题异步加载，GitHub 明暗 tokens 随应用主题切换；不插入 HTML、不从 CDN 加载代码。未知语言、超过 100,000 字符或高亮失败时保留原文，流式输入防抖并隔离迟到结果；自定义样式集中于 `src/renderer/styles/shiki.css`。会话与本地/商城技能详情共用 [ScrollFade](../../../apps/electron/src/renderer/components/ui/scroll-fade.tsx)，保留会话现有顶部渐隐和悬浮标题的 16px 重叠。组件只封装原生滚动容器与渐隐，透传 ref/滚动事件；会话跟随、定位和恢复仍由 ChatView 管理。详情切换技能从顶部阅读，未选择时保留居中空占位。

## 共享拖拽与页面收敛

[DragList](../../../apps/electron/src/renderer/components/common/drag-list.tsx) 提取会话页现有原生拖拽：行上半/下半区显示前/后插入线与圆点，源条目半透明，结束/离开清理落点；支持 Alt + 上下键，无需额外移动图标。`DragListItem` 允许调用方提供自己的按钮/内容；`DragListGroupTarget` 接受拖到分组标题的归类操作，空组与折叠组均可接收。只接受同一列表实例的有效源，不从任意外部拖拽读取业务身份；边界和保存由调用方决定。

会话保留置顶/普通分组内排序边界。技能“收藏”按持久 `favoriteResourceIds` 的顺序投影到各组；拖到另一组的行，在同一个 SQLite 事务中更新顺序与归属；拖到分组标题执行归类。分组排序增加前/后落点，旧的未指定 placement 请求仍按前置处理。搜索只改变可见目标，不删除或覆盖隐藏收藏的顺序；键盘移动按展开分组的实际显示顺序寻找相邻行。

技能导航不再提供“检查更新”和“安装记录”页面；旧分类偏好重启回到本地。批量检查通过技能菜单打开 Shell 最右侧的“技能更新”详情标签，与会话“任务与产物”复用同一个标签栏和内容容器；当前技能列表与主详情保持不变，结果行可直接展开差异并升级；单技能检查与升级位于详情标题栏，使用检查/向上箭头/完成图标，检查或升级时旋转显示进行中状态。更新不使用弹窗，不增加独立页面或导航。安装记录功能和导入面板底部“关闭/后台继续”按钮移除；仅展示本次安装或导出的进度和结果，保留取消扫描/停止安装。空闲时通过 Esc 或点击外部关闭。后台账本继续支持请求去重/进度/恢复，不增加历史浏览入口。

开发进程的 renderer 热更新不会重启后台 worker。若拖动返回不支持 `move-skill` 或不认识 `placement`，当前 worker 仍是旧合同；完整退出并重启 `pnpm dev`，不能仅刷新窗口。前端给出完整重启提示，不把不支持的新操作降级成不完整归类，也不自动重试写入。

## 原版格式与本机技能导出

导出列表仅展示现存收藏的技能，打开时默认全部选中，不列出其他本机技能；没有收藏时显示空提示并禁用预览与保存，不回退选择全部本机技能。收藏中的本机技能或 BoAI 受管副本均可导出，不要求先导入。本机仅传稳定 ID，宿主重新校验规范路径和内容，沿用冻结预览/有界读取/不覆盖保存；不写原目录、不创建资源或员工授权。弹窗移除 description 与技能库名称输入框，导出使用默认名称“我的技能库”。仅保留一个常驻的关键词输入框，输入时实时过滤收藏技能的名称/来源；右侧保留检索按钮，点击聚焦该输入框，不展开第二个输入框、不清空关键词。过滤不改变已有勾选。下方采用只展示名称/来源的紧凑多选列表，不展示简介；保留逐项勾选，移除“全选 / 只选收藏 / 清除选择”按钮，已选数量与收藏总数位于 footer 左侧，右侧仅并列“预览”和“导出”，移除底部“关闭”。“导出”直接准备并校验冻结内容，然后打开原生 ZIP 保存窗口，不切到预览步骤；同名冲突或其他阻塞错误直接显示，取消保存保留选择。准备预览、直接导出及保存期间仅在当前点击的按钮内显示加载动画，并保持按钮宽度；其余操作暂时禁用，不在内容区域添加过程状态提示。按“添加模型连接”的实现保留同一个 Dialog 和 Popup，通过步骤状态原位切换内容：第一步选择技能（520px），点击“预览”后切换至第二步目录预览（620px），不叠加弹窗或遮罩。第二步按宿主冻结 ZIP 的实际文件清单展示可展开目录、文件名和大小，所有层级移除原生列表圆点/方点及默认列表留白；容器复用全局 Card 及边缘皮肤，滚动使用 ScrollFade，不单独绘制卡片边框。移除“导出说明”折叠块，仅在存在阻塞错误时显示错误提示；页脚最左侧是带左箭头图标的 ghost“返回选择”按钮，总量与“保存 ZIP”位于右侧；清单包含静态仓库模板、实际技能文件和空目录，与最终 ZIP 使用同一份冻结内容，不虚构截图中的文件。进入预览聚焦标题，返回第一步保留搜索与勾选，第二步仍可保存 ZIP；当前选择与预览不一致时不能保存旧预览。同名不同来源仍需选择一个或分别导出；旧后台没有文件清单时明确提示完整重启。

ZIP 对齐原 boai-app `personal-repository/export.ts` 与 `templates.ts`：`skills/` 完整内容、`boai.json`、`boai.lock.json`、`meta.ts`、`.gitmodules`、`.gitignore`、`package.json`、`scripts/cli.ts`、`instructions/`、`vendor/`、`sources/` 和中文 README。可验证 Git 来源进入 vendors/lock 来源声明；没有可靠 Git 来源的条目进入 snapshots，不把外部技能冒充手写。原有 JSON 来源/收藏附录继续保留，旧应用可忽略。应用只生成这些文件，导入和导出不会执行 CLI。

本地与收藏页的操作菜单均提供“导入技能库”，使用独立弹窗选择 ZIP 或解压后的目录。入口要求有效的 `boai.json` / `boai.lock.json`，沿用旧版 meta.ts 静态解析、来源/校验和/收藏附录校验与有界读取；普通技能目录不能冒充技能库。有效条目默认选中，确认“导入收藏”后安装到 `~/.agents/skills`，所选条目固定加入收藏，并恢复包内分组；没有收藏附录的旧版库导入为未分组收藏。相同内容复用现有本地技能，重复导入保留当前分组；同名不同内容显式冲突且不覆盖。完成后刷新本地目录和收藏，切换至收藏页；继续保留逐项失败反馈和停止安装。

## 本机发现

[目录用例](../../../packages/runtime/src/modules/resources/local-skill-catalog.ts) 读取共享 `~/.agents/skills`、旧版注册的 Agent 技能根及 Codex 已启用插件。支持 `CODEX_HOME`、Codex `.system` 和命名空间子目录；不要求安装或运行 Agent CLI。

- 先扫描共享技能及启用插件，再补 Agent 来源；普通同名技能沿用全局优先规则，插件以 `plugin:slug` 区分。
- 目录链接解析到实际位置后去重，多个 Agent 的同一技能不会耗尽扫描上限。正文不得为链接，旧身份对应的目录被改指向时要求重新扫描。
- 只读取有界 SKILL.md 与插件声明，不遍历整个主目录，不执行脚本，不复制账号凭据。不可读目录、坏文档、失效链接和截断可见。
- 展示兼容旧技能的名称；导入到 BoAI 时仍按现有执行资源规则严格校验 name 与包内容。
- 每个宿主进程首次读取扫描目录，之后命中内存缓存并合并并发请求；渲染器按客户端和升级版本缓存目录并合并在途请求，有效缓存直接显示且不发目录 IPC，重新进入不闪出加载态。收藏快照跨页复用，相同 revision 不重算列表；搜索字段和排序记忆化、收藏顺序使用 Map，搜索输入与结果更新分离。本地/收藏采用 TanStack React Virtual 动态测量，只挂载视口及前后各六行，拖拽源、焦点和打开菜单的行保持挂载以保护交互。手动“重新扫描技能”传 refresh，安装发布或更新结束后使目录失效，扫描过程中失效不会复用旧结果。详情/文件仍实时校验身份和路径；不自动联网检查更新。读取失败不显示成成功的空列表。

2026-09-29 本机只读核对得到 325 项：174 个全局、44 个 Agent、107 个插件，包含 `agents-sdk` 和 `kata-code:express-modular`，无扫描诊断。此数量是该时点用户目录结果，不作为固定测试断言。

## 收藏、编辑、安装和更新

本机条目使用 `local:` 稳定身份，仅存在于目录和收藏中，不写入可执行 Resource，也不修改员工 skillIds。收藏/分组沿用 SQLite 版本检查和事务；不存在第二套前端收藏存储。仅折叠状态作为界面偏好保存；选中条目是页面内临时状态，重新进入时显示空占位。

正文与元数据的编辑按钮用系统默认编辑器打开经过身份校验的 SKILL.md，保存后刷新。插件来源作为读取内容展示。**AI 辅助编辑尚未迁入**，不能将打开文件描述为 AI 编辑能力。

技能页只展示本机目录与商城，不合并 snapshot.resources、不展示员工绑定、不提供“导入到 BoAI”。后续员工配置再接入显式绑定，本批不做。

导入保留原版 `SkillInstallMenu.tsx` / `InstallSkillDialog.tsx` 的布局与交互：搜索旁统一操作菜单包含“导入文件夹、ZIP 或链接 / 从 Git 仓库导入 / 重新扫描技能 / 检查技能更新 / 导出技能库”，菜单及导入面板默认显示在同一按钮右侧；选择来源后进入 400×420 面板。顶部来源 Tabs、中部文件选择/拖入区或链接扫描、候选勾选/全选/正文检查、底部安装按钮；移除安装范围与员工选择，固定提示安装到 `~/.agents/skills`。拖入路径经 preload 的真实 File 与宿主校验授权，沿用受限来源扫描。

导入面板的样式尺寸独立适配当前应用：浮层和商城对话框共用明确覆盖基础组件默认值的尺寸/零外层内边距工具类，避免 Tailwind 工具层把页面 CSS 的宽度和内边距覆盖。内容横向留白统一 16px，链接输入框与扫描按钮使用全局 32px 控件高度，正文 13px、说明 12px；分支选项保留纵向展开，空态使用 20px 图标。中心内容滚动、底栏固定，最大宽高受视口限制；扫描与安装逻辑不变。

预览携带 `target: local`；宿主从扫描计划取得目标，不接受前端自定安装路径。本地安装先校验/复制到该目录下本次隐藏暂存，提交前复核内容；同名同内容复用，同名不同内容冲突，不覆盖。仅保存 local 身份的来源、收藏和逐项操作，不写 Resource/员工 skillIds。重启中断未完成项、不重放安装；已发布但结果未确认的文件保留并提示重新扫描，清理只处理本次暂存。旧后台不支持该合同则明确要求完整重启，不降级为受管安装。

技能操作菜单的“检查技能更新”通过 Shell 的 DetailTarget/DetailTabSession 打开最右侧“技能更新”标签，复用会话“任务与产物”的顶栏 Tabs、滚动容器、关闭、拖拽排序及收起恢复，不占用技能主详情区域。使用固定标签身份去重，重复打开仅激活既有标签；切换标签、切换技能和收起不会重启检查或清除当前展开项。标签内展示进度、停止与逐项结果，结果项可展开文件差异/实际包内容并点击图标升级；合并最新检查和操作结果，升级完成不继续显示旧批次的“可更新”，同时刷新技能列表与正文。点击结果名称定位本地技能主详情并保留更新标签；详情标题栏的单项图标打开 Popover，检查/升级中仍可打开；进度、检查时间、差异、确认和操作均放在浮层，实际正文预览仅展开后读取。移除主详情中的更新状态卡片、说明刷新按钮及底部重复收藏操作；收藏只在现有菜单中操作，底部保留收藏分组，外部编辑后返回窗口重新读取正文。更新仍先审阅差异和实际包内容，再明确提交；不提供安装记录或独立更新页面。本机批量检查不混入员工受管资源。

sidebar 是主页面边界，Shell 通过 detailWorkspacesReducer 为每个页面单独保存右侧标签、选中项和显隐状态；标签 key 加页面前缀，同一目标在不同页面不共享编辑身份。切换主页面不显示上一页标签，返回时恢复本页标签和未保存草稿，关闭应用仍汇总全部未保存状态。技能更新标签在隐藏页面暂停列表轮询，恢复只读既有批次而不重启检查；检查/升级本身不因页面切换取消。

`skill-updates.ts` 同时支持旧受管资源和 `~/.agents/skills` 普通目录。来源优先采用 BoAI 已保存的 GitHub/URL/商店精确安装记录；对原 skills CLI 安装，读取 `~/.agents/.skill-lock.json`（配置 XDG_STATE_HOME 时沿用其 skills 路径）中的 GitHub 仓库、分支与技能路径。不根据同名商店技能猜测来源，也不执行外部 CLI。没有来源记录的条目明确提示不支持；其他 Agent 目录、插件和目录链接仍交给原安装工具更新。

旧 CLI 的 tree hash 不能冒充本应用的完整内容校验和：首次接入保存 `baselineUnknown`，存在更新时必须确认替换当前文件；已知本地修改同样需要确认。更新保留 local 身份与收藏，使用 `.agents/skills/.boai-update-*` 同盘暂存与旧内容备份，沿用内容复核、SQLite 版本提交和中断恢复；不创建 Resource 或员工绑定。CLI 原锁文件不重写，后续本应用检查使用自己的来源/版本记录。

统计入口与页面暂时移除，旧统计导航偏好回退本地。后续仅在有真实 skill 调用证据时增加统计。
