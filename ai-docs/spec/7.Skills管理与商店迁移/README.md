# Skills 管理与商店迁移

更新：2026-09-29。状态：**K1–K4 已实现并完成 K-01 至 K-22 主闭环验收；K5 保持可选后续**。实际实现与验证见 [Skills 实施记录](../2.已实现功能与代码现状/21-Skills管理与商店实施.md)，本组其余正文继续定义完整目标。

**导航/发现修正**：上述前期验收只覆盖受管副本，遗漏了本机已安装技能与旧版交互。最新要求和补充证据见 [05 本机发现与图标导航修正](./05-本机发现与图标导航修正.md)。

## 迁移结论

当前侧栏只有一个“技能”入口，顶部为本地/收藏/商城 Tabs，左列表/右详情。技能页只展示本机扫描与商城，不混合员工资源；后续绑定留给员工配置，本批不实现。导入参考旧 boai-app 的来源浮层交互，尺寸与样式适配为当前应用的 400×420 紧凑面板，固定安装到 `~/.agents/skills`，没有员工或安装范围选择。

当前链路是：**发现本地或商城技能 → 扫描包内容 → 安装到本地 → 查看或收藏**。新安装不创建 Resource、不修改员工 skillIds；此前受管安装/更新和授权测试仅证明旧兼容管道。

制定规格时，项目已经实现本地 Skill 目录导入、公共/员工专属资源、员工绑定、版本化读取和删除撤权。当时需要新增的是管理界面、来源信息、收藏分组、商店检索、批量扫描与安装、可检查的更新和便携迁移能力，不必重建一套运行引擎。

## 本方案采用的假设

1. 初稿为后续开发规格；现已获准按规格实施，开发测试仍使用隔离数据，不主动迁移用户真实技能。
2. 当前管理独立于数字员工；用户明确安装到 `~/.agents/skills`，不改 Codex/Claude 插件或项目来源目录，不执行包内脚本。
3. 已有资料库的知识资料与员工视图继续保留；技能与商店通过单一技能入口进入同页 Tabs；资料库旧分类转入专属工作区。
4. 使用当前 Soft UI、Base UI 和本地图标入口，参考旧交互而不复制 Craft 的整套界面依赖。
5. 本地资源管理与商店可先独立交付；脚本执行环境的准备继续属于第 5 组 S2，不因商店接入而提前宣称已就绪。

本批只新增固定全局目录安装；外部目录原位升级/卸载仍不属于该入口。最新边界见 05，旧 K 矩阵不作为本批未测试改动的验证结果。

## 范围与交付顺序

使用 **K1–K5** 表示本组阶段，避免与既有 B/S/G 阶段混淆。

| 阶段 | 交付范围 | 状态 |
| --- | --- | --- |
| K1 | 已安装/我的、收藏分组、技能正文与文件详情、本地批量扫描导入、员工绑定入口 | 已交付；本地闭环、授权及旧数据已验证 |
| K2 | skills.sh / ClawHub / SkillHub 的只读列表、搜索、分页、详情和缓存 | 已交付；离线回归和三家实际接口探测通过（可用性以探测时点为限） |
| K3 | 商店及远程来源安装、来源记录、检查更新/单项更新、受管卸载 | 已交付；原生安装/更新/取消/断流、实际任务、真实更新断点恢复和卸载记忆失效已验证 |
| K4 | 旧应用导出库导入、当前技能库导出、可携带来源与收藏关系 | 已交付；旧库/新库离线往返、来源/集合幂等和桌面原生保存恢复已验证 |
| K5 | 本应用技能使用统计、更多来源及外部 Agent 适配 | 可选后续，不阻塞主闭环 |

核心验收是：用户从商店安装一项技能，在资料库看到来源和内容，显式绑定一位员工后由该员工的 task 读取；未绑定员工不可读取，更新/移除不破坏授权和旧数据。K1–K3 完成后可称主闭环交付；K4 完成后才可称旧技能库迁移交付。

K-01 至 K-22 已建立[逐项证据表](../2.已实现功能与代码现状/21-Skills管理与商店实施.md#k-01-至-k-22-证据核对)，五项补验缺口已关闭，并与产品/架构规格交叉核对；每项验证方式和限制分别保留。

## 与现有规格的关系

- [工作区与资源隔离](../4.数字员工与协作重构/02-工作区与资源隔离.md)：沿用物理路径、所有者和资源撤权，不改变群知识交集规则。
- [Sandbox 文件系统与 Skills](../5.Mastra能力扩展/03-Sandbox文件系统与Skills.md)：继续区分“说明可用”和“执行就绪”；本组管理取得和维护技能，S2 管实际执行准备。
- [员工执行后端与能力契约](../4.数字员工与协作重构/04-员工执行后端与能力契约.md)：当前 ACP 员工不能直接绑定 BoAI Skills；本组不得用商店安装绕过这个限制。
- [Cumora 协作重构](../6.Cumora协作重构/README.md)：安装管理不是员工工作项；不新增模型判断、任务预算或自动重试机制，重启后不重放业务工具。

原规格以本地代码快照为依据；本轮已探测三家商店接口，证据和限制见实施记录。已有三家实际包下载与内容检查证据；在线探测与离线/原生进程验收分别保留证据，不承诺外部服务持续可用。
