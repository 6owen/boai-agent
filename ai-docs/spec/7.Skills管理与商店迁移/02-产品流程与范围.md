# 产品流程与范围

更新：2026-09-29。本文是完整目标行为；实施进度见第 2 组 Skills 记录，迁移前行为见 [01](./01-现有实现与迁移映射.md)。

## 1. 入口与信息组织

保留当前图标侧栏，技能只占一个入口，无二级菜单；点击进入统一页面，左栏顶部 Tabs 切换本地/收藏/商城。商城内再切换三个商店来源，下方为胶囊搜索和列表。右栏默认居中空占位，点击条目后显示详情，切换分类或来源时清空选择；保留可调分栏、收藏/分组与详情操作。资料库继续承载公共资料与按员工查看；旧技能分类转入专属工作区。当前合同见 [05 本机发现与图标导航修正](./05-本机发现与图标导航修正.md)。

| 视图 | 内容 | 主要操作 |
| --- | --- | --- |
| 本地 | 本机目录扫描到的 Skill，显示来源、内容与位置 | 导入到 ~/.agents/skills、查看、收藏、打开目录、编辑 |
| 收藏 | 用户收藏的本机 Skill，按自定义分组或未分组展示 | 收藏/取消、分组增删改、顺序和折叠、导出 |
| 按员工 | 该员工实际绑定的技能与知识，延续当前筛选 | 查看状态、转到员工配置；区分专属资源与公共绑定 |
| 技能商店 | 单个提供商的榜单、搜索和详情 | 切换提供商、搜索、排序、加载更多、安装到 ~/.agents/skills |

“收藏”采用显式收藏，不依据导入路径推断原创。旧库导入时可明确选择“加入收藏”；新安装不自动绑定员工。取消收藏或删除分组不卸载技能、不修改员工授权；删除分组后成员回到未分组。一项技能在“收藏”中最多属于一个分组。分组标题样式与拖拽复用会话；技能组内顺序和跨组移动持久保存。分组名称原位编辑，新建/编辑按钮与输入框同行；不显示上下移动图标。顶部导航为本地、收藏和商城，统计暂时移除，更新在详情操作，安装记录功能移除；导入/扫描/导出合并为搜索旁单个向右展开的菜单，导入面板无底部关闭按钮。

首期不做跨商店混合排名、未安装技能的云端收藏、自动为所有员工安装、技能创作工作台或 GitHub 双向同步。

本批技能页与数字员工暂时无关，不展示员工资源、绑定人数或绑定操作。导入保留 boai-app 来源浮层的布局交互，尺寸与控件样式适配为 400×420 紧凑面板：文件夹/ZIP/链接 Tabs、选择或拖入区域、链接扫描、候选多选和固定底栏。没有安装范围选项，新安装只写入 `~/.agents/skills`，不创建 Resource。员工绑定是后续员工配置能力；以下旧受管绑定/更新设计仅保留兼容背景。

## 2. 技能详情

技能工作区在列表右侧显示完整详情；资料库的资源详情标签保持兼容。详情包含元数据、说明与受管文件，不引入第二套窗口管理。

- 概览：名称、描述、所有者范围、来源、安装时间、已绑定员工、检查更新时间与结果。
- 说明：完整 SKILL.md 的可读 Markdown；商店拿不到正文时标明“提供方未提供正文”，安装预览再读实际包内容。
- 文件：相对路径树；按需读取有大小上限的文本，二进制只显示信息；Markdown 不执行 HTML 或脚本，不自动请求文档中的远程图片。
- 兼容状态：name/目录规范、无法映射的 frontmatter、所需运行时说明；普通元数据展示不自动更改工具和审批设置。
- 操作：加入/移出我的、管理绑定、检查更新、打开受管目录、移除。没有稳定更新来源的条目显示“本地副本，需重新导入”，不显示虚假的更新成功。

按员工查看“说明可用/不可用”“命令未启用/执行依赖未验证”等现有状态。K1–K4 不新增“执行就绪”的判断；同一技能在不同员工和执行后端下状态可不同，不能给全局卡片一个统一的可执行绿灯。

## 3. 本地导入和安装预览

本地目录支持单个 Skill，也支持扫描用户选定目录中的多个 SKILL.md。扫描有深度、数量和字节限制，不遍历整个用户主目录；已知本机 Agent 目录在进入技能页时只读发现；导入仍需明确预览和提交。

1. 用户选择目录/ZIP 或输入受支持的 HTTPS/GitHub 来源；界面按当前阶段展示可用来源。
2. 宿主扫描/下载到临时区，读取实际包，不运行其中程序。
3. 展示候选：名称、说明、相对路径、内容、是否重复/冲突；底部固定提示 ~/.agents/skills，不提供公共或员工专属目标。
4. 用户选择条目；默认冲突策略为跳过。同名同内容可复用已有本地目录，不选择员工或公共/专属范围。
5. 提交时再次验证预览仍有效，只安装到 `~/.agents/skills`。同名同内容复用，同名不同内容提示冲突，不覆盖。
6. 完成后刷新本地列表、收藏与商城状态。每项返回成功、跳过或失败；不创建员工资源或修改员工 `skillIds`。

安装公共技能不等于全员可用；安装员工专属技能也不自动绑定。绑定时沿用 `saveAgent`、配置版本检查和后端能力校验。安装成功但绑定失败应分别报告，保留已安装技能，允许用户重试绑定。

首个远程阶段支持三家商店给出的可验证下载目标、公开 GitHub 仓库/指定 ref/子目录、HTTPS ZIP。任意 Git 托管、SSH/私有仓库认证和自动依赖安装延后。遇到不支持的来源给出可下载后本地导入的路径，不用静默启动外部 CLI 补救。

## 4. 商店浏览和安装

提供商切换保留各自搜索条件；只展示该提供商支持的排序。页码和游标原样按能力处理；去重依据 `provider + providerItemId`，不能仅按名称合并。

列表应有首次加载、空结果、下一页加载失败、可重试错误和缓存过期提示。断网不阻塞本地资料库；有内存缓存时可展示上次结果并标识时间，首次离线则提示无法访问，不伪造推荐列表。切换搜索后旧响应不能覆盖新结果。

商店条目与已安装条目通过来源身份匹配：同名不显示成已安装；同一来源多份副本可展示数量并跳到具体副本。统计字段缺失显示未知，不能补零；提供方 verified/security report 仅显示为提供方标记，不承诺可安全执行。

安装按钮统一进入第 3 节预览。提供商详情中的任意 shell 指令或 Markdown 链接不能替代实际下载合同。安装使用取得并校验的包，记录版本/hash；不因“已验证”标志跳过本地校验或自动启用命令。

## 5. 检查更新、更新和移除

**检查更新**只读取上游，不改变受管文件、收藏或绑定。结果区分“已是最新”“发现新版本”“来源不支持”“检查失败”；失败和跳过不计入已是最新。支持手动检查全部可更新条目，但首期只逐项确认更新，不做自动更新或无预览的一键全量覆盖。

**更新**展示来源、当前/目标版本、文件变化摘要、本地修改和受影响员工。保留资源 ID、所有者和收藏关系。存在本地编辑时默认不覆盖，用户可保留当前内容或明确替换；没有可靠基础 hash 的旧资源先视为无法安全比较。来源消失、校验失败或中断时继续保留旧版本。上游变更技能 name 时首期拒绝原位更新，提示导入新资源并重新绑定，避免绕过同名规则。

更新提交前若关联员工/资源仍有活跃或等待工作，拒绝切换并提示先结束或停止相应工作；不隐藏地取消任务，也不等待占用全局服务锁。提交时重新检查，执行器未退出不能当作空闲。

**移除受管资源**展示绑定影响，沿用当前取消运行、撤销绑定和来源记忆失效流程。仅删除应用内副本及其收藏/来源记录，原始目录和其他 Agent 安装保持不变。无法安全结束使用中的执行器时，不提前删除文件；清理失败单独报告，不能显示完整卸载成功。

## 6. 旧应用数据迁入与导出

推荐使用旧应用“我的”ZIP 导出作为用户可审阅的迁移媒介；也支持用户直接选择旧 Skill 文件夹。只选择 `boai-app` 源码仓库不等于选择了用户的技能数据，不能默认扫描其 node_modules 或整个应用数据目录。

导入已有 `boai.json` / `boai.lock.json` 的库时，先预览技能、来源、快照和冲突。优先离线复制包内 `skills/` 的完整内容；来源声明用于后续显式检查更新，不在恢复时强制重新下载“最新”。旧导出不携带分组关系时，明确提示本次只能恢复技能并按用户选择加入“我的”，不声称完整还原旧收藏分组。

本应用导出支持所选技能或“我的”，携带 SKILL.md、references/scripts/assets、许可证、来源及可迁移集合信息。不包含模型凭据、对话、记忆、使用统计、机器绝对路径和执行许可。公共/员工专属作用域在导入预览中重新选择，不能凭另一台机器的员工 ID 授权。

ZIP 内用于用户自行维护仓库的 `meta.ts`、package scripts 或 Git 声明可作为文件保存，但导入时绝不执行。K4 的具体兼容格式见 [03](./03-架构合同与数据迁移.md)。

## 7. 可选统计

K5 先统计本应用实际观测到的技能加载/读取，按资源 ID、员工、会话和时间窗口聚合；去重规则需先定义。同名资源不可合并。展示“加载/读取”而不是“任务成功”，Trace 完成也不是技能交付成功。

已知 Agent 技能目录的只读发现已接入；当前统计入口展示目录/收藏/绑定数量。外部 Codex/Claude 使用统计及全局安装位置管理继续独立评估。
