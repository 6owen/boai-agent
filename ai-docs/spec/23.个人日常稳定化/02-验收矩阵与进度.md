## 3. 10项真实自用任务

以下是首批题型，尚未选定用户材料。DU0替换为实际常用任务，冻结输入、预期、允许动作与后端。每项先跑一轮，修复后第二轮完整记录；失败样本保留，同题材料更新另登记版本。

| ID | 任务 | 可用结果判定 |
| --- | --- | --- |
| UT01 | 根据两份固定资料回答一组实际问题 | 事实可定位来源；资料没有的内容明确未知 |
| UT02 | 使用已选检索服务补充资料并整理研究结论 | 引用实际读取内容；区分登录限制/提取不全，不补造正文 |
| UT03 | 根据材料生成一份实际需要的文档 | 正式交付文件可打开，满足事先列出的内容要求 |
| UT04 | 对UT03提出明确修改，切换会话/重启后继续 | 修改准确作用于目标文件，原结果和新结果可核对并找回 |
| UT05 | 本机Agent完成隔离目录内的小开发任务并通过终端或预览检查 | 文件变更符合要求；报告实际运行/未运行检查；进程正确收尾 |
| UT06 | 同一项工作跨桌面和CLI交接，过程中回答一个待决问题 | 上下文、目标与结果一致，问题只作用于正确员工/运行 |
| UT07 | 设置一个实际长期偏好，在新会话纠正并忘记 | 当前事实被使用；纠正/忘记生效；临时要求未持久泛化 |
| UT08 | 设置一项实际有用的定时资料整理或提醒 | 正确到期、等待/失败清楚、结果可找回；无重复副作用 |
| UT09 | 给两名员工分工完成研究/文档任务，并做单员工同题对照 | 依赖与最终交付正确；比较结果质量、人工介入和耗时 |
| UT10 | 从一周历史中找回指定结果及待办，并在隔离副本恢复备份 | 具体来源可定位，已保存数据与文件可核对，未重放执行 |

预定交付形式由题目决定：问答不强制生成文件。外发、删除、屏幕观察等动作不因纳入题目就自动获得权限。真实渠道/PPT/日报若成为高频工作，可在开跑前替换一项题型并保留更改原因，不无限扩张样本。
