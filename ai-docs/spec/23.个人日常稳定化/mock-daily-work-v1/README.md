# Mock：青禾周报助手

这是一套完全虚构的项目资料，供BOAI做资料问答、周报交付和修改验收。人物、项目、记录和数字都是合成数据，不描述BOAI当前项目，也不是已经跑过的成绩。

## 直接使用

1. 给一名日常员工新开测试会话，仅上传下面三份输入。不要上传验收清单。
2. 依次发送[任务卡](./任务卡.md)的四轮消息。问答轮直接回答，文件轮要实际交付可打开的Markdown文件。
3. 用[验收清单](./验收清单.md)核对事实、计算、原件和修订；记录失败，不以“完成”状态代替检查。

| 输入 | 内容 |
| --- | --- |
| [项目简报](./项目简报.md) | 目标、范围、负责人、计划与未知信息 |
| [会议纪要](./会议纪要.md) | 新日期、真实阻塞、后续动作；用于识别新旧事实 |
| [试用记录](./试用记录.md) | 固定样本、人数与批次计数；用于核对加权计算及分母 |

任务卡与验收清单供操作者查看，验收答案不混入员工的资料。模型应从三份输入及本轮消息得出结果。

## 本套能检查什么

对应第23组UT01资料问答、UT03文件交付、UT04明确修改的合成探路，并补一条已发现的通知补事实负例。跨会话或重启后的文件找回可在第三轮观察，实际行为单列记录。单员工与两员工同题对照可复用相同输入，但必须从独立干净会话分别运行。

公开检索、本机开发、CLI待决交接、长期记忆纠正/忘记、定时触发、一周历史及完整备份没有被这四轮覆盖；不能把本套当成10项真实自用任务或一周采用结果。

当前只准备材料，模型调用为0、四轮均未执行。真实运行继续使用原AppService/Mastra或桌面入口，执行前另登记代码/模型、实际调用额度和停止条件；本文件没有启动自动测试或定时任务。
