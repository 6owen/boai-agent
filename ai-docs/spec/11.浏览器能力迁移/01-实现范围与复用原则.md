# 实现范围与复用原则

日期：2026-10-02。状态：**待实施规格**。本组按用户“先接浏览器、最好照抄旧实现”制定，首批采用本地 Electron 浏览器，不选云浏览器或 Computer。

## 1. 直接复制哪些内容

旧代码源位于 `/Users/wangwenbo/Desktop/demo/boai/boai-app`。复制以实际文件和版本/hash 为准，不根据记忆重新写相似实现。

| 内容 | 优先做法 | 需要保持的行为 |
| --- | --- | --- |
| BrowserPaneManager | 直接迁入本地窗口/页面部分，局部适配宿主依赖 | 独立窗口、工具栏/页面/遮罩组合、显示/隐藏、导航状态、窗口几何 |
| BrowserCDP | 优先完整复制驱动算法，局部改日志与取消门禁 | AX 节点/ref、点击/填表/选择、页面快照、截图与页面结果校验 |
| BrowserPaneFns/types | 迁入浏览器专用共享合同并去除重复定义 | 页面驱动与 Agent runtime 分离，不向模型暴露 Electron 对象 |
| browser-tool-runtime | 保留命令词、引号处理、参数校验和动作结果逻辑 | 同一个命令产生与旧实现一致的页面动作；原导航后 ref 刷新规则 |
| browser_tool 入口 | 用 Mastra createTool 替换 Pi 注册 | 保留 `{ command: string }` 与原命令学习成本 |
| BrowserControls/toolbar | 复制布局与交互，接当前组件/主题/图标入口 | 地址栏、导航按钮、加载反馈和窗口菜单，不另做视觉方案 |
| browser-live-fx | 复用遮罩/控制视觉和平台边角算法 | 用户可分辨自动操作；视觉状态只表达真实执行，不充当取消证明 |
| HTML/preload/空态 | 同时迁入并适配 build、CSP、字体和路由 | 开发和打包均能加载；旧示例入口只改到当前明确任务路径 |
| 原测试 | 保留有价值业务意图，迁为当前测试框架 | ref/导航/页面动作和 UI 同步行为；改变的隔离/权限断言按本组重写 |

保留现有类名与模块职责。不能为“现代化”主动换 Playwright、WebContentsView、远程浏览器服务器或拆成大量空模块；需要解决明确兼容问题才做局部替换，并保留行为对照证据。旧 manager 较大不构成本批全量重构理由。

## 2. 最小必要改动

| 必须改的地方 | 原因 | 限定改动 |
| --- | --- | --- |
| 全局 `persist:browser-pane` | 全窗口共享账号，不符合多员工归属 | 页面/popup 使用员工×会话 partition；应用 UI/网页的 session 与权限边界重新核对 |
| Pi/session 工具注册 | 当前是 Mastra Agent 与 utilityProcess runtime | 保留命令实现，只换工具注册和类型化消息桥 |
| renderer 实例 ID 操作 | 显示筛选不是员工执行权限 | Main 核对宿主绑定的 scope/run/动作资格，不信模型或任意 UI 传入身份 |
| 默认 always-allowed | 统一入口含写操作、上传和脚本 | parser 后检查实际动作和明确任务授权；未匹配的外部副作用等待审阅 |
| 命令批执行 | 中间失败前面动作不可回滚，重试可能重复副作用 | 首批模型调用一次一个命令；执行前拒绝批输入，不执行第一项后才拒绝 |
| 停止/解除控制 | 原版停加载或遮罩不证明退出 | 新增动作门禁/代际/回执，等实际退出再交出控制或释放占用 |
| 下载/来源/截图 | 旧结果未接当前成果与材料来源 | 保留底层采集，增加受管文件、真实内容/hash、来源范围和原生模型图片接线 |
| UI/构建依赖 | 旧 Craft 别名、Jotai、主题和路由在当前项目不存在 | 接当前已有范式，不因复制 UI 引入整个旧应用框架 |

这是“直接迁入后适配”，不是字节完全相同。复制共享登录、审批豁免或错误重试会破坏现有产品规则，不能作为照抄验收目标。

## 3. 用户入口与默认值

浏览器能力放在**员工详情的现有能力设置区域**，以单个明确开关启用；本批不增加单独浏览器产品主页，也不改团队创建表单。

| 配置/动作 | 首批合同 |
| --- | --- |
| 新员工、旧员工升级 | `browser` 权限默认关闭；缺失字段按关闭处理，不按角色/技能/旧模型连接推断授权 |
| 用户明确启用 | 保存员工配置与权限版本；不启动浏览器、不新建聊天或工作 |
| 普通聊天/判断/记忆 | 不挂 browser_tool，不因提到“浏览器”就开窗口 |
| 已认领 task 使用工具 | 检查能力与原任务范围，首次实际需要时申请 scope 的浏览器执行权 |
| 登录资料 | 沿旧持久体验保留，但分区归员工×会话；支持明确清除，普通业务备份排除 |
| 同一 scope 多任务 | 复用登录但串行操作，同一时刻仅一个明确 run 持有执行权；旧 run 不能释放新 run |
| 同群不同员工 | 各自窗口/登录/操作权独立；不自动共享同一个群浏览器 |
| 单聊与群聊 | 同员工不同 conversation 分区独立，记忆召回与登录复用是不同规则 |
| 自动化 | 初版不自动授予浏览器执行；普通手动任务先验收，自动化若后续接入须另验原 occurrence 预算/实际退出 |
| ACP 员工 | 本组不支持注入；配置界面不可显示“已可用”，外部连接保持自有工具边界 |

页面窗口第一版依然独立于 IM 主窗口。用户从当前员工任务查看相关窗口，窗口标明操作者/任务归属。全局窗口徽标可以沿旧展示，但不能把“当前焦点窗口”作为 Agent 的可用窗口权限。

## 4. 保留的命令与首批开放范围

下表是功能交付范围，不是自动放权清单。命令先经 parser、scope/run、权限版本与目标校验，再进入底层调用；参数范围以 02 的真实源代码映射为准。

| 命令类别 | 首批处理 |
| --- | --- |
| help/open/focus/windows/hide | 保留命令体验；工具 windows 仅列当前任务获准实例，不列所有员工页面 |
| navigate/back/forward/reload | 在已授权浏览目标及跳转规则内提供；没有获得新的站点或登录权限 |
| snapshot/find/截图与区域截图 | 保留算法，输出有界、掩码敏感信息，并登记明确来源；截图确实可进入支持图片的模型 |
| wait/scroll/window-resize | 保留已有动作与结果校验；等待可取消且有界，不阻塞停止确认 |
| click/click-at/fill/type/select/key/drag | BRM3 完成授权与控制状态后开放；包括按钮、按键可能提交的情况，不统一视为只读 |
| downloads | 保留记录/等待能力；在 BRM3 将本次下载纳入受管目录和文件发布，不把下载事件当成果交付 |
| release/close | 保留名称，增强为真正执行权释放/关闭确认；隐藏、解除遮罩与关闭分别表达 |
| console/network | 保留底层诊断代码；模型首批不默认获得原始日志，避免将 Cookie/请求令牌等作为普通结果输出 |
| evaluate | 保留底层必要内部实现，但不向模型开放任意脚本命令 |
| get/set clipboard、paste | 首批不开放系统剪贴板；输入使用 scope 内明确文本，不读取用户全局剪贴板 |
| upload | 原裸路径接口不开放；后续通过现有材料/成果授权单独增加受控上传，不接受模型给任意宿主路径 |
| 分号/数组批命令 | 模型首批执行前拒绝；可保留内部 parser 源码，不开放自动批处理 |

点击/输入是否会写入网站状态不能只由工具名称判断。用户已明确授权的具体任务可以持续执行匹配动作，不要求每一步重新确认；缺失的外部副作用资格由宿主提出可审阅动作。无法可靠匹配时转人工接管。

## 5. 登录、页面信息与交付

人工登录沿旧可见窗口进行。密码由用户在页面输入，不要求发到聊天；员工在人工控制期间不能继续输入/点击。继续自动操作必须是明确动作，并重新获取当前页面 snapshot，旧 ref 不继续复用。

不复制旧共享 Cookie、用户日常 Chrome profile 或系统凭据到员工 workspace。首批没有“迁入旧登录”的按钮。持久 partition 的清除、员工删除、聊天清理和退出必须等归属执行器实际退出；清理不影响其他 scope。

网页正文和截图是外部资料，不是新权限或员工永久人格。成果里的引用使用实际 URL、获取时间及正文/截图证据；`@eN` 是操作目标。若页面资料来自私人登录，则分享给群或纳入记忆继续核对实际授权范围，不能靠 Browser 已启用自动扩权。

文件下载必须确认本次操作归属、完成状态、真实受管原件与 hash，并通过现有 `publish_artifact` 发布。附件、成果修改/采用与员工记忆继续走既有权威仓库。未完成下载和截图临时文件不冒充成果，未知回执不自动重复外部动作。

迁移过程中每项旧行为标记为“原样复制 / 必要适配 / 首批不开放”，并写出实际差异。旧截图/ref/动作校验不因接 Mastra 而删断言；旧全局 Cookie、权限豁免和提前 released 断言不能保留为新规格。
