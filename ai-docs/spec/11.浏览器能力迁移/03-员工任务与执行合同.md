## 2. 应用功能与工具装配

内置浏览器是应用功能。顶栏直接开窗、网页导航、登录和窗口生命周期不依赖业务对象。公开开窗/状态接口不接受员工或会话身份。

获准Mastra任务可调用应用浏览器工具。工具装配仍遵循现有task阶段规则：普通chat、decision、memory、重新汇报和当前不支持的ACP/自动化阶段不注入。具体网站、内容读取和对外操作逐次核对原请求和宿主批准，窗口存在不等于取得工具权限。

浏览器本身不产生模型调用，不要求浏览器服务Key，也不代表已经接通MCP或Web Search API。

## 3. 应用窗口与登录资料

应用使用确定的浏览器实例和持久登录分区。浏览器身份不拼接employeeId、conversationId或聊天清理代际；模型不能选择partition或任意实例。旧分区不自动合并账号数据，也不因升级删除。

| 对象 | 存续与边界 |
| --- | --- |
| 登录资料 | 应用统一保存；普通关闭、业务切换和业务对象删除均不清除 |
| BrowserWindow/页面实例 | 内置浏览器统一管理，重复点击复用当前窗口 |
| 自动操作租约 | 仅绑定本次Work/run/执行代际和权限；同一时刻单一实际持有者 |
| popup | 沿应用浏览器Session，不能取得产品preload或绕过网站权限 |
| 工具证据/下载/成果 | 沿实际调用的业务来源和hash管理，不决定浏览器归属 |

不提供成员选择、员工能力开关或“本会话浏览器登录资料”。任务结束/撤权只结束对应调用资格；聊天或员工清理不得关闭内置窗口或清除登录资料。

## 4. 保持单工具协议，按动作执行授权

Mastra 入口保留 `{ command: string }`，严格拒绝其他字段。工具调用身份从 SDK 实际 `toolCallId` 取得，不能让模型在 command 中设置 operationId。原命令解析器负责引号、转义和参数，不能用简单 `split(';')` 误伤带分号的填表文字。

每次调用必须只解析出一个顶层动作。命令串含多动作、换行批处理、旧数组模式或无法确定含义时，在任何 `BrowserPaneFns` 调用前拒绝；不得先执行第一个再报告后续不支持。旧批处理实现可保留为来源代码，但不能从模型路径到达。

解析后的结构只在宿主内部使用：`action + normalizedArguments`。动作分类和输入限制由代码决定；单工具保留不代表整工具沿旧 `safeMode: allow` 放行。

| 动作组 | 首批合同 |
| --- | --- |
| open、navigate、snapshot、find、截图、scroll、wait、back/forward | 在当前任务获准网站/目标内执行；导航/历史改变后重新获取页面证据 |
| click/click-at、drag、fill、type、select、key | BRM3 开放；核对目标、输入、实际页面和允许的业务效果；可能触发提交/自动保存 |
| focus、hide、release、close、window-resize | 仅内置浏览器的当前实际调用；release/close 必须执行实际退出握手，不直接复用旧立即成功语义 |
| downloads | BRM3 接受管文件后开放；仅当前获准页面，输出有界，下载列表不是成果交付 |
| console、network | 保留底层诊断代码；模型首批不默认获得原始日志，内部诊断同样有界脱敏 |
| evaluate、get/set-clipboard、paste | 模型入口首批禁用；不能通过别名、数组模式或其他动作绕过 |
| upload | 首批禁模型裸路径；以后增加授权文件身份到已核读字节的专用适配后单独验收 |

保留驱动内部确定性、固定用途的页面测量脚本，例如截图尺寸和 ref 定位；禁止让模型把 arbitrary evaluate 经“测量”入口送入页面。首批截图优先 ref/坐标模式；任意 selector 扩展须经过同样校验。

旧 `safeEvaluate`/pageMetrics 所需脚本迁入宿主固定枚举白名单，白名单决定表达式和参数边界。不是把整段旧 `evaluate(expression)` RPC 公开给模型，再依靠工具说明限制用途。

常规读取在已授权范围内连续进行。对外发送、发布、删除、购买、文件上传等效果必须获得具体授权；授权冻结目标页面/来源、目标元素、输入内容和动作摘要，变化使旧授权失效。权限判断不能只看“按钮名称不像提交”，也不能由模型回答“安全”直接授权。

登录和验证码由用户在页面处理，凭据不进入模型参数、聊天、Trace、下载日志或员工记忆。浏览器网站原生权限默认拒绝；摄像头/定位/剪贴板等旧自动 allowlist 不迁入，确需能力时由宿主按应用浏览器和用户明确选择处理。

人工登录期间停止自动快照和截图；AX 输出排除已识别密码字段值，截图按私有页面来源范围使用，不默认公开到群。页面可能自行展示敏感文本，字段过滤不构成完整防泄漏保证；需要硬范围限制的资料继续沿现有仅此聊天/明确成员授权处理。

## 5. 主进程与 runtime 的受控桥

Main 管理 Electron 窗口、CDP、网站权限和下载执行；runtime 管理 Work、员工配置、预算、来源、授权和持久回执。worker 不导入 BrowserWindow，网页 renderer 不获得 BoAI 业务 preload。

`BrowserHostBridge` 是当前 utilityProcess 通道的类型化扩展，至少承载申请实例/租约、执行一个动作、核对动作状态、取消/实际退出、普通用户导航和状态事件。不要为首批迁入旧远程 WS 协议或新增一个对外通用 CDP 端口。

一条内部动作信封包含：宿主生成 actionId、Work/run、scope、lease generation、配置/授权版本、解析后的动作和参数摘要。模型仅提供 command；身份在 AppService 当前持有者边界补入，绝不能从工具输入原样取信。

Main 只接受当前 runtime 连接的已登记租约。执行前同时检查连接代际、固定应用实例、租约仍活跃、动作身份与授权版本匹配、窗口未关闭或清理；检查通过后在实例串行队列进入动作。renderer 只提供用户操作意图，不能用任意 instanceId 直接调用底层驱动。

Main 返回含同一 actionId/代际的实际结果。迟到回复只能更新原动作核对记录，不能复活租约、释放新 run 占用或给旧阶段继续工具。错误结构区分未开始拒绝、已开始失败、退出未确认与结果未知；不统一提示“重连后重试”。

| 当前接线位置 | 唯一责任 |
| --- | --- |
| `src/main/browser/{browser-pane-manager,browser-cdp,browser-service}.ts` | 原版窗口/驱动及宿主租约/动作门禁 |
| `src/runtime/adapters/mastra/{browser-tool-runtime,browser-tool-types,browser-tool}.ts` | 旧 parser/BrowserPaneFns 与单工具 Mastra 包装 |
| `src/runtime/modules/browser/` | 必要授权、动作回执和来源合同；不再保存另一套 Work/budget |
| `src/shared/ipc/browser.ts` | 内部 DTO 与校验；不得直接复用网页可访问的任意动作接口 |

工具动作的导航策略在初始URL、重定向、弹窗和页面新导航上核对，只允许本次获准网络范围。人工正常浏览不受工具来源列表限制。`file:`、应用业务协议和直接本地资源不能因浏览器工具而取得文件权限；renderer sandbox 不是完整网络隔离的验收证据。若首批无法可靠控制某类请求，就限制该入口并记录真实边界。

## 6. 逐动作回执与副作用核对

复用同一 SQLite 权威库和 `WorkRepository` 持有者事务，不另建第二套 Work 或预算。现有 run 级 `markEffect/confirmEffect` 不能证明某次网页点击已执行几次；新增最小浏览器动作回执用于消除盲重试。

回执保存：actionId、真实 toolCallId、Work/run、scope/代际、规范化参数 hash、动作类别、授权版本、开始/结束时间、执行状态和必要结果证据摘要。字段受既有会话清理/来源范围约束；Cookie、密码、完整网络头和无限正文不入回执。

动作身份绑定原始 Work/run 与 SDK toolCallId，由宿主生成并事务保存。相同身份/相同参数返回原回执或只读核对；同身份不同参数拒绝。同文案、新 toolCallId 或新窗口不证明这是原操作重试。

缺少可信 SDK toolCallId 时在外部动作前拒绝，不能随机生成身份后执行。同一工作仍有待核对写动作时，新 toolCallId 或新 run 不解除其屏障；先核对原动作，不能通过模型再次发出同一意图绕过 unknown。

执行顺序必须固定：

1. 确定性解析并拒绝禁用/批命令；校验当前任务、授权来源与所有者。
2. 在 SQLite 事务内检查当前 Work 持有者、冻结参数/授权、受理动作回执；外部效果同时沿 `beforeEffect` 的来源/记忆屏障登记核对标记。
3. Main 校验当前租约，在串行队列实际开始前确认动作仍可执行；开始身份经桥接确认后才进入 CDP/页面操作。
4. 得到真实结束结果后，将同一动作回执及必要证据写回 SQLite；效果已结束才走 `afterEffect`，未知不能确认效果完成。
5. 返回有界结果给当前 task；发布前再次检查授权、取消和来源。数据库保存失败即保持待核对，不凭内存结果宣称持久完成。

新增受理/结果方法应与现有 Work 持有者检查组合在同一事务；必要时让既有事务辅助方法接受同一 tx，避免先读持有者再独立写回执。不要在一个已打开事务里直接调用另起事务的 `markEffect`，也不能先提交一个新动作再因效果标记失败照常执行。

取消后仍可保存原动作已实际结束的事实及用量；这不是授权继续执行、调用下一步骤或发布旧结果。`afterEffect` 的取消异常不能导致丢失真实终止回执，unknown 则维持效果核对标记。

SQLite 和网页服务器不构成一个原子事务。崩溃可能发生在“网站已处理、回执未提交”之间；必须明确保留 unknown，不能声称能够保证外部服务 exactly-once。

| 动作状态 | 意义与下一步 |
| --- | --- |
| prepared | 已受理、尚无可信开始确认；能可靠证明未发送才可取消为未执行 |
| started | 执行器已进入动作；不能按超时推断未发生 |
| completed / failed | 有匹配身份的实际终止回执；failed 仍可包含已产生效果，不能自动回滚推断 |
| cancelled_before_start | 两端可靠确认未开始；不制造成功结果 |
| unknown | 无法确定开始/结果或回执保存；保留原身份/参数，先只读核对 |

同 scope 动作串行；网页动作未真实退出时，新动作不能越过队列。纯读取 unknown 可以在确认旧执行退出后用新身份重新读取当前页面，不能把它当原动作完成。写入/提交 unknown 必须核对网站结果；缺少可靠证据时等待用户处理，不自动重放。

## 7. 普通浏览、停止、关闭与重启

内部租约/退出状态只管理工具资格，不作为用户操作权界面。手工浏览与工具调用使用内置窗口；手工导航与应用工具队列串行，不隐式切换take/resume、取消员工工作或增加approvedOrigins。动作执行状态与窗口可见状态分开保存。

停止task、撤权、清理和销毁先封住新工具动作，然后请求当前动作取消/停止并等待实际退出。CDP timeout或Promise reject只结束等待，不能当执行器退出证据；仍无法确认时保持draining/unknown。

用户随时可以正常使用地址栏、点击和登录，没有常驻遮罩、输入锁或“我来操作/交还员工”。手工变化使旧snapshot/ref/批准失效，员工后续动作重新核对当前页来源、pageVersion和命令资格；未获准的人为新页面不会自动扩权给员工。

工具栏刷新/停止加载只控制网页，不冒充任务停止；停止加载无需等待导航队列结束。X及系统关闭直接走当前窗口实际销毁/退出，不清Cookie。旧release命令仅显示/聚焦当前窗口，不退休租约、不切控制权或暂停任务；验证码提示通过原工具结果返回，员工请求用户完成验证后新snapshot，不绕过或反复提交。

task-runtime dispose除workspace外还等待该run浏览器租约释放；不能只设置disposed=true即算完成。旧run的迟到finally按持有者/代际比较，不能关闭后续打开的窗口或释放新run。

runtime 连接退出或应用重启后，Main 废止旧连接全部租约并停止旧自动控制；重启仅核对已保存动作/文件事实，不调用模型、自动继续 task、重做提交或重新下载。持久登录保留，工具执行资格不继承；unknown 核对不能自动升级为未执行。

## 8. 模型预算、网页来源和文件交付

浏览器驱动不隐含额外 LLM；员工读页面后的下一次模型调用仍走当前 `prepareStep` 和原 Work/occurrence 预算，等待登录不重置绝对期限。无需新“浏览器 token 账本”；若以后加入内部模型驱动，必须先接同一唯一调用预算。

网页结果至少包含实际最终 URL、标题、取得时间、scope 和页面证据版本。`@eN` 只用于操作定位，不是来源引用；页面导航/关键状态改变后 ref 作废。回复和成果引用实际取得的证据，不能仅凭搜索片段、窗口标题或意图宣称已读。

正文/AX、console/network 和图片输出均有明确上限与截断提示。截图走真实图片内容适配，并用实际连接验收模型能看图；只返回磁盘路径或 `image-preview` 文本不算看图。仅文本连接允许文本快照，不能宣称理解未输入的截图。

工具取得的页面证据、截图和下载按本次调用的业务来源授权保存，不因应用共享登录而自动发布。需对其他成员发布时沿现有明确来源/成果授权；网页文字和登录 Cookie 不能修改工具权限。

任务下载进入由实际run登记的受管暂存位置；先记录实际完成状态、实际文件 hash、来源 URL/取得时间和归属，再允许现有文件门禁读取。文件名不作身份，下载进行中不进入成果列表，失联不能重新触发下载。

发布下载/截图使用现有 `publish_artifact` 和真实原件 hash；下载成功、工具成功、SDK 结束均不自动记为 Work 已交付。交付必须由现有 `report_work`/提交事务引用可检查回答或已登记成果。

网页内容派生的材料、成果和记忆保存来源链、员工获知证据、聊天范围及有效期；进入员工记忆仍用现有 SQLite 记忆合同。来源撤权/会话清理阻止旧快照继续调用、工具读取和公开发布，不把网站内容写入永久根身份文件。

## 9. 清理、备份与排错

浏览器 Cookie/网站存储/持久分区、未完成下载和临时截图默认排除业务备份。已明确发布的成果按现有成果规则备份，必要来源元信息和最小动作回执随业务数据备份；备份恢复不导入网页登录、不恢复自动控制、不重放动作。

清空会话、解散群或删除员工只结束对应工具调用并清理其业务证据/下载，等待实际退出；不得关闭内置浏览器、轮换分区或清除应用登录资料。

受管下载/截图清理使用所有权和原 hash，外部修改保留并记录待处理；浏览器分区不作为普通材料目录暴露给 renderer。业务证据清理失败保留修复门禁和原回执，不以应用登录资料作为待删除的业务文件。

Trace 仅记录实际动作和脱敏摘要，关联原会话/员工/run；不把 Span 结束当网页效果/交付证明。诊断/只读回执查询不得启动浏览器新操作，隐藏页面暂停 UI 查询但不删除在途回执。

## 10. 必须通过的运行验收

实施步骤和唯一进度以 [05-实施步骤与验收清单](./05-实施步骤与验收清单.md) 为准；本节限定业务不变量。

| 验收触发 | 成功证据 |
| --- | --- |
| 新旧 Mastra 员工普通聊天/任务及旧 false/缺失字段升级 | 默认可用，普通聊天不挂工具；仅获准 task 有工具，停用/ACP拒绝 |
| 切换/删除不同业务对象 | 内置窗口与应用登录持续保留，工具调用资格独立核对 |
| command 批动作、伪造窗口 ID、禁用动作/别名 | 首个底层动作之前拒绝；不能从旧 parser 支路绕过 |
| 旧授权后目标/输入/页面变化 | 再核对并拒绝旧授权，未经确认不产生对外效果 |
| CDP慢操作时停止/关闭，旧 run 迟到回调 | 保持 draining；实际退出后释放，旧 run 不干预新租约 |
| 网站已提交后桥接失联/数据库写失败 | 保留 unknown 和原参数；只读核对，不自动重复提交 |
| 准备回执后或实际动作中重启 | 无模型/业务重放；恢复仅核对，登录资料与工具执行资格分离 |
| 下载中取消、外改、重复文件名、清理失败 | 不伪造成果；实际文件/hash/来源明确；外改保留且问题可见 |
| 业务对象清理、业务备份恢复 | 不清应用登录、不恢复工具执行；只恢复已发布业务事实 |
| 文本/视觉连接读取公开网页并交付成果 | 原预算覆盖后续模型步骤，真实来源可查；图片路径不冒充看图 |

模块、事务和协议用 Vitest；真实 Electron 窗口/应用登录保持/实际退出/打包路径沿仓库 playwright-bdd。旧测试只作迁移参考，always-allowed、按业务对象划分登录、立即 release 的断言必须改为上述业务意图；在真实验收前保持“待实现/待验证”。
