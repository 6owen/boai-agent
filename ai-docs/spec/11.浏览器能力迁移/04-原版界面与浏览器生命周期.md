# 原版界面与浏览器生命周期

本篇锁定当前浏览器交互，包含 2026-10-02 用户明确要求的普通浏览器行为。此前接管/交还菜单与遮罩合同由本篇覆盖；历史测试成绩不自动证明新交互已通过。实际实现与验证进度统一见 [05](./05-实施步骤与验收清单.md)。

## 1. 窗口结构照搬

保留旧实现的独立无框 `BrowserWindow`，初始 1200 × 900、最小 700 × 500。不把页面改成 IM 右侧内嵌网页，也不在本阶段替换为 `WebContentsView`。

```text
独立浏览器窗口
┌───────────────────────────────────────────────────┐
│ toolbarView：返回 / 前进 / 地址栏 / 刷新或停止 / X   │
├───────────────────────────────────────────────────┤
│ pageView：真实网站页面或原版浏览器空态               │
│ 旧 nativeOverlayView 不覆盖网页、不阻挡用户输入      │
└───────────────────────────────────────────────────┘
```

保留原窗口/CDP 路径和必要的窗口尺寸监听，工具栏固定48px，仅窗口实际尺寸变化时调整页面布局。删除菜单扩展工具栏高度及覆盖页面的透明点击层；普通点击不得触发整页遮挡、尺寸切换或导航刷新。

窗口先隐藏，待工具栏真实准备完成再显示，避免开窗白闪。加载失败明确显示错误，不能将失败记成工具栏已成功运行。退出过程中迟到的布局事件不能访问已销毁对象。

页面不加载 BoAI 业务 preload，不启用 Node；工具栏使用专用最小 preload。UI 组件能调用的导航接口不等于网站页面能访问这些接口。

## 2. 保留的视觉资产与必要替换

| 原资产 | 迁移要求 |
| --- | --- |
| `BrowserControls` | 保留地址栏、导航按钮、加载进度、URL 编辑/提交和主题随窗口切换的布局 |
| `browser-toolbar.tsx/html` | 普通导航/加载工具栏、标题栏拖动与X直接关闭；无菜单尺寸测量 |
| `BrowserTabBadge/BrowserTabStrip` | 旧组件已删除；主界面统一使用header浏览器图标 |
| `BrowserEmptyStateCard` | 保留原版居中卡片、介绍和示例提示布局 |
| native overlay / live-fx | 不再作为网页输入锁或员工操作遮罩；不显示操作权状态 |
| 明暗主题与窗口背景 | 接当前外观状态和语义 token，避免复制第二套主题系统 |

迁移时替换 `@craft-agent/*` 包别名、旧 i18n 初始化和旧路由；按钮、菜单和输入复用当前 Base UI/shadcn 封装。图标从 `src/renderer/components/icons/index.tsx` 的本地 Iconify 适配取得；旧 Lucide import 不原样搬入。

旧 Jotai atoms 改为当前状态范式，保留状态职责和必要更新逻辑，不引入 Jotai 作为第二套全局状态。地址栏局部编辑仍可使用 React state。

若实际迁入空态使用旧 `BrowserShader`，保留组件及效果，单独接其 `@paper-design/shaders-react` 直接依赖；不为避免该依赖重写效果，也不复制旧 UI 整包。manager 自带 native overlay 与该 React shader 是两项资产。

旧视觉层含 `color-mix()` 等表达；迁入时用现有 token/静态视觉值表达同一效果，不新增平行颜色函数体系。保留减少动态偏好、键盘访问和窄窗口可达性。

## 3. 应用内置入口

Header右侧地球图标直接打开内置浏览器；重复点击显示同一窗口，不弹成员选择或登录资料设置。窗口标题及工具栏只呈现浏览器/网页信息，不显示员工、聊天或工具持有者。

## 4. 主界面与状态

浏览器入口属于应用框架，不依赖当前sidebar页、聊天选择、员工列表或模型配置。开窗只操作浏览器；不生成消息、Conversation、Work、Run或模型调用。

浏览器窗口使用全局稳定身份。应用事件驱动更新当前浏览器状态，业务页面切换不改变实例。关闭中的迟到事件不能复活旧窗口或改写新窗口状态。

## 5. 登录与浏览器资料

网站登录统一存于应用浏览器的持久Session。关闭/重开、应用重启保留登录；切换、清空、删除聊天和员工不更换分区、不关闭窗口、不清登录。

旧按业务对象创建的分区不自动合并不同账号Cookie，也不擅自删除；不读取日常Chrome/Safari资料。登录资料不进入业务备份。

popup和重定向沿内置浏览器Session，网站页面没有产品preload，原生网站权限默认拒绝。

## 6. 普通浏览器操作

| 操作 | 用户看到的结果 | 宿主必须完成的事实 |
| --- | --- | --- |
| 查看 | 窗口显示并聚焦 | 显示同一个实例，不新建或改绑任务 |
| 返回 / 前进 / 地址栏 / 刷新 | 按普通浏览器导航 | 与应用浏览器动作队列串行；不暗中接管、交还或取消整项员工工作 |
| 地址栏停止加载 | 当前页面停止加载 | 不宣称任务、CDP 操作或业务提交已取消 |
| X / 系统关闭按钮 | 直接关闭当前窗口 | 挡新动作、处理在途执行、关闭弹窗/View/CDP并收到实际退出回执；保留登录资料 |

刷新只刷新当前网页；停止加载只停止网页请求。任务停止仍属于聊天中的原工作操作，不放进浏览器工具栏。窗口关闭与清除持久Cookie是两件独立操作。

关闭失败显示实际错误；收到宿主终态前不伪造关闭成功，实际执行资源必须等退出才释放。

## 7. 手工浏览和工具调用

用户输入、点击、登录不依赖“接管/交还”，不锁网页输入或窗口缩放。模型动作仍属于原Work和租约，按已批准来源、命令hash和页面版本执行，不能借用户打开其他网站获得访问或提交资格。

手工地址栏导航与应用工具动作串行；停止加载可以及时终止当前网页请求。手工页面变化使旧ref和批准失效，下一员工动作必须重新取得当前证据；结果未知仍只核对，不重放。

检测到验证码时显示原窗口并向员工返回真实验证提示，由员工请求用户完成验证后重新snapshot。没有不可见的pause/take等待或“交还员工”要求；不得绕过验证码或反复提交。

窗口打开、聚焦或人工登录不会自动恢复停止/交付过的工作，也不临时创建Work。原预算、绝对期限和未知副作用屏障保持。

## 8. 状态同步与迟到事件

公开实例状态仅投影内置实例ID、状态revision、URL/标题、加载/可见/关闭状态；任务归属不进入浏览器产品状态。模型不从 renderer 的 active ID 取得操作资格。

主进程是实例生命周期事实来源。runtime 提供 Work/预算/能力授权；renderer 只展示对应版本，不能自行把任务成功或窗口关闭写成事实。

收到较旧 revision、旧控制代际或已关闭实例的事件时忽略。remove tombstone 必须保留至有权威更新可判定其失效；旧 list 响应不能清掉 tombstone 复活实例。

列表核对响应携带明确查询范围和版本。跨会话、切页和取消请求后，迟到结果不能覆盖当前列表或导航用户；读取失败不把当前实例列表清空成“全部关闭”。

下载和关闭事件同样遵循身份/版本核对。SDK stream结束和列表为空都不是执行器实际退出证据。

## 9. 关闭、重启与文件展示

关闭内置窗口等待在途工具、页面与下载实际退出；对当前调用的停止沿原Work边界，不取消其他独立工作。旧关闭请求和旧实例回调不得销毁或覆盖重开的窗口。

窗口生命周期结束不等于清除持久 Cookie。明确清除 profile 要先结束对应动作/实例，再核对受管目录归属；清理失败可见，不能报成功后后台继续删除。

应用重启只核对已有动作/工作记录，将未结束操作保留为中断或待核对，不重建浏览器并自动继续网站操作。用户明确启动新的任务才创建新的实例执行权。

截图保留原无 Agent 遮罩的页面捕获体验；提供给模型时必须传真实图片内容并验证模型支持，不能只返回 `image-preview` 路径文本。

人工下载使用原生保存。工具下载进入本次独立暂存区，只有完成且hash核对后才复制到受管运行目录；发布成功后才计为成果交付。工具结束不取消人工下载。
