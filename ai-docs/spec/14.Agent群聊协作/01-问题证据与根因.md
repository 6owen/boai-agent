## 4. 结论与推断边界

确认的事实：首两位存在没有前置结果的并发生成；后两位看见旧结果仍报1；五个独立意图未形成共同约定；后续沉默没有纠正错误；调度完成状态不能证明业务效果。

设计判断：需要在“多人独立参与”之外表达请求级协作关系，让顺序准入、前置结果和结束条件由共享状态落实。只加历史、只改气泡排序、只限制并发数量或只加一句“请合作”，均没有同时解决上述缺口。

不能证明的内容：单次现场不足以给出失败率；未对照不同提示或模型，不能精确归因其占比；研究员报4与看到三条回复一致，但不能证明它在执行一个正确的全群协议。
