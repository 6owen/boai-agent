## 1. 用户要求与概念

- “控制电脑的Agent”指：用户通过BOAI向本机Codex、Claude Code等Agent下达任务，由该Agent执行，BOAI承接指令、交互、过程和结果。
- 控制对象是本机Agent。调研具体关注程序调用、任务输入、原生会话接续、运行中交互、取消和结果回传。
- 原生工具、登录与配置、MCP、Skills、hooks、插件、子Agent等能力应尽量保留；是否存在接入损失，需要源码和真实对照证明。
- 远程电脑以后再说。本次不设计电脑环境、机器节点、VM/容器或桌面键鼠控制。
- 先查Lody、Raft、Cindy的GitHub实现再确定BOAI的缺口。用户认为数据一致性大致正常，本轮不凭空追加存储或执行内核重构。
- 前端整体卡顿单列后续专项；语音由另一session推进。最初研究批次仅文档，2026-10-28已按用户授权开展首轮真实对照与缺口修复，范围见02/03。
