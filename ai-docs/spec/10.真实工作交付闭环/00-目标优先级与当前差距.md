# 目标、优先级与当前差距

日期：2026-10-01。状态：待实施；本页为源码审阅基线，实施前重新核对。

## 1. 成功标准

用户可以把真实材料直接交给员工，检查实际成果，围绕指定版本修改并采用；离开后能找回成果和需要自己处理的事项。普通交流保持轻量，只有明确任务进入既有工作执行体系。

产品是否成功看实际成果、用户采用、返工和耗时，不看员工数、回复数或成功 run 数。

- 员工统一记忆、作用域与来源失效、编辑/固定/忘记，见[统一记忆实施](../2.已实现功能与代码现状/26-员工统一记忆实施.md)。
- Skills 本机发现、收藏、商城、安装/更新与便携库；自动化预算、通知、历史与明确接续，见[Skills 实施](../2.已实现功能与代码现状/21-Skills管理与商店实施.md)和[自动化实施](../2.已实现功能与代码现状/22-自动化增量实施.md)。

## 4. 首批与后续范围

| 首批必须交付 | 后续按独立切片增加 |
| --- | --- |
| TXT/Markdown 附件与来源、会话授权 | 文本 PDF、页码与解析版本 |
| Markdown 成果预览、旧版保留、明确修订与采用 | 图片/PDF 预览、文本差异等格式增量 |
| 员工显式技能绑定、已有能力状态可见 | 必要网页能力或依赖验证，沿原专题另行定义 |
| 待处理投影、精确来源动作 | 多来源筛选与更复杂聚合 |
| 确定性正文/文件名搜索与稳定阅读边界 | 依据真实需求评估语义检索 |

OCR、Office 在线编辑、更多商店、云同步、强执行隔离、G4 自动恢复和专用游戏不进入本组默认范围。新能力应有独立场景与验证，不能借本组界面自动改变现有运行边界。

## 5. 必须保留的不变量

1. 普通 chat 不创建 Work；附件准备和预览不触发模型或工作。
2. 来源授权、员工身份与会话范围由宿主核对；安装技能不等于授权使用。
3. 运行结束、业务已交付、用户采用、通知回执分开保存。
4. 修订保留旧结果；不按同名推断版本，不让旧版审核/采用自动继承。
5. 接续和预算沿现有工作/自动化规则；用户修订须显式定义新请求及预算归属。
6. 停止后等待实际退出，重启只核对，不自动调用模型或重放已执行/结果不明工具。
7. 新数据同时接入迁移、清理、撤权与备份；不能只删除可见界面。
8. 页面详情标签保持作用域隔离；输入框上方不增加常驻运行状态条。
