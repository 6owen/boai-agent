## 第一个可交付版本

> 用户在已有私聊/群聊中上传两份 TXT/Markdown 资料，员工输出有来源依据的 Markdown 报告；用户在应用内查看，针对确定版本提出一处修改，采用新版；切换会话、重启后仍能找到资料、版本与采用记录。

先用可验证的文本资料完成链路，文本 PDF 作为独立切片增加。空白 bobo compose 首批先发送目标，再在已建立会话中添加材料；附件首发需另行扩展原子受理合同。简单任务可由一名员工完成；多人协作使用已有工作、委派、依赖和预算机制，不固定要求研究员/写手/审核员全部参加。
