# 性能与内存验收合同

2026-10-13，用户明确性能测试必要，并要求检查后台常驻的内存泄漏。功能通过、单进程模块通过或短期RSS下降均不能代替性能门槛及长期资源验收。实际结果/失败与证据唯一见[02 §5](02-设计与实施验收.md#5-性能与资源增量验收2026-10-13)。

## 固定门槛

| 场景 | 门槛与不变量 |
| --- | --- |
| 一万项工作历史 | 五组全量计数及30/30/100条有界读取总计小于3秒；100条页小于1秒；保留授权、父子、同条件计数、游标与失效语义 |
| 检索规模 | 原15000条消息/32个文件的检索正确性与耗时门槛保持；输出每次实测 |
| 窗口/设置循环 | 预热后210次隐藏/重开、70次设置切换；原窗口、runtime PID及创建时刻不变，宿主监听器计数不增 |
| 隐藏消息 | 本地API协议夹具28条消息，每条一次完整员工回复；不冒充真实飞书或DeepSeek质量验证 |
| GC后内存 | 预热至结束，Main/Renderer JS堆增长分别小于16 MiB；DOM文档增长不超过2，节点小于1500，DOM监听器小于150 |
| 进程资源 | 原Main/Renderer/runtime单进程RSS增长各小于64 MiB；固定窗口和runtime不被重复创建 |
| 后台空闲 | 默认120秒，每15秒采样；最后5次Main/Renderer/runtime CPU之和的中位数小于5% |
| 正常退出 | 原真实退出收尾、偏好写入及隔离目录清理，失败/未知不伪装成功 |

门槛是有界回归信号，不是“无泄漏”的证明。初始数据、缓存、JS堆、DOM/监听器、工作集和空闲增长须分开阅读；CPU/RSS会受运行模式和系统压力影响。窗口隐藏保留界面和草稿，其固定占用也要计入常驻成本。

## 采样方法

- 原生窗口/进程指标由[Electron app.getAppMetrics](https://www.electronjs.org/docs/latest/api/app#appgetappmetrics)获取；工作集单位为[KB](https://www.electronjs.org/docs/latest/api/structures/memory-info)，JS堆和DevTools堆按字节另计，不把共享内存重复求和当实际总量。
- Renderer使用[HeapProfiler.collectGarbage](https://chromedevtools.github.io/devtools-protocol/tot/HeapProfiler/#method-collectGarbage)、Runtime.getHeapUsage及Memory.getDOMCounters。Main在隔离测试中通过Node内建模块执行GC；产品不添加GC开关、轮询监控或私有调试IPC。
- PID结合创建时刻核对进程身份。初始化/预热后留基线，每批操作及空闲周期留原始JSON；退出前留图/trace并归档。主进程监听器与DOM监听器分源检查。
- 查询优化先测同数据/查询计划与耗时，再核对新旧SQL结果。不得放宽原3秒门槛，不能通过缓存旧授权或省略全量计数加速。
- 源码阅读与第三方SDK检查只作为风险线索；[Electron官方性能指南](https://www.electronjs.org/docs/latest/tutorial/performance)的测量方法不代替本项目实际压力结果。

## 重复运行

```sh
pnpm exec vitest run tests/work-views.test.ts tests/search-quality.test.ts
pnpm test:bddgen
BOAI_TEST_DEV_SERVER=1 BOAI_REVIEW_RUN_DIR=.local/reviews/background-resources-new \
PLAYWRIGHT_JSON_OUTPUT_NAME=.local/reviews/background-resources-new/playwright-results.json \
pnpm exec playwright test --grep @background-resources --reporter=list,json
```

`BOAI_RESOURCE_IDLE_SECONDS`可设120–86400秒，例如1800秒为30分钟空闲观察，86400秒为24小时。运行前应保存实际源码/核心构建hash清单；报告由`generate-feature-review.mjs`沿原F11设置分组生成。长空闲观察与连续大量消息、真实飞书断网重连、图片/文件媒体压力分开，不混报覆盖率。实际未运行的时长或平台继续标未认证。
