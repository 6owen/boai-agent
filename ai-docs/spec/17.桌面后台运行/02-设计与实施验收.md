# 设计与实施验收

## 1. 当前合同

用户授权桌面后台运行，GitHub 选型见01。默认启用“关闭窗口后继续运行”，系统登录启动默认不注册。默认“登录后隐藏启动”只在实际登录启动且系统托盘可用时生效；手动启动显示主窗口。当前开发模式不注册真实系统登录项。

- 关闭主窗口时隐藏同一 BrowserWindow，原 renderer/草稿及唯一 utilityProcess 保留。网络渠道、模型调用和日程由原 runtime 处理，不新增消费者、服务或消息副本。
- 托盘菜单提供打开、关闭窗口后继续运行、退出。设置→运行选项提供后台选项、开机启动、登录后隐藏启动；UI沿用原Card/Switch与文档留白。
- 托盘、Dock activate、二次启动、通知点击共用主窗口入口。隐藏/最小化时恢复显示；窗口已销毁时重建原安全窗口，浏览器窗口不阻止主窗口重开。并发重开不创建多个主窗口。
- macOS全屏关闭先退出全屏再隐藏；期间重开取消待隐藏动作。托盘初始化失败时保持可见且关闭走系统原行为。
- 关闭后台选项时保留原窗口关闭习惯、未保存保护；显式退出/Cmd-Q始终真正退出。隐藏窗口上的未保存退出先显示窗口再询问。退出拒绝新IPC动作，等待runtime实际exit、浏览器/材料资源和设置写入完成。stopped回执或kill不算实际exit。
- 登录项仅安装后的macOS/Windows应用可操作。Windows固定当前可执行文件及`--boai-login-start`参数，按同路径/参数查询实际状态；macOS只用openAtLogin，不使用失效的openAsHidden。系统批准、查询失败与不支持状态明确展示。
- 偏好保存在主进程独立`desktop-settings.json`，布尔白名单、版本校验、串行原子保存。损坏/未来格式保留原文件且禁写。系统登录项不进入业务备份，Renderer无任意命令/路径注册权。

关闭窗口与退出、电脑休眠、关机、终端停止pnpm dev分开：本功能仅在应用进程仍运行且电脑开机联网时继续工作，不自动防休眠、不新增云服务或崩溃重放。

2026-10-22新增设计交接：当前托盘仍使用固定像素字母B。[第3组21 §8](../3.前端重构与功能/21-macOS应用与Dock图标切换.md#8-应用图标与托盘联动2026-10-22仅文档)规定后续共用外观`appIconId`显示对应单色模板；`BackgroundTray`继续唯一持有原Tray，换图只更新图片，不重建菜单、监听器或Runtime，也不改变后台/登录/退出规则。图片更新失败保留可用托盘及原菜单；Tray自身不可用沿本组现行处理。该增量仅文档，素材/实现/验收尚未开始，实际进度统一归21 §7；本组既有资源与生命周期成绩不能代替新图标验收。
