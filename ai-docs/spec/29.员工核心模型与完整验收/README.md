## 当前实施顺序

1. 固定员工模型：员工、workspace、长期memory、主聊天、任务、群会话的归属。
2. 打通单员工闭环：主聊天续接 → 独立任务执行 → 任务结果与员工记忆衔接。
3. 统一执行能力接入：不同Agent保持相同员工产品逻辑，并验证事件、回执、取消与恢复。
4. 打通群组闭环：各员工群内session续接 → 单人或多人任务 → 结果回到群中。
5. 完善员工交接：持久化context handoff、依赖关系和交接回执。

插件整理、浏览器稳定性和任务稳定性嵌入以上闭环，不作为独立重做产品的理由。首条完整验收路径固定为：**一个员工从主聊天接受工作，在独立任务session中完成，再回到主聊天继续交流，并能正确记住这次工作。**
