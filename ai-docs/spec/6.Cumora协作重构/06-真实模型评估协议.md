# 真实模型评估协议

登记时间：2026-09-28，首次供应商场景运行之前。使用本机唯一配置的 `deepseek-flash`，保留实际供应商类型与模型 ID。金额价格未知，以调用、输入/输出 token 记录成本，不推测美元金额。

## 固定范围

- 基线为 `87010ab` 独立只读源码；候选为本次当前源码。保存提交、四个关键源码 hash、模型、成员规则、提示文本和采样参数。
- 两个版本共用 `tests/evaluation/cases.ts`。9 个场景：6/12 人介绍、旧群问候、正式 @、自然点名、仅要计划、委派后汇总、独立文件交付和合法沉默。
- 正式每场景 5 次，全部成功/失败都保留。先允许一轮不计入正式结果的连接/场景试运行，试运行仍留档；不能只挑成功样本。
- 每个样本创建隔离数据库和工作区；不复制用户聊天、记忆、文件或成员规则。只读连接配置和系统凭据，明文 Key 仅通过进程内存/IPC 传递。
- 每版本最多 600 次真实请求，每个场景阶段最多 120 秒；产品本身的调用/运行/输出/时间预算继续生效。超限停止并保留失败，不扩大预算直到通过。

## 预设门槛

1. 程序安全/一致性门槛必须全部通过，来自已有真实 SQLite、SDK 协议和 Electron 回归；真实模型样本出现越权、假完成或重复副作用同样视为失败。
2. 6/12 人场景要求每位有效成员获得首次判断，100% 样本满足；合法 pass 不强制变为回复。逐条复核身份、是否符合邀请及多余附和。
3. 正式 @、自然点名、旧群问候、仅要计划与合法沉默，每个场景至少 4/5 样本满足语义条件，且候选不得低于基线。正式 @ 的非收件人抢答必须为 0。
4. 委派和独立产物交付至少 4/5 样本满足完整用户目标，不能仅依据 run completed 判定。候选必须有实际依赖/交付证据；基线缺少新协议时按原有公开结果评估业务目标，明确标记结构能力差异。
5. 简单社交场景的首次有效回复中位延迟不超过基线 1.25 倍，判断阶段已报告输入 token 均值不超过基线 1.10 倍。样本只有 5 次时逐样本报告，不把小样本 P95 当稳定性能保证。
6. 用量缺失保留未知。只有已报告字段、调用数和请求字节可比较；不得把未知 token 当 0，或把请求字节直接当 token。

首次可见回复由程序计时，首次**有效**回复依据人工语义复核选取消息 ID 后计算；二者不能混称。输出全文、阶段失败、投递结果、工作状态、产物文本及供应商请求状态均保留。有效运行比例、无进展、发布补判与等待开销从实际记录计算；无法测得的指标明确标记。

## 执行与比较

```sh
pnpm eval:collaboration --label candidate-pilot --samples 1 --cases explicit-mention
pnpm eval:collaboration --label baseline --source /path/to/baseline --samples 5
pnpm eval:collaboration --label candidate --samples 5
```

输出默认在 `.local/collaboration-evaluation/`，每样本一份 JSON，包含待语义复核字段。脚本不会加入默认 `pnpm test`。更换连接必须指定 `--connection ID` 并重新登记模型配置；不得跨模型直接归因代码收益。

全版本比较反映本次协作改动的合计效果，不能把所有收益归因某一处输入省略。输入省略本身的无损性另由单元测试证明；若比较失败，保留结果、分类诊断，再以新标签运行修订后的候选，不删除或覆写先前样本。

凭据若因系统加密环境不同而无法解密，可在本地终端设置 `BOAI_EVAL_API_KEY` 后运行；该值不会写入参数、结果或工作区，并在凭据桥交给 worker 前从子进程环境移除。也可在当前应用设置重新保存连接。不要把 Key 放入命令参数或聊天记录。

## 采样容量修订（候选正式采样之前）

原 600 次上限保留在上文和第一批 `baseline-formal` 配置中。实际第一轮 9 个基线场景共需 168 次请求，5 轮预估 840 次，原配置无法满足既定采样数量。这是评估容量配置错误，不把达到评估请求上限造成的中断归因产品或模型质量。

完整比较改为**每版本最多 1,000 次请求，包含分批补齐与连接检查**。不改变场景、每场景 5 次、质量/延迟/token 门槛、产品自身预算或单阶段超时，也不因业务失败重复跑该样本。第一批达到 600 上限后保留完整结果；只补齐尚未开始或被评估上限截断的样本，使用 `--sample-start` 保留样本编号。截断尝试另列，已消耗请求计入 1,000 总额；完整的失败样本不得替换。若 1,000 仍不足，报告未完成，不继续扩额。

首个候选试运行显示普通解释被归类为任务，已在正式候选采样前明确聊天/执行边界并精简重复轮次指令。该试运行完整保留，不能作为新候选正式成功样本。
