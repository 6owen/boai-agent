## 1. 材料输入与实际读取

入口继续是原聊天composer、原生文件选择、真实文件粘贴/拖入和已有消息材料。文本路径、网页说明及外部Agent声称的路径都不是文件读取授权。

| 输入 | 目标接入方式 | 不能假称的能力 |
| --- | --- | --- |
| TXT/Markdown | 宿主核验原件/hash/当前范围后，提供有界正文或受控文件引用 | 收到文件名不等于读过正文 |
| 图片 | 按适配器核验能力提供原生图片输入或本次获准的受控文件 | 不因接受输入就认定模型理解图片 |
| 通用文件 | 保留原件与类型/大小；按真实能力选择受控引用或明确不支持 | 不把二进制复制说成已解析PDF/页码/OCR |
| 历史材料/成果 | 绑定明确材料或成果ID、版本/hash与来源消息 | 不按同名文件猜最新内容或跨聊天检索 |

沿用当前材料上限、受管存储和解析合同，不借本机Agent接入放宽前端任意路径读取。原件不直接放进所有员工可读的共享目录；需要临时文件时，记录员工、会话、run、来源/hash和归属，只有本次获准运行取得引用。

新附件的接收范围仍是当前聊天成员；旧显式名单仅按历史兼容规则处理。宿主在准备输入、每次可介导的读取、业务工具调用、公开结果提交与记忆写入时复核当前成员、材料版本和来源资格。

将材料交给外部程序前，适配器必须说明实际数据去向：程序的本机目录、原生session、可能使用的云模型，以及是否写入其自动记忆或日志。用户选择本机运行方式不等于授权所有聊天材料进入所有外部账户。

外部已读数据无法通过撤权“收回”。撤权应立即阻止BoAI后续读取、桥接、发布和记忆投影，并中止受影响运行；不能证明旧session不再使用撤销内容时，废止它在BoAI的续用资格，按当前授权重新准备。不得声称删除BoAI材料同时抹掉外部缓存、日志或服务端历史。

外部原生工具若可以绕过宿主直接读取文件，不能展示为与现有受控材料相同的隔离能力。受限材料能否交给该配置由已核验的实际边界决定；不满足策略时拒绝该组合，保留其他不依赖该材料的用法。

## 2. Skills与本机资源

优先复用本机Agent已经支持的技能加载机制，不再让BoAI模型解释一遍技能并代替其运行。BoAI负责保存“选了什么、给了谁、实际加载了什么”，适配器负责将该选择映射到已验证的运行时配置。

| 来源 | 授权与加载要求 | 状态展示 |
| --- | --- | --- |
| BoAI已绑定Skill | 沿用Resource、来源hash、员工configVersion；按支持机制提供确定版本的受管副本或配置引用 | 已绑定、已准备、运行时确认加载、未验证分别记录 |
| 外部本机技能目录 | 用户明确选择目录/配置profile及使用范围；记录真实路径、版本与发现机制 | 原生发现不等于BoAI授权或依赖可执行 |
| 本机项目规则/工具配置 | 明确本次运行实际继承的规则、插件与MCP配置；不自动继承其他项目 | 未核验的自动发现能力显示未知 |
| 技能依赖与登录 | 使用明确动作验证；不因保存员工配置而安装依赖、登录或执行脚本 | 可读、依赖可用、执行验证分别表达 |

同名不同来源技能不得静默覆盖或合并。若外部运行时无法限定扫描范围，应明确其真实加载集合；不能一边继承整个用户技能目录，一边把界面勾选的少数条目说成唯一有效权限。

技能更新、绑定变化或外部配置变化应使相关能力核验失效。活动任务按冻结版本执行或按原取消/退出合同终止，不在运行中静默替换技能；撤权后禁止新的调用和结果提交。外部源文件不由BoAI擅自改写或删除。

Skills说明只提供任务方法，不能修改宿主审批、成员权限、预算或成果登记规则；技能脚本产生的文件也必须走正式发布。

## 3. BoAI记忆与原生session

BoAI的员工记忆继续以现有MemoryRepository、来源、作用域、epoch及清理代际为权威。外部session是运行时上下文，不替代员工记忆，也不直接成为其他聊天的背景。

- 启动阶段只注入当前员工、当前聊天与任务获准的记忆投影，记录实际提供的条目及版本；不复制完整私有记忆库。
- 原生session按员工、会话、运行时配置及阶段关联；私有decision/memory协议与公开聊天/任务历史隔离。恢复须核对记录，不通过员工姓名或目录相似度找session。
- 原生压缩摘要、会话历史与自动记忆文件只能作为标明来源的外部状态；不得不经提取与授权校验就写入BoAI长期记忆。
- 只有确实支持无工具memory阶段、结构化候选与来源映射的配置，才开放自动记忆维护；显式混合路径可交给用户选定的控制后端。能力缺失保持关闭，不借另一模型悄悄补全。
- 私有维护以当前轮的实际完成消息为新增证据。定向接续若因进度更新改用最新用户消息作触发，只有本员工本轮已公开交付的原Work可补入其精确原用户请求；该请求必须仍在当前会话的有界获准窗口内。模型输入与MemoryRepository提交白名单使用同一来源选择；其他历史、其他员工、未交付/待核对工作不随之扩权。旧原请求只提供事实证据，不取得纠正已有记忆的当前用户权限；维护沿原工作预算和绝对期限，失败不重放业务。
- 记忆撤销、材料来源失效或配置切换后，旧session不能携带失效上下文继续代表当前员工；安全重建不能重放原业务工具。
- 清理BoAI记录与请求外部删除分别留回执。外部不支持删除或无法核对时如实保留限制，不把本地删除完成写成跨系统清除成功。

原生长session的便利不能改变成员历史授权和成果来源资格；一个员工参加两个群仍是两个授权范围。尚未证实隔离的运行时不得复用同一原生session串联这些范围。

## 4. 可选MCP业务工具桥

可以把BoAI已有业务用例通过本地MCP或适配器原生工具桥暴露给获准运行，不强制所有适配器都使用MCP，也不因此自动引入通用外部MCP商店。

工具桥只做协议适配，最终调用原有宿主用例；不建立第二份Work、Artifact、员工或自动化数据库。候选能力包括受控材料读取、正式发布成果、查询获准工作、委派/等待真实群成员，以及仅bobo可用的组织工具。

每次调用绑定宿主签发的短期运行资格与employee/conversation/run/work身份；参数中的自报身份、聊天文本或原生Agent角色声明不能取得权限。审批前后、实际操作前与提交事务均复核当前版本，退出或撤权使资格失效。

业务写操作沿稳定请求身份及原事务回执：已提交返回原结果，载荷冲突拒绝，结果未知先只读核对。桥连接重试不意味着重跑发布、建群、外发或文件操作；缺乏可靠回执的原生副作用必须保持待核对。

普通员工不得调用bobo专属组织接口；桥接工作查询也不自动取得全部员工私聊。MCP连接本身不授予文件、命令或网络范围，外部原生工具与桥接工具的授权和观测能力分别记录。

## 5. 交付、审批与宿主边界

外部Agent输出文件路径、文本声明或运行成功，只能形成候选结果。正式成果必须由宿主核验来源、当前权限、真实文件及hash，先持久登记精确的发布准备身份，再复制到受管位置；成果登记与准备记录清除在同一事务提交。未提交复制文件不能在重启或备份恢复时被导入为历史成果，清理仍只删除hash匹配的原件。版本/hash、原消息、Work及适用修订关系保持可检查。

成果采用、稍后处理、要求修改仍在原员工交付消息办理；右侧保持只读内容/版本/来源。修订绑定用户所见版本/hash并创建原合同要求的新根工作，不把外部session续聊当旧Work自动续命。模型审查、运行成功与本人采用分别保存。

审批继续出现在原聊天请求卡，显示实际动作与范围，并绑定本次run/请求。只对外部协议真正交给宿主的动作承诺“允许一次/拒绝”；外部程序可绕过协议直接运行的命令不能伪装成被BoAI逐次拦截。

`cwd`、独立HOME、临时目录、MCP连接和禁用客户端文件桥都不是操作系统沙箱。需要硬隔离的配置必须另有实际核验的执行环境；用户已选择的外部登录也不使BoAI有权复制密钥或继承整套宿主环境。

取消先关闭后续业务提交，再等待协议/进程及受管文件处理实际退出；临时文件只清理本次拥有且hash匹配者。备份仅纳入明确支持的已提交业务数据，不复制外部凭据，也不在恢复后重发原生prompt或重放工具。

## 6. 验证与进度归属

本篇能力按阶段接入，不能用首批工具交付代表全部资源能力；进度、支持的适配器版本和证据只在[06](./06-实施步骤与自动验收.md)登记。验收至少覆盖实际图片/文件输入、同名来源、撤权后session失效、技能加载集合、跨群记忆隔离、正式发布/固定版本修订、协议审批拒绝、未知回执、实际退出及重启零重放。

握手成功、一次文本答复或外部自己声称已加载技能，均不足以证明材料/Skills/记忆/工具桥已交付。界面证据、真实运行证据与人工效果分别记录；不支持的能力保持显式状态。

## 7. 本次宿主工具桥选择（2026-10-10）

Codex/Claude执行能力复用已有NativeTool桥。读写、技能、命令申请、Work结果和成果发布仍由宿主按当前冻结来源执行并返回真实回执；原生文件修改/命令及插件、全局技能或子Agent不因打开前端入口而启用。文件候选不等于已发布成果，运行完成不等于Work交付。模型目录请求只返回模型名称，执行清单不返回密钥、私有员工提示或工具正文；固定运行详情沿原授权读Trace和已发布成果。详见10 §13、06 §119。
