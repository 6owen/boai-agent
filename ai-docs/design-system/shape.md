## 圆角遵循容器用途

| 变量 | 用途 |
| --- | --- |
| `--radius-control` | 按钮与输入控件 |
| `--radius-card` | 相关内容的卡片容器 |
| `--radius-composer` | 消息输入的较大容器 |
| `--radius-pill` | 圆形与胶囊形标记 |

支持连续圆角的浏览器使用 squircle；其他浏览器保留圆角回退。不要为每个页面重新定义一组曲率。

## 一盏光源

控件的细边缘与高光来自同一套 Soft 变量。输入不带底部外侧阴影，按钮保留轻微抬升感。悬浮层使用较明确的层次，普通内容不需要反复叠加阴影。

## 分割线

水平与垂直分割使用 [Separator](/components/badge)，Card 页脚与表格沿相同细线变量。通过留白与一条边界组织层级，避免同一处重复画线。

## 动效

按下、悬停和布局变化保持短促。减少动态效果设置下，控件过渡与骨架动画应关闭，状态文字和业务反馈继续可见。
