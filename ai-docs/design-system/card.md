## 一个主题的完整结构

Card 用来聚合一组相关信息。完整结构由标题、说明、就近操作、主体和可选页脚组成。

| 部件 | 用途 |
| --- | --- |
| `CardHeader` | 标题区域 |
| `CardTitle` | 这一组内容的名称 |
| `CardDescription` | 简短用途说明 |
| `CardAction` | 标题区右侧的操作或状态 |
| `CardContent` | 字段、内容或列表 |
| `CardFooter` | 与这组内容关联的操作 |

## 使用分寸

普通列表使用普通行。只有信息需要被作为一个主题一起理解时，才建立 Card。避免在每张卡片中再套多层卡片。

卡片的边缘、背景和页脚分割复用 Soft 变量。大小使用默认或 `size="sm"`，页面通过容器适配可用宽度。

## 语义

Card 本身是布局容器，不会自动赋予内容标题层级。需要文档语义时，在内容结构中使用正确的 heading。可点击卡片应有明确动作、键盘支持与可访问名称。
