## 先保留已知结构

能确定最终布局时，先显示标题、容器、字段和接近内容尺寸的骨架。数据到达后在原位替换，避免整页从空白突然出现。

## 可访问状态

在区域上设置 `aria-busy`，并提供可理解的区域名称。骨架只表示内容尚未就绪，不代表任务已完成或操作成功。

## 合理的等待反馈

| 情况 | 反馈 |
| --- | --- |
| 已知内容布局 | Skeleton |
| 用户提交后的等待 | 原按钮的加载/禁用状态 |
| 可测量进度 | 明确进度值 |
| 请求失败 | Sonner 与原位置的重试入口 |

减少动态效果时骨架保留形状，停止动画。多次刷新已有内容时，优先保留已加载结构与阅读位置。
