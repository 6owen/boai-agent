## 何时使用

按钮触发一个明确动作。名称表达动作与对象，例如“保存更改”“新建项目”。导航使用链接，通过 `render` 复用相同的按钮表面。

| variant | 用途 |
| --- | --- |
| `default` | 一组操作中的主要动作 |
| `secondary` | 次要操作与中性控件 |
| `ghost` | 工具栏、就近的轻量动作 |
| `outline` | 需要轮廓的次要动作 |
| `destructive` | 后果明确的危险动作 |
| `surface` | 复用 Card 表面的可点击容器 |
| `link` | 文字链接形式 |

## 尺寸

默认控件高度为 32px。`xs`、`sm`、`lg` 分别用于较小、紧凑和较大的操作区域；图标按钮使用相应 `icon` 尺寸，并提供可访问名称。

## 状态

`disabled` 必须真实阻止操作。异步提交时使用禁用状态、加载提示与必要的提交锁；公共 Button 不创建任务、管理审批或猜测业务进度。

使用键盘时保留可见焦点。颜色与字号继承主题，调用者的 `className` 主要负责布局。
