## 先表达用途

颜色变量描述用途。正文使用 `--foreground`，次级说明使用 `--muted-foreground`，操作使用 `--primary`，卡片使用 `--card`。组件继承当前主题，页面不用逐项指定明暗色。

| 变量 | 用途 |
| --- | --- |
| `--background` | 应用外层底色 |
| `--card` | 控件与卡片的表面 |
| `--foreground` | 正文与主要内容 |
| `--muted-foreground` | 说明、占位与次级信息 |
| `--primary` | 主要操作与强调 |
| `--border` | 轻量结构边缘 |
| `--destructive` | 危险操作与失败状态 |
| `--success` | 已完成或成功状态 |

## Soft 表面

表面由中性色、高光、细边缘和阴影共同构成。输入框使用 `--shadow-input` 的内侧边缘；按钮与 Card 可以使用 `--shadow-control` 的轻阴影。颜色变化发生在同一套语义变量中。

## 状态与明暗

状态必须有文字或可识别的形状。避免只靠红、绿区分结果。默认浅深配色来自同一个纯解析器，主操作会选择具有可读对比度的前景。

组件不读 BOAI 的偏好存储。浏览器宿主选择当前模式，桌面宿主继续按原配置解析主题并覆盖变量。
