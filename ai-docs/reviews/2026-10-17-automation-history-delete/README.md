# 执行记录删除

每条记录右侧增加删除按钮和Popover确认。打开确认时固定所见版本，取消无请求；运行/等待/取消中的记录禁删。后台还核对真实适配器退出，不能绕过按钮直接删除活动任务。失败仅Sonner，保留重试入口。

先写持久清理意图，独立任务使用原ConversationHistory清理实际工作区、原生暂存、过程/快照/Trace与已核对下载；来源撤销、hash冲突、符号链接边界保持。共享聊天旧任务仅清本次Run的日志和浏览器下载，保留共享文件、消息及其他执行。实际清理成功后保留无正文的最小触发去重身份，历史查询分页前排除，旧请求与日程核对不重跑。启动恢复未完成清理，SQLite随后压缩。

任务计划、其他执行和主私聊中已经送达的公开消息保持；删除会关闭所有页面中该次执行的过程标签，迟到查询不能恢复列表行。没有自动批量清理用户记录。
