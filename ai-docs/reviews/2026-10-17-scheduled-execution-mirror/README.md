# 定时任务的实时执行镜像

原公共接收只同步Message正文，主聊天的活动卡只读取本会话runs。任务Run仍在隔离执行会话，因此即使任务右侧有reasoning/工具，主聊天也没有对应执行卡。固定消息定位还会关闭原“最新页执行卡”显示资格，直接追加底部卡仍不能覆盖用户的跳转路径。

现在ConversationDetail提供只读executionMirrors，引用原Run和已发布的真实指令锚点；聊天在该指令旁复用ExecutionFeed，直接读取原conversationId/runId。定位指令时也显示，原会话changed事件刷新仍有效；运行、等待批准、返回reasoning和工具沿同一数据源。流式回答不会与执行卡重复，终态恢复普通最终答复，隐藏页面停读。

宿主按公共接收的同一个确定性消息身份直接查找，不遍历聊天历史。原任务/occurrence/消息、当前成员和执行可读资格均核对；清空后失去镜像资格，原执行仍可继续。没有新建/复制Run、Work、turn、预算、上下文，也未发送第二次模型请求。群任务保持同一原群归属。
