首批PDF/XLSX/PPTX失败发生于打开“文件记录”：插件懒加载完成时，包含标题的占位框被整个替换，菜单节点消失。正文实际能够渲染，但该交互是生产回归。修复为默认插件只提供正文，宿主标题在Suspense/ErrorBoundary外保持；既有同步文本适配器保留自身模式/标题组合，惰性插件禁止接管标题。增加实际React菜单状态/节点保持回归，未改测试等待或跳过菜单来规避问题。

初次类型检查发现新增测试Promise回调允许空组件，已修正类型；最终通过。首批缺少运行前构建清单，报告保留1项留证缺口；最终已在运行前记录构建，生成报告零留证缺口。过程中一次补丁因重复目标文件被工具拒绝、未写入，修正补丁后正常应用。

实际检查最终PDF、表格及交付自动切版的原生全窗口PNG，标题/正文和第二版显示正常；人工视觉评价仍待用户。Electron为macOS源码构建、离线模型协议加实际工具/文件/IPC，不代表真实供应商内容效果、发行安装包或其他平台认证。图片插件沿原组件接线，本批未新增图片桌面场景。
