暂停与后续事项

以下事项保留记录，不计入上面的 20 项验证进度，也不会因为打开或填写此页而恢复实施。

本机 Codex / Claude已有部分实现 · 后续开发与兼容验收暂停

员工绑定、连续聊天、文件交付和群协作等已有接线及分批证据。完整稳定性与故障矩阵尚未完成；代码、入口、配置、历史和原成功/失败证据保留。

Pi 与 A2A 外部委托尚未完成接入 · 延后

Pi 没有独立员工后端。A2A 尚无完整产品接线，后续再考虑由 Mastra 委托外部服务；当前没有自建 Claude / Codex 包装服务。

五类模型阶段简化优化方向 · 尚未实施

判断、聊天、执行、汇报、记忆阶段仍保留。暂停本机路线不会自动减少 Mastra 的调用阶段，需依据实际体验再决定怎么简化。

代码项目与远程扩展独立后续功能 · 当前未完成

Git 项目、worktree、PR / 合并、专门 AI 审查、远程机器、手机端及对外 MCP / API，不属于当前已完成的产品功能。

  • PDF / Office 可作为文件接收和保存，未接正文解析、OCR 或页码引用；图片理解依赖模型能力。
  • MCP 连接管理、独立 Web Search、Computer、LSP 不能列作已完成入口；本地全文搜索不等于互联网搜索。
  • bobo 明确复用指定已有群属于后续扩展；当前组织流程建立新群。
  • 资料库主页面、独立待处理页面和专用狼人杀已退役；相关现有操作以当前聊天、技能和任务入口为准。
