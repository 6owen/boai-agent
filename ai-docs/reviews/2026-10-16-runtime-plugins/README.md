测试暴露并修复：首次插件会话安装标记缺失、控制帧undefined字段校验、原生代理/CA继承、原生action回复的过早提交标记、provider命名空间碰撞、活动更新/获取租约竞争、更新丢失停用偏好，以及“请求批准”对Pi原生工具权限的误导。原失败保留在日志中。运行时包页与原预览/主题页共用入口，但持久配置独立，一类坏配置不会伪装成另一类已损坏。

真实Pi需先在原生Pi登录界面重新登录供应商，再进行新的真实批次。本次没有自动登录、修改个人BOAI连接、重发失败业务、安装OpenCode、提交或推送Git。

尚未认证：真实Pi连续多轮/文件/停止/重启，真实OpenCode；插件渠道、完整自动化触发、浏览器、图片/材料和业务备份恢复的新桌面矩阵，长期资源、发行包及其他操作系统。SDK仍是候选版，旧Codex/Claude独立插件包装和完整错误信封未发布；市场/A2A/不受信代码沙箱另期。
