# 通讯录详情与执行入口

员工工作方式、能力事实及群目的/共享知识使用与定时任务相同的紧凑Card字段行；群成员、归属定时任务与执行记录使用相同的图标/两行列表。计划仍跳转全局定时任务管理，成员仍定位原员工资料。配置保存、成员、授权和聊天归属不变。

“查看执行详情”改为页内Collapsible，首次展开才加载；收起或离开页面停止订阅与读取，已加载节点保留用于关闭动画。员工保留会话筛选；群直接查询本群执行。原游标分页保持，每页有界；检索明确仅针对已加载记录。刷新保留原列表，迟到响应不能恢复旧页面。

点击记录按conversationId、agentId、runId打开原全局右侧面板，复用TraceTab/ExecutionFeed，只显示选中那次运行。不同Run独立标签，同一Run重开复用；精确查询旧记录不依赖第一页。活动正文、思考、工具和定位聊天沿原组件；读取失败仅Sonner，记录删除后不残留旧卡片。

详情滚动条在容器最右侧，scrollbar-gutter:stable预留；编辑正文也预留。选择员工/群及进入或退出编辑时复用个人资料的8px Panel reveal，结束释放transform/filter，减少动态效果直接显示；后台数据更新不触发页面动画。折叠复用现有shadcn/Base UI高度过渡。
