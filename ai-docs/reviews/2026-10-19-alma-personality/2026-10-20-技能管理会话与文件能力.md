# 技能管理、会话与文件能力

本批新增六份技能，已通过原技能库和员工绑定协议安装到当前 bobo。当前共 **16 项**，configVersion **46**、人格 profile revision **16**；原十项未覆盖或重绑。共享源与实际员工副本逐项核对一致。普通员工仍通过原技能选择入口独立绑定。

| Alma 原技能 | BOAI 实际能力 |
| --- | --- |
| skill-search | 按已绑定→本地库→市场查找；使用现有技能发现、读取和市场协议 |
| skill-hub | 扫描/安装/创建/编辑/更新/移除/绑定/分类，复用原版本、hash 和持久回执 |
| thread-management | 会话列表、详情、消息分页、打开主私聊、清空隐藏；本批补公共 `sessions.search` 和 `sessions.rename` |
| file-manager | 原文件列举/搜索/读写/局部编辑/移动/删除与命令工具；保留目录授权和原件检查 |
| send-file | API/本机共同的 `publish_artifact` 和原文件卡、交付证据 |
| system-info | 原命令执行与 macOS 兼容诊断；读取真实机器数据 |

源文件位于 `resources/agent-skills/boai-*/SKILL.md`。研究目录保持原件；未将不能执行的 Alma CLI 命令当作已接入能力。会话改名沿原核心会话规则，普通员工/群名称仍属于各自配置；没有新增任意 Alma 线程、跨渠道切换或强制桌面导航。技能安装不会给员工增加不存在的工具或权限，也不会自动覆盖已有独立技能副本。

## 记忆诊断与人格效果

原先评估器只能看到通过验证后返回的记忆，失败候选会丢失。本批增加仅显式开发评估使用的校验前观察器，传出候选和输入的副本；消费者不能借修改副本改变生产校验。无效来源仍硬拒绝，不修补 ID、不静默丢弃候选、不重放模型请求。

这次来源错误没有复现，所以不能宣布旧问题已修复。新的反思仍写了“窗外的光在下午四点左右落得最快”，没有对应来源；也推断用户性别/性格、未观察的白天状态。**人格真实性仍未达标。** 本批没有应用新的文学表达候选，反思源保持原 v3。
