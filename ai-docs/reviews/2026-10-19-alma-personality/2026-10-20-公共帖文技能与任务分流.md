# 公共帖文技能与任务分流

Bobo 已绑定第 31 项 `boai-twitter-media`。当前版本 71、人格配置 revision 16，原 30 项身份和顺序保持；31 项源文件、员工副本与构建产物一致，40 份研究技能原件未改。空闲核对后重载原 `pnpm dev`，服务健康。

## 实际改动

- 新增共享只读 `read_twitter_post`：只接受真实 X/Twitter 帖文 URL，固定无凭据公共提供方，校验返回 ID，保留完整正文、作者和媒体来源；大小/超时/取消有界，调用前后复核员工绑定和源版本。API 与本机工具桥共用；没有账号操作，也不把元数据冒充视觉读取。
- 判断阶段原来只显示前 20 项技能，现在显示本人全部绑定技能，并提供实际聊天读取工具、任务命令/文件能力元信息。读取技能说明仍可聊天；实际下载和文件交付进入原 task。私有阶段没有新增可执行工具，权限与审批保持。
- macOS 的直接 curl 没有自动读取这台机器的系统代理，造成 CDN 下载超时。技能下载流程改用 Python 默认代理处理，整体期限与大小限制、独占新文件写入、原发布工具保持；没有修改系统代理或关闭 TLS 验证。
- 评估新增公开交付检查：运行完成但答复被扣留，或没有实际公开答复，不能再算成功。产品本身的证据门禁未放宽。

## 实际结果及失败

| 批次 | 模型请求 | 结果 |
| --- | ---: | --- |
| 原命令技能基线 | 21 | 图片真实交付；文本与不可用帖文错误宣称没有执行能力 |
| 仅任务分流 | 12 | 正文已取得，但最终答复因精确证据不匹配被扣留；图片 curl 超时，后续未运行 |
| 仅只读工具 | 30 | 文本读取成功；图片请求错误留在聊天，没有交付文件 |
| 工具与分流组合 | 14 | 文本成功；图片正确进入任务，仍在 curl 下载处失败，后续未运行 |
| 准备失误中断 | 4 | 编辑路径错误后意外启动旧候选，发现后终止；保留部分请求/数据库，不能算成功 |
| 系统代理下载流程 | 25 | 图片交付、目录查询完成；不可用帖文无替代图片，但原因解释仍有错误 |

六批共 106 次模型请求，累计 1252 次。公共帖文工具另有 8 次 HTTP，开发探查 7 次，既有搜索 HTTP 3 次；命令内部网络请求单独保留在轨迹中，未冒充完整 HTTP 总量。已返回用量合计输入 2,430,145、输出 20,735、总计 2,450,880 tokens；准备失误中断的 4 次模型请求全部计入，但该运行没有成功终态。详细每批用量、路径、hash 和原回复见 [twitter-media-workflow.json](twitter-media-workflow.json)。

最终图片是 NASA 指定帖文的第一张原图，JPEG 2048×1536、209,332 字节。来源文件、公开成果和独立 CDN 下载 SHA-256 均为 `4a8d483991447072dd38ea7e2d9b6fa9adce3a06539cd0e2d8a808d1a5209980`。没有用帖文的 YouTube 封面替代图片，没有生成新图。原件见[隔离运行交付目录](../../../.local/twitter-post-proxy-candidate/.local/personality-evaluation/twitter-post-proxy-ready-1792461523677/data/workspaces/1d75d4a1-3db9-4b6d-9b22-a97e460dafb6/artifacts)。

不可用帖文仍未达到语义标准：工具明确说提供方不可用、原帖删除状态未确认，但模型最终写成“原帖已删除或设为私密”，还尝试了多余后备端点。只能确认没有伪造替代文件，不能确认这段解释正确。图片答复也仍复述了无需说明的约束，语气没有获得人工或独立评分认证。没有继续采样挑选更好回复。

## 验证与边界

224 项相关检查通过，类型检查和源码构建通过。新增检查覆盖 URL、身份、Fx/vx 不同格式、过大内容、取消、绑定撤权、API/native 共用读取，以及公开答复被扣留的检测；它们不能替代真实提供方可用性或语义评审。

普通只读 SQLite 打开曾失败；实际进程退出后，将数据库及存在的 WAL 一并复制到短路径私有快照恢复读取，复制前后核对原件 hash，未用忽略 WAL 的方式读活动数据库。初次类型/测试准备、heredoc、Header 定位和工作目录错误都保留，未计入通过结果。

当前没有登录或读取任何真实社交账号，没有外发消息，没有日常聊天测试，没有 E2E、安装包或 git 提交。公共镜像只证明它当时返回了什么。[FxEmbed 文档](https://docs.fxembed.com/api/introduction/)及[当前状态接口](https://docs.fxembed.com/api/twitter/operations/2statusid/)是提供方参考，未把旧样例的 404 删除或换题冒充成功。
