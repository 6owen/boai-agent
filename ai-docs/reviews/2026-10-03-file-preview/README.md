模型使用离线协议服务，不能当成真实供应商模型的交付质量评价。图片来自原 trace 的 screencast 帧，五张 JPEG 均按原始压缩字节复制并实际查看确认，无裁剪、重绘、重编码或清晰度增强；并非标准连续录屏。原帧为 800×533，放大不会增加细节。

这些 trace 包含测试步骤源码，**不包含足以确认完整运行时源码版本的源码摘要**。不补记当前 HEAD 来冒充当时运行版本。已核对两个旧场景临时数据目录均已不存在，本页没有归档这些原产物，也不会用截图或脚本内容重建“原件”。完整 trace 没有复制进本样例，之后如果旧测试目录被清理，仍可核对本目录已归档帧的哈希，但无法仅靠本目录重放全部 trace。

Markdown 源码的停留很短：源码首行断言 `call@137` 结束后约 9.217 毫秒的最近实际帧仍显示源码，已逐张查看后选用。其他帧根据对应点击/断言时间附近选取；具体偏移写入 manifest，未把事件时间强行等同于绘制完成时间。

本页只读展示，没有伪造人工批准按钮，没有自动保存“通过”评价，也不代表其他功能或完整采用/修订/审批流程已在本次样例中获得验证。
