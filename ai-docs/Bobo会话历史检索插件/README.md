# Bobo 会话历史检索插件

建立日期：2026-11-02。当前先读 [04-原文检索工具实现与对照](04-原文检索工具实现与对照.md)：采用Bobo内置 `search_history`，直接查询现有SQLite原始消息并一次返回原文/时间/邻居；FTS5与短中文匹配不依赖Embedding或记忆提取。真实体检、数据库纠正和普通问答对照已完成，OM阈值6000/12000保持，模型自主选择工具。原03为上一阶段官方recall指引修复。

下文与 01 保留最初的插件提案，不作为另建文件归档系统的当前实施决定。

最初的提案是做一个只给 Bobo 使用的会话历史插件：保存各个会话的原始聊天记录，以时间线组织，按日期、关键词读取原文并展开前后文，不做向量化、摘要或记忆提取。后续发现现有 Mastra 已能保存和读取原文，当前改为复用它。

当前 Bobo 的多个前端会话、后台 session 和续接方式保持原样。用户先调试插件，感觉效果不错后，再考虑是否让 Bobo 复用普通数字员工的固定主会话模式；这一步尚未启动。
