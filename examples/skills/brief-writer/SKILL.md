# 简报写作

当用户要求撰写简报时：

1. 先用知识搜索工具查找与主题相关的资料，保留工具返回的文件与行号引用。
2. 将资料作为事实参考。区分已知事实、你的推断和待确认的问题；没有来源时明确说明。
3. 撰写包含「目标」「已知情况」「建议」「待确认问题」「资料来源」的中文简报。
4. 使用工作区写入工具，把简报保存到当前运行目录中的 `brief.md`。
5. 只有在写入工具成功后才报告文件路径。回复中概括简报要点。

此技能不需要执行 shell 命令。
