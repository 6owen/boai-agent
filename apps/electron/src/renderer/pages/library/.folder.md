# library

技能工作区、商店与共享资源详情；资料库主页面已删除。

一旦我所属的文件夹有所变化，请更新我。

| 成员 | 地位 | 功能 |
| --- | --- | --- |
| `resource-detail.tsx` | 共享详情 | 保留受管资源正文/来源、收藏、员工与会话绑定和明确移除操作，供设置等页面的详情标签使用 |
| `use-local-skills.ts` | 目录 Hook | 按客户端/升级版本缓存本地目录并复用在途请求；手动扫描及安装升级失效，迟到响应不污染新快照 |
| `skill-list.tsx` | 技能列表 | 收藏沿会话Collapsible自然布局，展开不触发虚拟测量/自动滚动；本地全目录沿TanStack Virtual，保留拖拽/焦点/菜单行，共用技能行、DragList与键盘定位 |
| `skill-list-item.tsx` | 共用技能行 | 资源库本地/收藏及员工选择复用的图标、名称/来源/说明和按钮皮肤，兼容原拖拽与选中状态 |
| `use-skill-collections.ts` | 数据 Hook | 跨页缓存、合并读取/事件、相同版本不重算，提交代次隔离旧响应；持久收藏读取、版本冲突和迟到响应隔离；旧后台排序协议错误提示完整重启 |
| `skill-export-dialog.tsx` | 便携导出 | 首步仅预览/导出按钮，直接导出先冻结校验后原生保存，加载仅在当前按钮内且保持按钮宽度，无独立状态提示；冲突显示错误，无底部关闭按钮；同一 Dialog/Popup 按步骤替换收藏选择与文件预览，沿用模型连接的 520/620px 宽度切换，无叠加弹窗；仅列出现存收藏并默认全选，无批量选择按钮，页脚左侧计数；无收藏时禁止导出，选择变化后旧预览不可保存；独立文字列避免复选框拉伸，无 description/技能库名称输入，单输入框实时过滤收藏名称/来源，右侧检索按钮聚焦搜索框，无简介紧凑列表，导出沿用默认技能库名称；冻结预览/同名冲突/排除文件展示和原版 BoAI 仓库 ZIP 保存 |
| `skill-export-preview.tsx` | 目录预览 | 目录箭头复用全局样式，收起向右、展开向下；第二步以共享 Card/ScrollFade 展示无列表圆点的实际目录和文件大小；无导出说明，仅保留阻塞错误；最左侧带左箭头的 ghost 返回、右侧总量/保存，加载仅在保存按钮内，进入时聚焦标题；不持有 Dialog/Popup，返回保留选择，在本步骤保存 ZIP |
| `skill-import-dialog.tsx` | 导入交互 | 本地/收藏菜单的技能库导入弹窗，只接受 BoAI ZIP/目录；所选技能安装到本地并加入收藏，恢复包内分组，旧库无分组也可收藏；单图标右侧 DropdownMenu 合并导入/重新扫描/检查更新/导出，8px 菜单留白与舒展条目；导入面板锚定同一按钮向右显示，400×420 浮层保留来源 Tabs/拖入/扫描/多选/当前结果，无安装记录和底部关闭按钮；仅安装到 ~/.agents/skills，无员工或范围选择 |
| `skill-content.tsx` | 内容阅读 | 真实安装来源、本地修改提示、安全 Markdown、文件及更新入口 |
| `skill-marketplace.tsx` | 商店界面 | 各来源搜索/分页/重试、缓存反馈和现有标签内详情，来源/正文共用 Card；统一技能导航插槽、按实际 local 身份显示已安装/跳转本地详情、商城来源 Tabs、胶囊搜索工具栏/显式选中列表、同行右侧排序 Tabs；搜索挂入常驻工具栏，移除说明图标，详情共用SkillDetailPanel/Body |
| `skill-preview.tsx` | 包预览 | 安装/更新共用的实际正文与受限文件读取 |
| `skill-update.tsx` | 更新交互 | 详情更新状态/差异放入图标 Popover，进行中仍可打开，正文预览按需加载；可组合到标题栏/结果行的检查与升级图标，旋转进行中状态；内嵌文件差异、已运行更新重连、未知内容基线/本地修改显式确认；本机不显示员工绑定 |
| `use-skill-installations.ts` | 数据 Hook | 按 provider 与精确来源 ID 显示已安装副本 |
| `skill-markdown.tsx` | 安全正文 | 相同正文跳过 Markdown/Shiki 重渲染；本地和商店共用 Markdown/Shiki 渲染，移除 frontmatter，不执行远程内容 |
| `skill-update-batch.tsx` | 批量检查 | 更新详情的12px收起箭头；所属页面/标签隐藏时暂停列表轮询，恢复不重启检查；Shell 常驻详情标签启动本地检查，复用任务与产物的切换/关闭/收起与滚动容器，供技能页及共享详情使用；进度/停止/中断、结果行内展开差异和图标升级，合并最新单项检查与操作状态，已升级不重复显示为可更新 |
| `skills-workspace.tsx` | 技能目录与本机详情 | 本地/收藏/商城持续挂载同一Tabs，搜索独立插槽，固定标签宽度；列表保持，选择交给Shell右侧LocalSkillPanel；扫描/导入导出/收藏分组/拖拽/更新保持，隐藏详情停止正文读取 |
| `skill-groups.tsx` | 成员 | 标题加号随行悬停/聚焦显示、新建时保留并继承 label 颜色；无额外行间 gap 的紧凑 34px 分组浮层、全局拖动/键盘排序与计数；原位重命名、同行新建表单，无上下移动与行首图标，删除前浮层确认 |

| `customization-workspace.tsx` | 工作区入口 | 技能/数据源分类、按技能/MCP/API/本地文件夹复用会话Collapsible动画，组内有界虚拟列表；主目录和系统右侧详情并存；行内源操作回执原位更新/删除同步侧栏及详情 |

| `skill-detail-layout.tsx` | 共享详情表现层 | 本地与商城共用标题栏、ScrollFade、图标标题、元数据和正文卡片；不发起数据请求 |
| `catalog-transition.tsx` | 目录过渡 | 原Panel reveal淡入/位移，结束释放变换上下文 |

| `prompt-templates-view.tsx` | 提示词目录 | 技能式列表、搜索、CRUD Dialog与确认删除；所见版本保存，错误统一Sonner |

| `use-prompt-collections.ts` | 集合读取 | 提示词独立缓存、版本化变更与失败回读、迟到/卸载隔离 |
