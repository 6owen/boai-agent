# contacts

按群聊和联系人直接浏览资料；员工基础配置在原页分区编辑，高级配置和群聊配置使用Dialog，发消息才跳转会话。
独立选中项由 Shell 持有，编辑复用未保存守卫，不复制领域数据。

一旦我所属的文件夹有所变化，请更新我。
