画板宿主仅负责入口、位置、原IPC适配与操作反馈。文档、会话隔离及编辑由独立画板包提供。
一旦我所属的文件夹有所变化，请更新我。

| 成员 | 地位 | 功能 |
| --- | --- | --- |
| `bridge.ts` | 宿主传输 | 固定员工作用域的类型化命令、瞬时导出下载及URL释放 |
| `import-intent.ts` | 导入待核对意图 | 失败保留原操作身份，显式放弃仅清客户端重试意图，不删除宿主文档/回执 |
| `host-barrier.ts` | 全局提交屏障 | 汇总可见/隐藏视图，零视图仍单次回执，备份hold/resume按身份释放 |
| `menu.tsx` | 员工入口 | 画板列表、新建/导入与稳定重试身份；二级确认放弃待核对后重选文件，隔离迟到结果 |
| `workspace.tsx` | 容器装配 | 同一控制器供右侧/中间/Dialog使用，迁移前保存、人工提交/备份屏障、独立viewId、选区复制/导出与二级确认放弃草稿重载 |
