# shared

跨进程共享的领域类型、IPC 合同和外观数据；内部执行合同归 runtime。

一旦我所属的文件夹有所变化，请更新我。

| 成员 | 地位 | 功能 |
| --- | --- | --- |
| `appearance/` | 子目录 | 共享外观 DTO、内置色板、默认值和语义表面 token |
| `domain/` | 子目录 | 共享产品实体、员工头像、原问题回复版本/消息关系和领域类型 |
| `ipc/` | 子目录 | 跨进程方法、事件、消息、问题卡所见版本补充、工作树停止和 DesktopApi |

browser.ts 承载 Main/runtime 私有租约/动作合同及 Renderer 获准会话窗口状态；公开开窗/控制只携员工与已有会话身份，人工归属不伪造 Work/Run。

| `plugins/` | 插件合同 | 内置预览/主题清单、兼容/启停及视图生命周期 |
