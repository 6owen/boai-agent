# shared

跨进程共享的领域类型、IPC 合同和外观数据；内部执行合同归 runtime。

一旦我所属的文件夹有所变化，请更新我。

| 成员 | 地位 | 功能 |
| --- | --- | --- |
| `appearance/` | 子目录 | 共享外观 DTO、内置色板、默认值和语义表面 token |
| `domain/` | 子目录 | 共享产品实体、员工头像和领域类型 |
| `ipc/` | 子目录 | 跨进程方法、事件、消息、工作树停止和 DesktopApi |

browser.ts 承载 Main/runtime 私有租约/动作合同及 Renderer 获准会话窗口状态；公开控制只携员工与会话身份。
