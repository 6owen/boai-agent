# main

Electron 宿主层，负责窗口、IPC（含受管 Skills 安装/更新及商店）、外观、凭据与数据迁移。

一旦我所属的文件夹有所变化，请更新我。

| 成员 | 地位 | 功能 |
| --- | --- | --- |
| `appearance.ts` | 文件 | 外观配置、图片、分模式颜色、字体与缩放的校验/迁移/持久化 |
| `decode-image.ts` | 文件 | 图片解码和尺寸检查 |
| `local-configs/` | 适配层 | 本地配置有界扫描、密钥留在宿主、选中配置重读及协议/来源保留、Codex 登录与 ACP 程序发现 |
| `main.ts` | 文件 |放行员工删除/群解散接口； 放行个人资料保存与只读活动查询；放行定时任务草稿、创建回执和显式恢复；放行持久消息表情回应 IPC；扫描来源 API 配置测试重读凭据并复用草稿测试，扫描不保存；放行通讯录分类/排序偏好 IPC；ACP 候选只读预填、草稿测试 IPC 与新草稿保存/测试前扫描来源复核；持久通知串行领取/提交/失败回执及窗口重载后精确导航； 放行纯日程预览与分页历史 IPC； 技能目录/ZIP 原生选择与 File 拖入授权、技能库原生保存与本地来源授权、安装/更新/批量检查/清理恢复 IPC； 本地 API/ACP 配置扫描、原生目录选择、显式导入 IPC、 显式自动化补充 IPC、自动化运行结束提示不宣称业务交付、桌面窗口、原生菜单/快捷键缩放、编辑密钥回填/模型目录/草稿连接测试与会话列表/历史清理 IPC、未知方法的完整重启提示与运行进程生命周期、只读会话 Trace 查询；放行本机发现；按已验证 ID 打开/定位 SKILL.md |
| `migration.ts` | 文件 | 旧版本数据根迁移 |
| `preload.ts` | 文件 | 受控的 window.boai 请求/订阅接口与 webUtils File 路径桥接；不暴露任意路径注册 |
| `vault.ts` | 文件 | 系统加密凭据保存 |

| `automation-notifications.ts` | 消费器 | 串行领取、系统提交与失败/未知回执隔离；不重新提交已尝试的提醒 |

main.ts 放行核心助手非空首发/具名团队受理及按请求身份只读核对回执；旧 T1 接口仅用于历史/内部发布日志与显式恢复。
