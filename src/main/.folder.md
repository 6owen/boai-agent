# main

Electron 宿主层，负责窗口、IPC、外观、凭据与数据迁移。

一旦我所属的文件夹有所变化，请更新我。

| 成员 | 地位 | 功能 |
| --- | --- | --- |
| `appearance.ts` | 文件 | 外观配置、图片、分模式颜色、字体与缩放的校验/迁移/持久化 |
| `decode-image.ts` | 文件 | 图片解码和尺寸检查 |
| `local-configs/` | 适配层 | 本地配置有界扫描、密钥留在宿主、选中配置重读及协议/来源保留、Codex 登录与 ACP 程序发现 |
| `main.ts` | 文件 | 本地 API/ACP 配置扫描、原生目录选择、显式导入 IPC、 桌面窗口、原生菜单/快捷键缩放、编辑密钥回填/模型目录/草稿连接测试与会话列表/历史清理 IPC、未知方法的完整重启提示与运行进程生命周期、只读会话 Trace 查询 |
| `migration.ts` | 文件 | 旧版本数据根迁移 |
| `preload.ts` | 文件 | 受控的 window.boai 请求和订阅接口 |
| `vault.ts` | 文件 | 系统加密凭据保存 |
