扫描只读取已知工具目录或用户选择的目录；配置密钥留在宿主，逐项导入交给现有模型连接保存链路。
解析与文件读取独立；不执行配置中的命令、不联网、不修改来源；Codex 登录导入为指定目录的 ACP 启动项，认证与刷新由 Codex 管理。

一旦我所属的文件夹有所变化，请更新我。

| 成员 | 地位 | 功能 |
| --- | --- | --- |
| `discovery.ts` | 用例 | 记住当前扫描范围/候选，重读 API/登录来源、检查程序身份，生成模型连接或 ACP 启动项并保留登录目录 |
| `codex-login.ts` | 解析 | 识别有效 token 结构、账号来源身份与无凭据登录元数据 |
| `codex-acp.ts` | 程序发现 | PATH/标准目录/nvm 的有界程序查找、真实文件身份和 Node shebang 识别；不执行程序 |
| `local-config-scan.ts` | 扫描 | 已知目录/自选目录、JSON/TOML/YAML/dotenv、深度/全部配置文件数量限制、无密钥预览及网页登录元数据 |
| `local-api-config-parser.ts` | 解析 | 显式同对象模型/接口/密钥、环境引用、Claude 模型别名和不支持配置识别 |
| `codex-api-key-detection.ts` | 解析 | 当前 Codex provider/profile、密钥认证与 Responses/Chat 协议识别 |
| `read-config-file.ts` | 文件边界 | 单文件 1 MB 限制、普通文件校验、拒绝符号链接与无敏感文本错误 |
| `LICENSE.txt` | 许可 | 原扫描实现的 Apache-2.0 许可，随构建分发 |
| `NOTICE.txt` | 归属 | 原来源归属与本项目修改说明，随构建分发 |
