# work-views

文件按员工或群/渠道会话范围汇总已收到附件和已登记文件；旧Work视图已退出产品入口。读取不会认领工作、批准操作、采用成果或重放执行。

| 成员 | 地位 | 功能 |
| --- | --- | --- |
| `model.ts` | 纯合同 | 五组状态、受控筛选、日期边界及身份去重；所见审批/运行/可选原消息与文件内容/授权身份重核 |
| `pagination.ts` | 读取核心 | 用新游标重核已加载页；隐藏/条件变化后停止后续读取，重复游标显性失败 |
| `query-lifecycle.ts` | 可见性合同 | 范围/筛选和显示代际核对，旧页不在新范围或重新显示时瞬间复活 |
| `view-state.ts` | 页面内偏好 | 按范围/查询及Work身份保留选中卡、详情与子展开；不保存正文，不影响业务状态 |
| `use-paged-query.ts` | 生命周期 | 独立分页/总数/失败、活跃与事件失效、迟到隔离及页数记忆 |
| `filters.tsx` | 筛选组件 | 同款输入、Select和中文日期范围 |
| `work-card.tsx` | 共用卡 | 目标原文显式标明，完成式文字不改真实状态/交付；自然高度不收缩，负责人/真实状态、原请求/问题/结果/审批导航、可信原计划与本次触发回查；只读详情/有界子工作，处理仍归原聊天 |
| `work-view.tsx` | 旧工作投影 | 已退出会话/全局任务和员工资料入口；底层Work只读逻辑保留 |
| `conversation-files.tsx` | 文件入口 | 员工跨会话或群/渠道文件与附件，有界筛选与范围偏好，固定原件预览/原消息定位；不展示版本历史 |
