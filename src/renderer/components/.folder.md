一旦我所属的文件夹有所变化，请更新我。

| 成员 | 地位 | 功能 |
| --- | --- | --- |
| `app-shell/` | 子目录 | 桌面框架、无独立待处理的主导航、原聊天问题回复及对应详情工作区 |
| `common/` | 子目录 | 现有业务公共组件、共享透明毛绒伙伴 WebP 空态、Markdown与file-preview文件预览入口、全局 DragList 手势/落点和交互保护 |
| `detail-panel/` | 子目录 | 按主页面隔离的多窗口详情标签/显隐状态、独立编辑会话与固定会话活动内容 |
| `employee/` | 子目录 | 独立员工资料能力/当前工作概览、版本化配置编辑与系统文件/工作区/记忆 |
| `icons/` | 子目录 | Solar/Carbon 图标和基础组件图标适配 |
| `ui/` | 子目录 | shadcn 基础组件及主题化 Sonner 提示、统一 SelectField、ChatComposer、CodeBlock/Shiki、ScrollFade 共用滚动容器与统一 Soft 样式/变体 |
| `work-views/` | 子目录 | 共用Work只读卡/五列看板/列表、有界分页与文件版本清单；固定来源/审批身份导航，隐藏停读和迟到隔离 |
| `browser/` | 浏览器组件 | 原地址栏/空态/紧凑徽标与真实状态/控制意图 |
