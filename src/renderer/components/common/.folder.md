# common

跨页面公共控件、格式化辅助函数和未保存状态守卫。

一旦我所属的文件夹有所变化，请更新我。

| 成员 | 地位 | 功能 |
| --- | --- | --- |
| `index.tsx` | 文件 | useMutation 保持 run 引用稳定且保留提交互斥/错误处理；基于 UI Field/Checkbox/Button 的字段标签、提示关联和资源选择；离线 SVG/上传头像与图片回退、可省略介绍且滚动内容/页脚分离的编辑框架、格式化与支持局部标签切换的未保存守卫 |
| `markdown.tsx` | 全局渲染 | 会话/技能共用 GFM 和 Shiki CodeBlock；保留行内代码，禁用 HTML/远程图片/隐式外链，支持元素展示覆盖 |
| `add-contact-menu.tsx` | 组件 | 会话与通讯录共用的加号创建菜单 |
| `group-avatar.tsx` | 组件 | 按成员顺序显示一至九宫格真实头像 |
| `use-editor-guard.tsx` | 共用守卫 | 主页面与独立详情标签的未保存保护和限定表单提交 |

| `drag-list.tsx` | 全局交互 | 会话/技能/分组共用原生拖拽，前后落点线、拖动态、归组目标、Alt 方向键和来源边界；业务保存由调用方负责 |
| `illustrated-empty.tsx` | 共享组件 | 会话/定时任务/技能/通讯录共用的 shadcn Empty 与头像风格 SVG，SVG 不可选中/拖拽，仅会话保留标题，其他页面只有插画及可选操作。 |

add-contact-menu.tsx 仅有回调时展示团队创建。
| `user-avatar.tsx` | 个人资料 | 资料/导航/会话共用头像，旧文字/无效/损坏图片统一回退小猫 SVG，无远程加载 |
