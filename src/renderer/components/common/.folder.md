# common

跨页面公共控件、格式化辅助函数和未保存状态守卫。

一旦我所属的文件夹有所变化，请更新我。

| 成员 | 地位 | 功能 |
| --- | --- | --- |
| `index.tsx` | 文件 | useMutation 保持 run 引用稳定且保留提交互斥/错误处理，默认 inline 并允许显式 toast 模式逐次提示；基于 UI Field/Checkbox/Button 的字段标签、提示关联和资源选择；透明 WebP 预设/图片回退不叠加底色、上传头像保留既有底色；可省略介绍且滚动内容/页脚分离的编辑框架、格式化与支持局部标签切换的未保存守卫 |
| `model-picker.tsx` | 共用模型字段 | 模型目录获取/同行反馈/手动输入与两种布局；连接来源隔离迟到请求，不自动改写选中模型，默认模型占位无重复说明 |
| `markdown.tsx` | 全局渲染 | 安全GFM与Shiki；MarkdownContent组合Typeset及可滚动表格，支持compact；旧Markdown无隐式样式变化 |
| `add-contact-menu.tsx` | 组件 | 会话与通讯录共用的员工/群聊加号菜单，通讯录追加团队创建，保留页面可选菜单插槽 |
| `group-avatar.tsx` | 组件 | 按成员顺序显示一至九宫格真实头像 |
| `panel-resize.tsx` | 分栏展示 | 左右面板常驻裁切与显隐、交互隔离，分割线沿原命中范围 |
| `panel-resize.css` | 分栏动效 | transitions-dev Card resize原版片段/减少动态保护与BOAI分栏和标题区适配，拖动即时响应 |
| `use-editor-guard.tsx` | 共用守卫 | 主页面与独立详情标签的未保存保护和限定表单提交 |

| `drag-list.tsx` | 全局交互 | 可选 canGroupDrop 按来源/目标校验归组，行内排序无效时保留拖拽来源并交由分类目标接收，有效排序优先；拒绝归组不终结外层排序手势；会话/技能/分组共用原生拖拽，前后落点线、拖动态、归组目标、Alt 方向键和来源边界；业务保存由调用方负责 |
| `illustrated-empty.tsx` | 共享组件 | 会话/定时任务/技能/通讯录共用的 shadcn Empty 与头像风格透明毛绒 WebP，图片不可选中/拖拽，展示可选标题及操作，无描述文字。 |

| `user-avatar.tsx` | 个人资料 | 资料/导航/会话共用圆角方形本人头像，透明预设及旧文字/无效/损坏图片的小老虎回退不叠加底色，上传图片保留既有底色，无远程加载 |

| `file-preview/` | 全局只读预览 | 内置插件注册/加载/局部失败，统一标题、Markdown/源码、代码/文本、PDF/Office及图片；页面提供核源和业务操作 |

| `lody/` | 固定来源模块 | PDF/DOCX/XLSX/PPTX与只读DiffViewer、原worker及LICENSE/NOTICE；宿主控件/主题/CSS接线与来源清单。 |

| `error-feedback.tsx` | 错误反馈 | Sonner统一错误通知、同文案去重及无DOM的ErrorToast |
| `catalog-search.tsx` | 目录检索 | 图标展开与聚焦/收起，原输入皮肤 |
| `creation-assistant.tsx` | bobo创建会话 | 计划与数据源共享持续对话、持久回执及结果插槽 |
