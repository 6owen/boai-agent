# file-preview

成果和聊天附件共用 `FilePreview`，页面负责读取、核源、版本、权限和操作菜单，此目录只负责格式分发与展示。Markdown 是文本预览的一种模式；其正文继续复用 `common/markdown.tsx`，源码复用全局 `CodeBlock`。源码不显示行号栏，保留空行、来源行定位和高亮。

PDF、DOCX、XLSX、PPTX 继续使用 `common/lody/` 的既有实现和许可证；`plugins/` 以独立惰性入口装配。隐藏预览不挂载正文或二进制查看器，加载/渲染失败只回退当前预览。

执行过程的差异共用 `DiffPreview`，通过 Pierre 官方 `parsePatchFiles` 保留原始 hunk 行号，复用既有 `common/lody/diff-viewer.tsx` 的主题与高亮 worker。明确 add/delete 输入是文件正文，update 是 patch；缺失行号的片段、二进制及不完整 patch 保留原文。该组件不读取工作区文件，也不改变原生事件。

一旦我所属的文件夹有所变化，请更新我。

| 成员 | 地位 | 功能 |
| --- | --- | --- |
| `index.tsx` | 全局入口 | 将已核验数据交给插件宿主；统一活跃状态、标题与选区修改 |
| `header.tsx` | 共用标题栏 | 单行弹性文件名与右侧操作；标题沿用执行历史 label 的字号和字重 |
| `text-preview.tsx` | 文本查看器 | Markdown 预览/源码图标切换、Shiki 代码与文本、无行号来源定位 |
| `plugin-view.tsx` | 视图宿主 | 固定当前provider、正文Suspense/局部错误回退、稳定标题、隐藏卸载 |
| `plugins/` | 内置扩展 | 只读合同、不可变注册与确定匹配、文本/图片和惰性PDF/Office插件 |
| `image-preview.tsx` | 图片查看器 | 已核验 data URI 的静态图片、局部滚动和加载失败提示 |
| `diff-preview.tsx` | 差异查看器 | 按需加载Pierre查看器，统一视图、11px正文、主题增删色与多文件展示 |
| `diff-preview-data.ts` | 差异格式适配 | 区分明确文件正文与patch，保留真实hunk坐标、不完整记录回退 |

| `selection.ts` | 选区定位 | 仅捕获当前正文，源码行/PDF页码和原文；携带选区锚点直接打开修改Popover |
