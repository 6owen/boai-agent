每个 sidebar 页面各自拥有顶栏可关闭标签、选中项及显隐状态，常驻内容保留草稿、滚动和会话范围；主页面切换只展示该页标签。
一旦我所属的文件夹有所变化，请更新我。

| 成员 | 地位 | 功能 |
| --- | --- | --- |
| `index.tsx` | 组件 | DetailPanelHeader 提供可拖拽/键盘排序、横向滚动的窗口 Tabs、图标、焦点及独立关闭；DetailPanel 可收起并保留内容 |
| `tabs-state.ts` | 状态 | 按 sidebar scope 分区的工作区 reducer、跨页目标命名空间及局部状态转换；技能更新按固定身份去重，重开只激活并保留当前检查/升级状态；新建自动化稳定草稿与按计划 ID 去重的编辑标签； 商店按提供商/条目身份去重； 保序去重、会话范围、移动/切换/相邻关闭/收起恢复的纯转换；增加按轮次与员工去重的 Trace 标签；图标重开重新定位原员工/轮次；普通/Agent/监控共用稳定新建标签 |
| `tab-session.tsx` | 生命周期 | 常驻标签内容、固定页脚布局宿主、独立编辑守卫与脏状态汇总 |
| `activity-tab.tsx` | 数据边界 | 固定会话任务与产物，活跃时独立加载和事件刷新 |
| `trace-tab.tsx` | 数据边界 | 轮次与员工筛选统一使用 SelectField； 固定消息/轮次、员工筛选、按事件刷新 Trace 与折叠运行摘要 |

团队创建使用弹窗，不进入详情标签状态。
