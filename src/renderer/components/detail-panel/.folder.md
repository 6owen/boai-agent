详情工作区由顶栏多个可关闭窗口标签和常驻内容会话组成，各自保留草稿、滚动及会话范围。
一旦我所属的文件夹有所变化，请更新我。

| 成员 | 地位 | 功能 |
| --- | --- | --- |
| `index.tsx` | 组件 | DetailPanelHeader 提供可拖拽/键盘排序、横向滚动的窗口 Tabs、图标、焦点及独立关闭；DetailPanel 可收起并保留内容 |
| `tabs-state.ts` | 状态 | 保序去重、会话范围、移动/切换/相邻关闭/收起恢复的纯转换；增加按轮次与员工去重的 Trace 标签；图标重开重新定位原员工/轮次 |
| `tab-session.tsx` | 生命周期 | 常驻标签内容、固定页脚布局宿主、独立编辑守卫与脏状态汇总 |
| `activity-tab.tsx` | 数据边界 | 固定会话任务与产物，活跃时独立加载和事件刷新 |
| `trace-tab.tsx` | 数据边界 | 固定消息/轮次、员工筛选、按事件刷新 Trace 与折叠运行摘要 |
