# contacts

按群聊和联系人浏览资料，在主区域编辑配置；发消息才跳转会话。
独立选中项由 Shell 持有，编辑复用未保存守卫，不复制领域数据。

一旦我所属的文件夹有所变化，请更新我。

| 成员 | 地位 | 功能 |
| --- | --- | --- |
| `index.tsx` | 页面 | 组合持久列表与详情，右键查看/编辑和列表导航共用未保存守卫；未选中时只显示不可选中/拖拽的动物伙伴 SVG，无标题或描述文字； 复用会话置顶的无底色分组标题/悬停箭头与文字样式；共用加号菜单、分组搜索、折叠列表、员工与群拼图头像、资料/配置编辑、群成员头像网格编辑、资料跳转和发消息入口，编辑页脚随文档滚动 |
| `contact-list.tsx` | 列表 | 搜索与折叠分类、右键发消息/查看/编辑/归类、组内拖拽和键盘排序 |
| `contact-categories.tsx` | 分类管理 | 员工分类的新建/重命名、计数与删除确认，员工归回未分类 |
| `use-contact-list.ts` | 数据 Hook | 类型化偏好读取/版本化提交、冲突刷新与迟到响应隔离 |
