# contacts

按群聊和联系人浏览资料，在主区域编辑配置；发消息才跳转会话。
独立选中项由 Shell 持有，编辑复用未保存守卫，不复制领域数据。

一旦我所属的文件夹有所变化，请更新我。

| 成员 | 地位 | 功能 |
| --- | --- | --- |
| `index.tsx` | 页面 | 员工资料不展示启用标签；群名称下无人数副标题，人数紧随群成员标题；删除只清理被移除详情对象的草稿，群编辑解散后刷新；组合持久列表与详情，右键查看/编辑和列表导航共用未保存守卫；未选中时只显示不可选中/拖拽的透明毛绒动物伙伴 WebP，无标题或描述文字；共用加号菜单、搜索、头像、资料/配置编辑、成员跳转和发消息入口；群资料展示团队目的/建议和 roleplay 能力边界 |
| `contact-list.tsx` | 列表 | 普通员工右键删除、群聊右键解散，分类标题右键重命名/解散/整类员工删除；批量范围按完整分类，删除确认解释单聊/记忆/工作区清理与群保留/空群解散；失败显性反馈；核心助手不参与分类/删除；加号团队创建与分类菜单、分类/员工独立拖拽及键盘排序、搜索临时展开与本机折叠状态 |
| `contact-categories.tsx` | 分类管理 | label 操作随行悬停/聚焦显示，确认/新建时保留并继承文字颜色；分类标题操作共用受控重命名弹窗、解散及整类员工删除确认；加号内的小标题二级 DropdownMenu，原位新建/重命名、计数与删除确认，解散分类将员工归回未分类；编辑或删除确认期间暂停排序 |
| `use-contact-list.ts` | 数据 Hook | 类型化偏好读取/版本化提交、冲突刷新与迟到响应隔离 |

| `team-creator.tsx` | 团队入口 | 团队名称和需求两项必填的受控弹窗，稳定请求受理后进入核心助手会话；错误先核对同请求回执，未核对锁定原字段/身份，确认未受理才允许修改；无团队草稿、模型选择、预设或群选项 |
