# contacts

按群聊和联系人浏览资料，在主区域编辑配置；发消息才跳转会话。
独立选中项由 Shell 持有，编辑复用未保存守卫，不复制领域数据。

一旦我所属的文件夹有所变化，请更新我。

| 成员 | 地位 | 功能 |
| --- | --- | --- |
| `index.tsx` | 页面 | 群名称下无人数副标题，人数紧随群成员标题；组合持久列表与详情，右键查看/编辑和列表导航共用未保存守卫；未选中时只显示不可选中/拖拽的动物伙伴 SVG，无标题或描述文字； 复用会话置顶的无底色分组标题/悬停箭头与文字样式；共用加号菜单、分组搜索、折叠列表、员工与群拼图头像、资料/配置编辑、群成员头像网格编辑、资料跳转和发消息入口，编辑页脚随文档滚动；群资料展示团队目的/建议和 roleplay 能力边界 |
| `contact-list.tsx` | 列表 | 独立团队创建图标按钮与加号中的分类二级菜单；分类标题前后落点/键盘排序，分类与员工拖拽身份隔离，未分类固定在末尾；本机持久化折叠状态，搜索临时展开且不改写偏好；搜索与折叠分类、空分类无占位、右键发消息/查看/编辑/归类；共享员工拖拽区支持空/折叠分类标题归类，组内拖拽和键盘排序 |
| `contact-categories.tsx` | 分类管理 | 加号内的小标题二级 DropdownMenu；原生拖拽/键盘排序，编辑或删除确认期间暂停排序；员工分类的新建/重命名、计数与删除确认，员工归回未分类 |
| `team-create-icon.tsx` | 图标 | 复用小狐狸、小猫和小兔本地 SVG 头像的拟物卡片组合，保留柔和配色、圆润造型、投影和加号徽章；悬停/聚焦时交错轻跳，支持减少动态效果偏好 |
| `use-contact-list.ts` | 数据 Hook | 类型化偏好读取/版本化提交、冲突刷新与迟到响应隔离 |

| `team-creator.tsx` | 团队详情 | 延迟保存、冲突比较；生成/结果标题与显式错误聚焦，提交展开首个无效字段；生成/取消/编辑、缺少模型时配置导航、恢复和按 ID 读取当前群名/成员现状 |

| `team-plan-editor.tsx` | 方案编辑 | 人数边界、原生必填/重名错误关联和可聚焦标题；旧同名提示、预设头像、职责规则和能力说明 |
