# settings

设置分类入口及模型、外观、数据和外部 Agent 配置。

一旦我所属的文件夹有所变化，请更新我。

| 成员 | 地位 | 功能 |
| --- | --- | --- |
| `appearance.tsx` | 文件 | 无保存状态提示，共用文档布局；Card 与全局 soft-divide-y 分组、Button 模式选择、NativeSelect 主题/字体/缩放，直接展示高级 Card，背景图片与 Slider 透明度即时预览/保存 |
| `connection-illustration.tsx` | 插画 | 使用全局语义颜色的小模型卡片与小插头 SVG，分别代表选择服务和配置连接 |
| `connection-model-picker.tsx` | 控件 | 默认模型标题右侧等宽图标加载的目录按钮及左侧同行反馈、铅笔/列表图标切换编辑，下方默认模型选择/手动填写，使用当前密钥含显式空值，按地址/密钥隔离并丢弃过期请求 |
| `local-connections.tsx` | 文件 | 适应窗口宽度的扫描弹窗、模型连接中的本地 Agent 扫描与目录选择、无密钥来源预览、补填模型后导入、已导入反馈、Codex 登录和可用 ACP 程序预览/确认接入 |
| `connections.tsx` | 文件 | 本地扫描入口与共用的本地 Agent 管理、OpenAI 接口协议选择与编辑保留、 与外观共用留白/宽度/标题，不显示页面说明与连接数量；共享 Card/soft-card/surface 卡片和全局行间/页脚分割线，Lobe Icons 本地品牌 SVG、紧凑连接行、操作菜单与标题后同行的逐项测试反馈；Dialog 无副标题的两步服务选择/凭据表单、步骤 SVG 插画与箭头、等宽纯图标测试加载、兼容接口固定服务分组、模型目录选择/铅笔编辑、编辑回填真实密钥及浅色显隐按钮、清空后使用空密钥、草稿测试不保存、旧宿主重启提示、右侧保存/测试同行状态和未保存保护；放弃草稿仅关闭弹窗并保留设置分类与搜索 |
| `data.tsx` | 文件 | Card 与 Button 数据目录/备份操作 |
| `external.tsx` | 文件 | 模型连接内嵌/独立管理共用启动项、Node 运行方式/登录目录编辑、握手与会话测试及失败反馈 |
| `index.tsx` | 文件 | 共用会话标题栏、InputGroup 搜索及图标尺寸、独立滚动的 Button 分类、外观/模型连接共享文档留白及设置子页编排 |
