# pages

通讯录、会话和其他功能页面直接按目录引用，不设置仅转发导出的总入口。

一旦我所属的文件夹有所变化，请更新我。

| 成员 | 地位 | 功能 |
| --- | --- | --- |
| `contacts/` | 子目录 | 群聊/联系人分组、员工能力与当前工作概览、资料配置编辑和发消息/原工作/全局任务跳转 |
| `conversations/` | 子目录 | 会话页面组件、活动投影与原问题卡片/同一输入框回复；明确问题版本/工作/occurrence 及未知回执核对 |
| `help/` | 子目录 | 使用帮助页面 |
| `library/` | 子目录 | Skills 专属列表/详情、商城和共享资源详情；旧资料库主页面已删除 |
| `schedules/` | 子目录 | 定时任务管理与结果 |
| `tasks/` | 子目录 | 全局真实Work看板/列表，复用会话/员工卡与宿主有界查询，处理回原聊天 |
| `settings/` | 子目录 | 个人资料及分享点阵绘制、模型API连接、外观与数据设置；本机Agent分区暂不挂载 |
