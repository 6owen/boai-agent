# conversations

会话私有组件与展示投影；组件和辅助函数直接从实现文件导入。

一旦我所属的文件夹有所变化，请更新我。

| 成员 | 地位 | 功能 |
| --- | --- | --- |
| `-components/` | 子目录 | 会话私有界面组件 |
| `activity.ts` | 文件 | 按轮次整理活动及原用户消息的持久中断投影；精确身份与已有结果保持 |
| `presentation.ts` | 文件 | 会话/业务结果文案、成员标签/材料草稿/明确问题关联与稳定发送请求和未知回执合同、展示辅助函数 |
| `group-chat.ts` | 展示投影 | 群工作优先宿主当前来源证据 bool、false 不回退陈旧正文；本轮用户触发及核对后的旧顺序前置关联不显示为引用，保留手动/明确跨消息引用与未知关系；同轮次同来源连续发言和明确消息附件/审批定位；群工作交付证据状态独立，不改变工作运行时 |

| `inline-mentions.ts` | 输入投影 | 已确认成员标签插入/选区扩展/普通编辑范围迁移/发送正文；删除同步取消点名，字面 @ 不推断身份 |
| `mention-editor.ts` | 编辑模型 | Tiptap 原子成员节点、真实光标前后位置、一次 Backspace/Delete 与撤销，草稿/文档位置转换；NodeView 的 DOM 光标边界与复制 HTML/纯文本分离 |

| `reading-state.ts` | D6 纯状态 | 统一历史滚动边界距离、真实完成可见筛选、流式变更失效旧 hash、有界历史合并、独立阅读与锚点迟到版本合并、固定会话/消息/文件目标、搜索有界游标/索引代际和覆盖回执、多词高亮/关闭隐藏丢弃 |

| `detail-reading.ts` | D6 详情读取 | 成果/执行/单次结果只按明确消息 ID 分批核读，每项 limit1、最多四项并行，隐藏/迟到停止后续批次，失效只原因无旧正文 |

| `question-state.ts` | 原问题合同 | 公开消息的固定问题/版本/Work或occurrence投影；旧完成/同伴失败Turn沿共享纯核验匹配实际已提交Run/Work问题才补原卡；自动化Work/Decision逐原问题保留确切message/Work与独立已答关系，混合旧chat按原消息核读与回执不被同turn其他答复覆盖，同聊天真实轮次来源为权威，纯旧无记录latest兼容排除已知task；旧消息缺origin兼容、存在origin严格核对，普通问题排除自动化；原key/白名单/CAS、本人原message/Work回执核对，不缓存业务解决状态 |
| `question-reply.tsx` | 聊天定向补充 | 原问题消息卡复用现有composer；提交前来源核对，普通问题接续原Work，自动化接续原occurrence/预算；原载荷持久冻结，隐藏/重启只读核对，消息页缺源/已答仍显示有界恢复卡；未受理显式放弃恢复正文且不覆盖新草稿；清理删除私有补充，迟到响应不修改新聊天 |

| `message-send-state.ts` | IM/ACP未决请求 | 统一保存原请求及材料版本引用，重启unknown只读核对；旧ACP兼容、损坏新版拒绝覆盖 |

| `use-chat-artifacts.ts` | 聊天成果操作 | 原消息采用/稍后处理/同一composer修订，持久原载荷与严格回执匹配，未知只读核对，清理隔离 |

| `live-message-buffer.ts` | 读取竞态缓冲 | 只保留当前会话读取期间实时更新；结束/替换/清理释放正文 |
