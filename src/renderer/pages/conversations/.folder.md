# conversations

会话私有组件与展示投影；组件和辅助函数直接从实现文件导入。

一旦我所属的文件夹有所变化，请更新我。

| 成员 | 地位 | 功能 |
| --- | --- | --- |
| `-components/` | 子目录 | 会话私有界面组件 |
| `activity.ts` | 文件 | 按轮次整理的活动展示投影 |
| `presentation.ts` | 文件 | 会话/业务结果文案、成员标签/材料草稿与稳定发送请求和未知回执合同、展示辅助函数 |
| `group-chat.ts` | 展示投影 | 群工作优先宿主当前来源证据 bool、false 不回退陈旧正文；单聊/群聊共用本轮用户触发关联去重、保留手动/跨消息引用、同轮次同来源连续发言和明确消息附件/审批定位；群工作交付证据状态独立，不改变工作运行时 |

| `inline-mentions.ts` | 输入投影 | 已确认成员标签插入/选区扩展/普通编辑范围迁移/发送正文；删除同步取消点名，字面 @ 不推断身份 |
| `mention-editor.ts` | 编辑模型 | Tiptap 原子成员节点、真实光标前后位置、一次 Backspace/Delete 与撤销，草稿/文档位置转换；NodeView 的 DOM 光标边界与复制 HTML/纯文本分离 |

| `reading-state.ts` | D6 纯状态 | 统一历史滚动边界距离、真实完成可见筛选、流式变更失效旧 hash、有界历史合并、独立阅读与锚点迟到版本合并、固定会话/消息/文件目标、搜索有界游标/索引代际和覆盖回执、多词高亮/关闭隐藏丢弃 |

| `detail-reading.ts` | D6 详情读取 | 成果/执行/单次结果只按明确消息 ID 分批核读，每项 limit1、最多四项并行，隐藏/迟到停止后续批次，失效只原因无旧正文 |
