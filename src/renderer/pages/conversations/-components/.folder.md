# -components

会话页面私有组件，负责列表、聊天、活动和外部任务文件。

一旦我所属的文件夹有所变化，请更新我。

| 成员 | 地位 | 功能 |
| --- | --- | --- |
| `activity-detail.tsx` | 文件 | 共享 Card/soft-card 与 surface 文件卡片、全局工具分割线；父子工作、依赖版本、定向通知与停止工作树； 运行与业务结果分离、暂缓草稿、等待耗时及文件/重试操作 |
| `chat-view.tsx` | 文件 | 组合悬浮标题菜单与 shadcn Scroll Fade 顶部渐隐消息；紧凑 ChatComposer、统一员工头像、聊天消息和任务交互，保留发送/停止/提及与滚动恢复逻辑 |
| `composer-toolbar.tsx` | 文件 | 加号与发送/停止操作；单聊显示 280px 权限菜单/完全访问本地预览和 256px 模型选择/连接管理菜单；群聊隐藏模型与权限控件，执行或未保存编辑时锁定单聊配置 |
| `conversation-header.tsx` | 文件 | 悬浮名称与单一下拉操作菜单：配置、置顶/取消置顶、任务与产物、清空聊天记录；使用最新会话快照并复用清理确认；详情入口记录稳定按钮用于关闭后恢复焦点 |
| `conversation-history-dialog.tsx` | 文件 | 列表/标题菜单共用的清空或删除确认，完整说明清理范围、阻止重复提交并保留失败反馈 |
| `conversation-list.tsx` | 文件 | 无底部工作空间状态栏；单加号入口、成员拼图头像、手动拖拽/键盘排序、置顶/会话两组独立折叠和搜索自动展开、Soft 右键置顶/清空/删除，共用清理确认 |
| `external-files.tsx` | 文件 | 统一 Button 外部任务文件列表与产物发布 |
