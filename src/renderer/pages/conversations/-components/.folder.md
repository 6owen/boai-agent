# -components

会话页面私有组件，负责列表、聊天、活动和外部任务文件。

一旦我所属的文件夹有所变化，请更新我。

| 成员 | 地位 | 功能 |
| --- | --- | --- |
| `activity-detail.tsx` | 文件 | 仅保留真实工作目标、交付状态、依赖、停止工作树与文件 |
| `chat-view.tsx` | 文件 | 按指定消息定位/焦点与失效提示，后续消息不覆盖定位；组合悬浮标题菜单与全局 ScrollFade 顶部渐隐容器，正文使用共享 Markdown/Shiki；紧凑 ChatComposer、统一员工头像、聊天消息和任务交互，保留原生滚动 ref、发送/停止/提及与跟随/恢复逻辑；输入框上方无状态条，回复旁 Trace 图标 |
| `composer-toolbar.tsx` | 文件 | 加号与发送/停止操作；单聊显示 280px 权限菜单/完全访问本地预览和 256px 模型选择/连接管理菜单、已适配模型的思考强度二级菜单与当前档位；群聊隐藏模型与权限控件，执行或未保存编辑时锁定单聊配置 |
| `conversation-header.tsx` | 文件 | 悬浮名称与单一下拉操作菜单：配置、置顶/取消置顶、任务与产物、清空聊天记录；使用最新会话快照并复用清理确认；详情入口记录稳定按钮用于关闭后恢复焦点；增加独立执行过程菜单 |
| `conversation-history-dialog.tsx` | 文件 | 列表/标题菜单共用的清空或删除确认，完整说明清理范围、阻止重复提交并保留失败反馈 |
| `conversation-list.tsx` | 文件 | 左侧空列表复用小尺寸伙伴 SVG 和轻量提示，插画不可选中/拖拽；来源筛选统一使用 SelectField； 普通/定时任务聊天来源筛选与预览来源标注； 无底部工作空间状态栏；单加号入口、成员拼图头像、复用全局 DragList 的手动拖拽/键盘排序及分组边界、置顶/会话两组独立折叠和搜索自动展开、Soft 右键置顶/清空/删除，共用清理确认 |
| `external-files.tsx` | 文件 | 统一 Button 外部任务文件列表与产物发布 |
| `trace-detail.tsx` | 文件 | 原生调用树、耗时条、锚定节点浮层的输入输出与错误 |
| `run-detail.tsx` | 文件 | 执行过程内折叠运行诊断、历史失败和显式重试 |
