# -components

会话页面私有组件，负责列表、聊天、活动和外部任务文件。

一旦我所属的文件夹有所变化，请更新我。

| 成员 | 地位 | 功能 |
| --- | --- | --- |
| `activity-detail.tsx` | 文件 | 群聊真实父子工作分区与交付证据状态；保留工作详情、依赖、停止树和会话文件，单聊保持现状 |
| `chat-view.tsx` | 文件 | 核心助手聊天按当前工作身份显示团队结果和显式恢复，主页面隐藏暂停读取；按稳定 user 身份展示当前个人头像，自动化来源独立，引用本人显示你；向标题传递资料快照；消息头移除行内职责，时间悬停显示；姓名点击提及并聚焦输入，通过编辑器 ref 在正文光标处插入标签，头像打开资料；接入 Prompt Bar 的真实成员与会话操作；同卡引用/正文与蓝色提及、消息卡片接线；群聊本轮触发引用去重、用户靠右/员工靠左与保守连续发言/明确文件和审批关联，按指定消息定位/焦点与失效提示，后续消息不覆盖定位；组合悬浮标题菜单与全局 ScrollFade 顶部渐隐容器，正文使用共享 Markdown/Shiki；紧凑 ChatComposer、统一员工头像、聊天消息和任务交互，保留原生滚动 ref、发送/停止/提及与跟随/恢复逻辑；输入框上方无状态条，回复旁 Trace 图标 |
| `composer-toolbar.tsx` | 文件 | 空白聊天首次发送前隐藏会话目录操作；核心助手隐藏命令权限菜单；@ 与 / 共用 Prompt Bar 菜单入口；群成员点名入口；加号与发送/停止操作；单聊显示 280px 权限菜单/完全访问本地预览和 256px 模型选择/连接管理菜单、已适配模型的思考强度二级菜单与当前档位；群聊隐藏模型与权限控件，执行或未保存编辑时锁定单聊配置 |
| `conversation-header.tsx` | 文件 | 群聊悬浮标题只显示群名，前三位重叠头像打开成员资料、纯文字 +N 悬停变色并打开当前群组设置，任务产物直达；单聊悬浮名称及共用下拉菜单：配置、置顶/取消置顶、任务与产物、清空聊天记录；使用最新会话快照并复用清理确认；详情入口记录稳定按钮用于关闭后恢复焦点；增加独立执行过程菜单 |
| `conversation-history-dialog.tsx` | 文件 | 列表/标题菜单共用的清空或删除确认，完整说明清理范围、阻止重复提交并保留失败反馈 |
| `conversation-list.tsx` | 文件 | 当前核心助手名称的独立会话分类，整行标题折叠，右侧更多/编辑仅整行悬停、聚焦或菜单打开时显示，保留占位并与标题同色；更多打开助手设置、编辑打开空白聊天；核心/普通分类和置顶边界独立排序；左侧空列表复用小尺寸毛绒伙伴 WebP 和轻量提示，插画不可选中/拖拽；移除来源下拉及过滤状态，普通/定时任务聊天共同展示、保留预览来源标注； 无底部工作空间状态栏；单加号入口、成员拼图头像、复用全局 DragList 的手动拖拽/键盘排序及分组边界、置顶/会话两组独立折叠和搜索自动展开、Soft 右键置顶/清空/删除，共用清理确认 |
| `external-files.tsx` | 文件 | 统一 Button 外部任务文件列表与产物发布 |
| `trace-detail.tsx` | 文件 | 12px旋转折叠箭头，节点标签保持详情入口；原生调用树、耗时条、锚定节点浮层的输入输出与错误 |
| `run-detail.tsx` | 文件 | 运行摘要整行折叠与12px旋转箭头；执行过程内折叠运行诊断、历史失败和显式重试 |
| `artifact-list.tsx` | 共享片段 | 群聊消息和任务详情共用同一真实文件入口、大小与发布时间 |

| `message-card.tsx` | 消息交互 | 表情浮层开关不控制工具条显示；本人操作与表情回应统一显示你，不重写历史名称；消息/工具条共用 Soft Card 边缘；按实测宽度定位工具条；表情提交保持焦点和亮度、移除回应后无滚动恢复焦点；常用偏好/持久回应、复制、引用和 Trace，提及统一通过姓名 |
| `prompt-bar.tsx` | 输入增强 | 首次发送前隐藏目录/产物等依赖会话身份的命令；群聊接入实际原子节点编辑器，单聊保留 textarea；已确认身份、整体删除/选中替换、编辑历史与纯文本剪贴板；Beautiful UI 风格 @ / 筛选、键盘/IME 与命令草稿 |
| `agent-info-popover.tsx` | 员工资料 | 点击消息或标题头像显示真实姓名/职责/启用状态/绑定技能知识；标题使用无按钮底色的 24px 重叠头像入口与下方浮层；复用 Avatar、Popover、Badge 与 Separator |
| `mention-input.tsx` | 群聊输入 | 挂载轻量 Tiptap 编辑器，成员标签共用 Soft Button，以文字 inline 和内边距替代固定高度 flex，真实原生光标/选区/整体删除/历史与受控草稿同步，恢复草稿时光标置末 |

| `core-team-results.tsx` | 团队交付 | 仅当前核心会话工作匹配创建回执，当前群名/已移除导航与显式继续/放弃文件操作；隐藏暂停读取，无团队草稿显示或自动恢复 |

| `core-chat-start.tsx` | 首发入口 | 可重复打开同一空白核心聊天，输入只保留页面；发送前不创建会话/目录，复用模型设置与首次发送回调 |
