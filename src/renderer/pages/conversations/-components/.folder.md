# -components

会话页面私有组件，负责列表、聊天、活动和外部任务文件。

一旦我所属的文件夹有所变化，请更新我。

| 成员 | 地位 | 功能 |
| --- | --- | --- |
| `activity-detail.tsx` | 文件 | 父子工作、依赖版本、定向通知与停止工作树； 运行与业务结果分离、暂缓草稿、等待耗时及文件/重试操作 |
| `chat-view.tsx` | 文件 | 统一员工头像、聊天消息和任务交互；紧凑 ChatComposer 与工具栏组合、底部无提示栏，保留发送/停止/提及逻辑 |
| `composer-toolbar.tsx` | 文件 | 加号操作、逐成员命令审批策略与真实模型切换；执行或未保存编辑时锁定配置 |
| `conversation-list.tsx` | 文件 | 单加号入口、成员拼图头像、手动拖拽/键盘排序、置顶/会话两组独立折叠和搜索自动展开、Soft 右键置顶/清空/删除及确认 |
| `external-files.tsx` | 文件 | 统一 Button 外部任务文件列表与产物发布 |
