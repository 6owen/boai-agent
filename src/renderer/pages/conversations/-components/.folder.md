# -components

会话页面私有组件，负责列表、聊天、活动和外部任务文件。

一旦我所属的文件夹有所变化，请更新我。

| 成员 | 地位 | 功能 |
| --- | --- | --- |
| `activity-detail.tsx` | 文件 | 共享 Card/soft-card 与 surface 文件卡片、全局工具分割线；父子工作、依赖版本、定向通知与停止工作树； 运行与业务结果分离、暂缓草稿、等待耗时及文件/重试操作 |
| `chat-view.tsx` | 文件 | 统一员工头像、纯名称无按钮背景的标题、聊天消息和任务交互；紧凑 ChatComposer 与工具栏组合、底部无提示栏，保留发送/停止/提及逻辑 |
| `composer-toolbar.tsx` | 文件 | 加号操作、280px 逐成员权限菜单与仅本地勾选的完全访问预览；256px 模型菜单保留模型选择/连接管理，群聊仅显示成员名分组；执行或未保存编辑时锁定配置 |
| `conversation-list.tsx` | 文件 | 无底部工作空间状态栏；单加号入口、成员拼图头像、手动拖拽/键盘排序、置顶/会话两组独立折叠和搜索自动展开、Soft 右键置顶/清空/删除及确认 |
| `external-files.tsx` | 文件 | 统一 Button 外部任务文件列表与产物发布 |
