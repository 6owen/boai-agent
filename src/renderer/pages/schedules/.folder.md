# schedules

定时任务阅读页与现有详情标签编辑器分开，执行历史由独立组件按游标读取。

一旦我所属的文件夹有所变化，请更新我。

| 成员 | 地位 | 功能 |
| --- | --- | --- |
| `index.tsx` | 阅读页 | 列表/内容接入 Shell 共用拖拽分栏，收起列表时同步隐藏分隔线；空态共用不可选中/拖拽的小熊时钟 SVG 与新建入口，不显示标题； 左栏复用会话标题布局与紧凑字号/间距/语义色；区分监控来源、记录位置与零模型执行；需处理筛选/独立排序、两行摘要/实际下次时间、结果优先布局；通知到达时定位包括已删计划在内的单次记录； 计划搜索/筛选/时间排序、摘要与执行操作；编辑只打开现有详情标签，完整记录交由历史组件 |
| `automation-editor.tsx` | 编辑标签 | 任务/执行对象/规则/通知使用 SelectField，表单默认值保持明确； 报告/监控类型、来源聊天与监控规则草稿；默认重要更新、每次结果或静音并兼容旧偏好； 固定计划/版本的独立草稿、每次新聊天/指定聊天、员工、星期多选/工作日、无效时区不格式化的纯预览与现有固定页脚/未保存守卫 |
| `automation-history.tsx` | 执行历史 | 监控独立检查摘要、基线/变化/失败、前后值/规则/来源证据与冷却说明；独立待处理分页、最近结束结果默认展开与身份去重；明确额度追加确认、累计上限与确认消息回执；通知回执与业务交付分开展示、按消息/记录身份定位； 数据库游标分页、真实结果正文/证据和消息定位、停止与原预算补充入口 |
| `monitor-editor.tsx` | 监控配置 | 比较条件使用 SelectField； 已发布 JSON 文件名、字段/阈值、数据有效期、冷却及来源格式说明 |
