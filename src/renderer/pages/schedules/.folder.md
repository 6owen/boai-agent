定时任务统一在本页创建、配置及查看执行记录；新计划只选择一名员工。
手动与bobo对话共用AutomationInput/保存服务；隐藏停止读取，未知请求只核对。
一旦我所属的文件夹有所变化，请更新我。

| 成员 | 地位 | 功能 |
| --- | --- | --- |
| `index.tsx` | 页面 | 会话式侧栏、全部计划、共用插画空态、弹窗创建/编辑及主区历史导航 |
| `automation-dialog.tsx` | 弹窗边界 | 仅手动创建/编辑Dialog，局部草稿守卫、保存期间禁止关闭及底页保持 |
| `automation-details.tsx` | 配置卡片 | 只读图标标题/真实配置值，单次运行页脚及窄容器布局 |
| `automation-editor.tsx` | 表单 | 名称/描述/指令、通讯录单员工、六种频率动态配置，旧偏好/暂停/回执保持 |
| `schedule-presentation.ts` | 展示投影 | 列表、卡片和员工查看入口共用日程摘要 |
| `automation-history-list.tsx` | 历史列表 | 技能式两行记录、检索和稳定分页，点击打开单次过程；悬停删除及当前任务全部历史清空确认 |
| `automation-history.tsx` | 单次面板 | 无额外顶部操作栏；停止图标放在最新TraceTab卡片的聊天定位左侧；未开始保留状态、停止/任务入口与Sonner原因，不查询虚构会话 |
| `monitor-editor.tsx` | 旧监控编辑 | 已发布JSON、字段/阈值、有效期和冷却；保留已有配置 |
| `automation-owner.tsx` | 领域投影 | 员工/旧群名称与归属、旧群分工编辑组件；新创建页不开放群选择 |
| `owner-automations.tsx` | 只读入口 | 员工/群有界两行计划列表，图标与密度复用执行记录，点击统一回到全局定时任务页 |
