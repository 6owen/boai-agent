# styles

统一视觉 token、桌面布局、阅读排版和页面表现，通过 global.css 单一入口加载，基础控件皮肤由 components/ui/skin.css 统一。

一旦我所属的文件夹有所变化，请更新我。

| 成员 | 地位 | 功能 |
| --- | --- | --- |
| `colors.css` | 视觉基础 | 启动色、离线 Geist/系统字体、13px 字号基准、32px composer 与 Soft 圆角、高光、控件尺寸、分模式阴影和背景图层 |
| `global.css` | 入口 | 声明级联顺序、聚合样式、全局禁用 ring/outline 并保留表面阴影 |
| `legacy.css` | 布局与公共控件 | 桌面框架、导航、52px 会话行、14px 消息与紧凑聊天布局；模型配置转入 composer 菜单、移除底部提示栏、固定会话栏显示逻辑、右侧顶栏/内容共享宽度并对齐拖拽线与窄屏详情；顶栏右侧空白可拖动窗口，多标签点击区域排除拖拽；图标默认 16px；员工分类仅布局、员工/资料库共享 Tabs 皮肤 |
| `pages.css` | 页面样式 | 固定宽度通讯录分栏、资料及共享 Tabs 内嵌配置布局、紧凑外观设置行、缩放响应式和任务侧栏、居中空状态及执行记录 |
| `tailwind.css` | 构建适配 | Tailwind/shadcn 动画、Iconify、布局层隔离、无默认 outline 的基线及 Soft 字号/圆角/阴影映射 |
| `typeset.css` | 阅读排版 | Markdown 正文、标题、代码与表格 |
