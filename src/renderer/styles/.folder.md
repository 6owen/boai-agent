# styles

统一视觉 token、桌面布局、阅读排版和页面表现，通过 global.css 单一入口加载。

一旦我所属的文件夹有所变化，请更新我。

| 成员 | 地位 | 功能 |
| --- | --- | --- |
| `colors.css` | 视觉基础 | 启动色、离线 Geist/系统字体、13px 字号基准、圆角、控件尺寸、阴影和背景图层 |
| `global.css` | 入口 | 声明级联顺序并聚合所有全局样式 |
| `legacy.css` | 布局与公共控件 | 圆角桌面框架、图标导航、15px 消息、13px 控件、表单及响应式布局 |
| `pages.css` | 页面样式 | 紧凑外观设置行、缩放响应式和任务侧栏、居中空状态及执行记录 |
| `tailwind.css` | 构建适配 | Tailwind/shadcn 动画、状态变体、Iconify、旧控件重置隔离及完整主题映射 |
| `typeset.css` | 阅读排版 | Markdown 正文、标题、代码与表格 |
