# styles

统一视觉 token、桌面布局、阅读排版和页面表现，通过 global.css 单一入口加载，基础控件皮肤由 components/ui/skin.css 统一。

一旦我所属的文件夹有所变化，请更新我。

| 成员 | 地位 | 功能 |
| --- | --- | --- |
| `colors.css` | 视觉基础 | 启动色、离线 Geist/系统字体、13px 字号基准、Soft 圆角、高光、控件尺寸、分模式阴影和背景图层 |
| `global.css` | 入口 | 声明级联顺序并聚合全局样式与 UI 皮肤 |
| `legacy.css` | 布局与公共控件 | 桌面框架、导航、消息与表单布局；旧控件/手写菜单样式已移除 |
| `pages.css` | 页面样式 | 紧凑外观设置行、缩放响应式和任务侧栏、居中空状态及执行记录 |
| `tailwind.css` | 构建适配 | Tailwind/shadcn 动画、Iconify、布局层隔离及 Soft 字号/圆角/阴影映射 |
| `typeset.css` | 阅读排版 | Markdown 正文、标题、代码与表格 |
