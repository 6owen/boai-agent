# styles

统一视觉 token、桌面布局、阅读排版和页面表现，通过 global.css 单一入口加载，基础控件皮肤由 components/ui/skin.css 统一。

一旦我所属的文件夹有所变化，请更新我。

| 成员 | 地位 | 功能 |
| --- | --- | --- |
| `colors.css` | 视觉基础 | 启动色、离线 Geist/系统字体、13px 字号基准、32px composer 与 Soft 圆角、高光、控件尺寸、分模式阴影、共用水平/垂直分割细线和背景图层 |
| `global.css` | 入口 | 声明级联顺序、聚合样式、全局禁用 ring/outline 并保留表面阴影 |
| `legacy.css` | 布局与公共控件 | 桌面框架、导航、52px 会话行、14px 消息与紧凑聊天布局；悬浮纯名称/操作菜单与 Scroll Fade 消息顶部重叠区、无列表页脚，会话页保留手动分栏宽度/拖拽线，不在窄窗切换详情浮层；其他页面保留窄窗详情布局；顶栏右侧空白可拖动窗口，多标签点击区域排除拖拽；图标默认 16px；员工分类仅布局、员工/资料库共享 Tabs 皮肤，右侧编辑内容滚动且操作栏定高固定；卡片与文件/资源按钮仅保留布局，边框由共享 UI 皮肤负责 |
| `pages.css` | 页面样式 | 本地配置弹窗有界滚动与卡片布局、 固定宽度通讯录分栏、资料及共享 Tabs 内嵌配置布局、通讯录页脚自然滚动、与会话对齐的设置标题/搜索/分类间距及窄窗导航、外观/模型连接共用留白/宽度/标题、紧凑外观行和直接展示的高级 Card、颜色/下拉/Slider 控件仅保留布局且外观共用 UI 皮肤、外观/模型连接表单与服务选项只负责布局，边框和行间/页脚分割线交由共享 UI 皮肤、模型连接列表标题与测试状态同行省略/无副标题两步弹窗、步骤 SVG 插画/箭头、品牌图标颜色随主题适配与兼容接口横向分组行、顶部获取模型/铅笔列表图标切换、下拉、密钥显隐与按钮左侧同行状态及局部键盘焦点、缩放响应式和任务侧栏、居中空状态及执行记录 |
| `tailwind.css` | 构建适配 | Tailwind/shadcn 动画、Iconify、布局层隔离、无默认 outline 的基线及 Soft 字号/圆角/阴影映射 |
| `typeset.css` | 阅读排版 | Markdown 正文、标题、代码与表格 |
