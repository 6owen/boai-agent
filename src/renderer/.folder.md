# renderer

Renderer 启动层；main.tsx 直接挂载 AppShell，页面、组件、状态和样式按职责组织。

一旦我所属的文件夹有所变化，请更新我。

| 成员 | 地位 | 功能 |
| --- | --- | --- |
| `assets/` | 子目录 | 随前端打包的21 款生肖与毛绒角色透明 WebP 头像、会话/任务/技能/通讯录及连接向导透明毛绒 WebP 插画、历史时钟、真实模式缩略图、Geist 字体及许可 |
| `components/` | 子目录 | 业务共享组件、按 sidebar 页面管理详情 Tabs 的桌面 Shell 和 shadcn 基础组件 |
| `index.html` | 文件 | Renderer HTML 入口；本地WASM编译/blob worker预览CSP。 |
| `main.tsx` | 文件 | 初始化外观，挂载 Tooltip 上下文、桌面 Shell 和唯一主题化 Sonner 提示入口 |
| `pages/` | 子目录 | 按功能组织的页面和私有组件；资料库主页面已删除、Skills 和共享资源详情保留；问题回复归原会话，无独立待处理主页面 |
| `services/` | 子目录 | 桌面通信适配 |
| `stores/` | 子目录 | 界面状态和外观同步 |
| `styles/` | 子目录 | 全局入口、统一视觉 token、桌面布局与页面分层样式 |
| `hooks/` | 子目录 | 基础组件的共享响应式 Hook |
| `browser-toolbar.html` | 浏览器 HTML | 随包专用 toolbar 入口，无远程字体 |
| `browser-toolbar.tsx` | 专用工具栏 | 普通地址栏/返回/前进/刷新/停止加载，网页状态；X直接关闭，无控制权菜单或尺寸伸缩 |
| `browser-empty-state.html` | 浏览器 HTML | 随包空态入口，网页没有业务 preload |
| `browser-empty-state.tsx` | 原空态 | 居中网页/登录说明，无接管/交还或菜单提示，不自动创建或发送会话 |
