# renderer

Renderer 启动层；main.tsx 直接挂载 AppShell，页面、组件、状态和样式按职责组织。

一旦我所属的文件夹有所变化，请更新我。

| 成员 | 地位 | 功能 |
| --- | --- | --- |
| `assets/` | 子目录 | 随前端打包的21 款生肖与毛绒角色透明 WebP 头像、会话/任务/技能/通讯录及连接向导透明毛绒 WebP 插画、历史时钟、真实模式缩略图、Geist 字体及许可 |
| `components/` | 子目录 | 业务共享组件、按 sidebar 页面管理详情 Tabs 的桌面 Shell 和 shadcn 基础组件 |
| `index.html` | 文件 | Renderer HTML 入口 |
| `main.tsx` | 文件 | 初始化外观，挂载 Tooltip/Toast 上下文和桌面 Shell |
| `pages/` | 子目录 | 按功能组织的页面和私有组件 |
| `services/` | 子目录 | 桌面通信适配 |
| `stores/` | 子目录 | 界面状态和外观同步 |
| `styles/` | 子目录 | 全局入口、统一视觉 token、桌面布局与页面分层样式 |
| `hooks/` | 子目录 | 基础组件的共享响应式 Hook |
