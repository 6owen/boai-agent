| 成员 | 职责 |
| --- | --- |

| `client.ts` | Craft客户端适配、CA/关联/事件与无自动重放 |
| `server.ts` | WS/WSS认证、注册方法与连接生命周期 |
| `channels.ts` | 原服务方法的显式schema/副作用/公开准入 |
| `discovery.ts` | 私有连接文件、实例核对与旧清理保护 |
| `index.ts` | 查询/invoke/listen命令、参数与退出状态 |

| `execution.ts` | 标准输入、原请求执行观察与取消、ExecutionFeed变化和JSON输出 |

| `server-spawner.ts` | 固定Craft迁用：认证已有服务/Node自启动、原owner空闲排空与后台交接 |

| `session.ts` | create/delete一次提交与原只读回执核对，未知保留请求ID |

| `cancel.ts` | 精确run/唯一目标选择、一次提交与只读退出核对 |

| `events.ts` | 原AppEvent共用桌面/独立服务的app与session:event发布 |
| `history.ts` | 原消息游标校验与双向CLI参数转换，不另行分页 |

| `output.ts` | 原文本证据的增量/废弃、工具结果投影和只读恢复入口；正文分块核验revision |

| `sources.ts` | --source按原员工绑定/版本生成Composer引用，重复请求保留原选择 |

| `attachments.ts` | 客户端真实字节、首发固定描述与旧准备回执；文件路径不发送至服务 |

index/execution/session传递显式权限期望；session创建与消息保持原回执身份。

| `presentation.ts` | 固定Craft动画迁用到stderr，TTY/JSON/NO_COLOR与显式关闭；只投影生命周期诊断 |

| `validation.ts` | 只读诊断/独占隔离目录、原会话执行回执和实际服务退出、证据报告 |
| `validation-fixture.ts` | 明确隔离验证的本地受控SSE服务与实际工具回执，非真实供应商 |
