受管员工、会话目录和执行环境；系统文件格式保持单一来源。
一旦我所属的文件夹有所变化，请更新我。

| 成员 | 地位 | 功能 |
| --- | --- | --- |
| `workspace-service.ts` | 工作区 | 员工根文件不投影会话/事项限定记忆；统一快照装配、受控投影和仅 hash 匹配的记忆视图清理；外部修改可见且保留；初始化/范围记忆投影、系统文件版本与纯团队初始文件清单|
| `environment-plan.ts` | 环境 | 获准资源、权限与运行环境计划 |
| `file-access.ts` | 文件边界 | 发布字节 hash/明确修订参数及失败外改保留；每次读/列/写/发布复核宿主材料来源；受限路径访问和真实产物发布 |
| `artifact-repository.ts` | 成果权威 | 显式本人固定版待验收资格/只读核对，修订/采用/关联新版在原事务结束资格，清理最小回执；资格不表示质量批准；宿主复制时 hash 到登记时原件一致门禁、受管原件 hash/逻辑版本、同一验证字节工具读取、真实文件证据与格式预览分离、无链接有界 Markdown 原文；用户消息同事务修订关系与根持有者发布；固定本人条件采用/事件/回执、来源门禁、外改保留清理日志及本地恢复核对 |
