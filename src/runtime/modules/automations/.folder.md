自动化产品账本、确定性时间规则与唯一原生时钟；业务工具仍走宿主运行链。
一旦我所属的文件夹有所变化，请更新我。

| 成员 | 地位 | 功能 |
| --- | --- | --- |
| `automation-service.ts` | 调度 |通讯录删除暂停计划、定向取消等待，随后同步原生日程； 创建回执查询与显式恢复暂停计划； 异步监控读取与当前授权/停止待退出、失败不重读；完整历史待处理计数与最近结束结果；当前预算期限与旧计时器隔离、时钟回拨不延长计时；持久通知消费唤醒与预算停止原因； 新任务聊天准备/授权、共享规则的纯日程预览和完整分页查询； 版本化配置同步/有界重试、事务受理与提交后投递、跨工作无重放核对、定向取消待退出、明确补充入口、原预算期限与容量释放通知和活跃投影 |
| `native-schedules.ts` | 适配 | 原生 Mastra 时钟、版本输入、时间桶完整分页对账与备份 |
| `automation-repository.ts` | 事务账本 | 监控单次认领、检查点/结果/通知同事务与规则变更/恢复重建基线；使用当前可信额度准入；结果与通知意图同事务、原通知偏好兼容/语义去重与恢复不重发； 任务聊天/触发同事务绑定、初始化失败记录、员工/聊天策略与日程版本； schema 快照迁移、定义 CAS、触发别名/容量认领、消息/意图提交、受理预算/等待容量再认领/补充消息同事务提交、工作执行/发布隔离、历史与中断恢复；创建去重回执与定义同事务，删除不重建 |
| `schedule-policy.ts` | 纯规则 | 工作日/星期多选统一校验、规范化 cron 和纯预览； 显式时区日历匹配/预览、版本化稳定身份、等待/取消退出占用、并发/时限 |
| `automation-results.ts` | 结果投影 | 已接替判断与旧失败分离、追加回执与累计预算；按持久来源汇总全部拥有的工作/轮次、当前正文与已核查文件证据；明确补充解除对应提问等待、权威逐调用预算用量与旧记录未知、独立依赖不归属，取消等实际退出 |

| `automation-notifications.ts` | 通知账本 | 监控重要性/冷却与显式每次结果偏好；与页面共用未交付/部分结果的待处理语义；与结果同事务的意图、语义去重/策略判断、原子领取、提交回执、重启/恢复未知或抑制 |
| `automation-monitor.ts` | 纯比较 | 完整性/新鲜度/时钟校验、固定字段与累计阈值、冷却、版本指纹及成功检查点 |
| `monitor-source.ts` | 来源适配 | 读取获准聊天的同名最新已发布 JSON；文件/路径/版本/大小/链接与读取变化检查 |

| `automation-draft.ts` | 创建草稿 | 结构化候选、明确身份与支持周期校验，不保存或启用计划 |
