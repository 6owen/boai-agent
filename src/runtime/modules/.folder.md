按业务能力组织员工、工作区、资源、记忆、外部后端、自动化和协作规则。

一旦我所属的文件夹有所变化，请更新我。

| 成员 | 地位 | 功能 |
| --- | --- | --- |
| `employees/` | 员工 | 通讯录独立分类与排序偏好；配置、版本与授权 |
| `workspaces/` | 工作区 | 文件访问、隔离环境和系统文件 |
| `resources/` | 资源 | 三家只读技能商店、技能/知识导入、技能详情/扫描安装/持久收藏与搜索；只读发现全局/Agent/启用插件 Skills |
| `memory/` | 记忆 | 带来源的授权记忆 |
| `backends/` | 执行后端 | 外部程序身份/运行方式、显式登录目录与版本化验证 |
| `automations/` | 自动化 | 事务调度、授权、跨工作证据汇总与定向取消待退出 |
| `collaboration/` | 协作 | 连接/资源准入、工作认领/委派/依赖、定向接续、根预算与业务结果 |

| `conversations/` | 会话生命周期 | 清理记录、专属文件和重启续清日志 |
