按业务能力组织员工、工作区、资源、记忆、外部后端、自动化和协作规则。

一旦我所属的文件夹有所变化，请更新我。

| 成员 | 地位 | 功能 |
| --- | --- | --- |
| `employees/` | 员工 | 通讯录独立分类与排序偏好；配置、版本与授权 |
| `workspaces/` | 工作区 | 文件访问、隔离环境和系统文件 |
| `resources/` | 资源 | 三家只读技能商店、技能/知识导入、技能详情/扫描安装/持久收藏与搜索；只读发现全局/Agent/启用插件 Skills |
| `memory/` | 记忆 | 带来源的授权记忆 |
| `backends/` | 执行后端 | 外部程序身份/运行方式、显式登录目录与版本化验证 |
| `automations/` | 自动化 | 事务调度、授权、跨工作证据汇总与定向取消待退出 |
| `collaboration/` | 协作 | 连接/资源准入、工作认领/分工/依赖、定向接续、根预算与业务结果；bobo 原组织合同/独立群根共预算、逐调用记账、原文件与首次启动显式恢复零重放 |

| `conversations/` | 会话生命周期/个人检索 | 清理与续清、固定阅读/完成身份；本地多词相关性与核源正文有界索引/覆盖 |

| `teams/` | 团队创建 | 草稿持久化、版本/hash 和单未结束实例 |
| `profile/` | 本机资料 | 资料版本事务、严格 PNG 校验、调用/技能/执行区间观测与一致活动聚合 |

| `materials/` | 聊天材料 | 私有 TXT/MD/图片/通用文件原件、准备回执、确定文本或安全栅格预览、版本/明确成员授权、消息事务关联与 hash 清理/备份 |

| `inbox/` | D5 待处理 | 原问题/审批/失败/显式成果资格的SQL只读投影、稳定分页；普通/自动化固定原问题/运行/Work/独立owner来源与补充事务复核 |
| `browser/` | 内置浏览器工具边界 | 应用窗口与调用持有者分离；原工作回执/来源批准/预算和实际退出，unknown不重放 |

| `bobo-collaboration/` | bobo 发起群协作 | SQL 有界员工发现、已有员工复用/缺员准备、真实公告与原预算启动意图同事务；取消/清理/重启保持员工独立 |

| `channels/` | 业务接线 | 员工/机器人关联、外部会话/授权、真实公开回复及独立发送回执 |
