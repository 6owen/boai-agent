集中管理聊天记录清理及独立个人浏览；宿主发布事务提供真实完成身份，来源 hooks 核对实际文件与当前授权。
一旦我所属的文件夹有所变化，请更新我。

| 成员 | 地位 | 功能 |
| --- | --- | --- |
| `search-body-index.ts` | 正文派生索引 | 同次核读文本、有界文件/字节/耗时、超限/失败记录、事务再次核对来源及清理竞态、稳定版本；不扫描任意路径/不调用模型 |
| `search-index-sql.ts` | 索引固定 SQL | 已发送/已登记对象在可见授权范围内的稳定待核读队列与覆盖/失败统计，未发/隐藏/清理不入队 |
| `search-matching.ts` | 纯匹配规则 | 连续中文子串、空白多词 AND、名称/正文/短语/重复词固定相关性；无向量/模型或默认英文分词 |
| `reading-repository.ts` | 个人阅读权威 | 真实发布同事务单调完成/重复幂等；固定所见完成身份、连续边界/有界缺口、独立锚点 CAS、当前来源同事务复核、旧历史未知、首个未读及清理 epoch |
| `search-repository.ts` | 个人浏览读模型 | 四类来源/核源文件正文的 AND 相关性、固定目标/摘录和覆盖进度，索引版本拒绝混页；查询/点击再次核源、失效零旧正文；原授权历史窗口与目标消失空页不变，不创建 Work/模型 |
| `reading-sql.ts` | 固定 SQLite 查询 | 四类名称/消息/固定来源正文多词 AND、确定性相关性和 score/time/ID/type 游标；可见性/会话/员工/时间/类型在 LIMIT 前；内部历史授权及 sequence/ID 窗口、当前 epoch 完成身份和首个真实未读 |
| `history.ts` | 清理用例 | D6 最终清理事务删除私人阅读/完成事实并提升最小 clock epoch；成果失效/hash 清理及修订/采用回执、外改冲突阻止递归删除；普通消息清理去重回执与材料 hash 清理冲突恢复门禁；核心首发保留去正文的最小 cleared 回执，阻止清理后的首发重放；清空/解散共用重启日志并先传播记忆来源失效，防跨会话摘要和原文回退；解散删除会话配置/通讯录顺序且不重建目录；清理关联模型调用/技能激活/执行区间、Trace、监控检查点、自动化私有意图/跨工作证据/预算回执/待回答引用，终结失去上下文的等待，保留个人资料/共享资源/触发身份；通知待提交抑制/提交中未知；聊天清理同事务移除codexSessions/claudeSessions映射，不复用旧外部历史。 |
