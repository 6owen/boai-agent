| 成员 | 地位 | 功能 |
| --- | --- | --- |
| `reading-repository.ts` | 个人阅读权威 | 真实发布同事务单调完成/重复幂等；固定所见完成身份、连续边界/有界缺口、独立锚点 CAS、当前来源同事务复核、旧历史未知、首个未读及清理 epoch |
| `search-repository.ts` | 个人浏览读模型 | 会话名称/正文与登记文件名统一有界搜索、原会话 ID 与固定旧版目标、sequence/ID 历史窗口、查询与点击当前来源复核；搜索隐藏/清理/删除竞态拒绝旧目标且不恢复，内部消息窗口仍核原授权；固定消息缺失或校验删除仅返回原身份无游标空页、不报提示、不回退正文；其余失效只原因无旧正文，模型上下文窗口保持独立 |
