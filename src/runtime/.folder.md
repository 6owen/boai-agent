# runtime

本地运行入口、应用用例和群聊调度；业务能力归入 modules，外部实现归入 adapters。

一旦我所属的文件夹有所变化，请更新我。

| 成员 | 地位 | 功能 |
| --- | --- | --- |
| `adapters/` | 子目录 | Mastra、ACP 和产品存储适配 |
| `contracts.ts` | 文件 | 仅供运行层使用的引擎上下文、接口和凭据合同 |
| `group-scheduler.ts` | 文件 | 群聊轮次、成员判断与发言调度 |
| `modules/` | 子目录 | 员工、工作区、资源、记忆、执行后端和自动化模块 |
| `service.ts` | 文件 | 应用用例、运行生命周期与授权管理 |
| `worker.ts` | 文件 | 本地运行进程的服务装配和消息处理 |
