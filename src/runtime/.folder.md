# runtime

本地运行入口、应用用例和群聊调度；业务能力归入 modules，外部实现归入 adapters。

一旦我所属的文件夹有所变化，请更新我。

| 成员 | 地位 | 功能 |
| --- | --- | --- |
| `adapters/` | 子目录 | Mastra、ACP 和产品存储适配 |
| `contracts.ts` | 文件 | 宿主/适配器统一连接容量及判断时限、引擎上下文、委派/等待、已声明等待与结果回调、合并投递引用及凭据合同 |
| `group-scheduler.ts` | 文件 | 群聊轮次、已回复成员合并普通输入且保留定向机会、首次/后续判断有限并发、有限并行任务/独立子工作、按成员并行流式聊天、完成事件版本与用户输入优先、清理后的投影回收 |
| `modules/` | 子目录 | 员工、工作区、资源、记忆、执行后端、自动化与协作工作控制 |
| `service.ts` | 文件 | 本地 API/ACP 来源标识串行去重、ACP 会话认证测试与失败清除验证、编辑与草稿测试保留 Chat/Responses 协议、 应用用例、草稿模型目录/连接测试不保存、编辑时读取密钥、显式空值与省略凭据的同服务同地址复用、会话记录/专属文件清理及内存回收、会话列表偏好批量持久化、工作认领/结算、统一判断时限与实际调用容量、仅关联输入更新草稿、证据/等待状态的有界汇报修复与发布、定向接续/停止树及授权 |
| `worker.ts` | 文件 | 本地运行进程的服务装配和消息处理 |
