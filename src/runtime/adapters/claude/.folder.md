一旦我所属的文件夹有所变化，请更新我。

| 成员 | 地位 | 功能 |
| --- | --- | --- |
| `engine.ts` | 原生员工引擎 | 共同持续会话入口的 Claude 子类；本机配置和原生工具保持 |
| `thinking-bridge.ts` | 提供方兼容 | nonce回环仅转原私有Messages，唯一格式器按有序ID/布尔回执选择；未完成才指定choice，schema/模型/消息/响应及实际关闭保持 |
| `input.ts` | 媒体输入 | 临时原生图片消息、实际MIME与base64/单件20MiB/累计60MiB核对；不静默丢图，不读取路径/URL |
| `provider.ts` | 模型来源 | 明确Anthropic端点及已知DeepSeek兼容映射，拒绝其他未支持的OpenAI兼容来源 |
| `policy.ts` | 版本策略 | 最小环境、明确API认证、禁用原生执行工具/技能/隐式MCP发现与自动续做；私有阶段仅格式器、显式提交说明及已验证有界合成提醒 |
| `supervisor.ts` | 存活监督 | 固定Node IPC启动脚本，同组运行CLI；宿主断开立即停组，实际退出码只经私有IPC返回 |
| `process.ts` | 受管传输 | 有界逐行输出、串行回调、取消和实际进程组退出；每次两流原始字节仅作诊断，原门禁不变 |
| `usage.ts` | 计量协议 | 实际消息ID去重、累计字段和缓存用量、成功终态一致性；仅返回已知部分，不保存正文或推算内部步骤 |
| `turn.ts` | 阶段入口 | 私有is_error仅省略/布尔，原唯一回执/三轮纠正/终态深相等保持；固定内容桶仅进入处理，身份/计量/工具/退出沿原合同 |

| `tools.ts` | 宿主MCP桥 | 回环认证/明确目录、公开调用身份/参数核对、单次执行回执及关闭等待实际退出；白名单接收/执行/回执计数与固定错误状态 |
