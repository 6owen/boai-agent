将外部框架、协议与产品业务分层；运行许可和业务状态归宿主。

一旦我所属的文件夹有所变化，请更新我。

| 成员 | 地位 | 功能 |
| --- | --- | --- |
| `agent-factory.ts` | 适配层 | 分阶段 Agent、聊天/执行边界、精简独立判断规则、授权委派成员与保留等待声明的重新汇报；阶段 Trace 装配与真实模型请求观测 |
| `bound-skill-source.ts` | 适配层 | 已绑定技能来源 |
| `engine.ts` | 适配层 | 员工思考强度传入各阶段、自动模式降低日常开销并保留任务默认， 宿主统一判断时限、判断截断有界修复、聊天/任务/记忆执行、私有重新汇报、步骤预算和结构化限流原因；各阶段结束刷新 Trace |
| `host-command.ts` | 适配层 | 宿主授权命令 |
| `message-projection.ts` | 适配层 | 授权消息窗口、轮次投影、判断阶段空元数据省略 |
| `model-catalog.ts` | HTTP 适配 | 兼容接口 /models 获取、超时与认证错误、响应校验和模型 ID 去重 |
| `model-config.ts` | 适配层 | 按有效模型及员工偏好映射 DeepSeek 思考参数， Anthropic 与 OpenAI Chat/Responses 配置；无协议旧记录继续使用 Chat |
| `task-runtime.ts` | 适配层 | 任务工具、副作用登记/完成确认、委派/依赖等待与结果声明 |
| `trace.ts` | 观测适配 | 原生 Span 本地导出、真实模型请求输入、密钥脱敏及阶段结束刷盘；不改变执行或重试 |
