# boai-tasks

`SKILL.md`：看板是人工目标/验收/产出的委派接口；Agent的todo、计划和子Agent分工不进入看板，tasks.create仅记内部progress。原指派沿原ID更新，交付待确认，由用户验收完成/关闭；状态不控制执行，完成后仍能在原会话继续问答、返工和重复使用。

会话创建的原始要求通过同一任务的title/description补全，briefPending只是正文待整理标记；状态可任意创建、拖拽或手动设置，不代表已经执行或验收。
